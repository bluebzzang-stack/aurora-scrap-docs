앱 잠금과 업데이트

보안설정은 앱 실행 시 비밀번호를 요구하는 화면 잠금 기능입니다. 저장된 파일을 암호화하는 기능은 아닙니다. 업데이트는 새 앱 버전을 내려받고 재시작할 때 적용합니다. 두 기능은 설정 → 일반에서 확인하며, 앱 창이 닫힌 상태에서도 트레이를 통해 다시 열거나 업데이트를 확인할 수 있습니다. 컴퓨터에 로그인하는 계정의 보호와 앱 화면 잠금을 구분해서 사용합니다.

비밀번호 설정하기

섹션 제목: “비밀번호 설정하기”
  1. 설정 → 일반을 엽니다. 보안설정까지 내려갑니다. 처음 설정할 때는 스위치를 켜면 비밀번호 입력란이 나타납니다.
  2. 비밀번호 입력에 사용할 비밀번호를 입력합니다. 비밀번호 다시 입력에 같은 내용을 한 번 더 입력합니다.
  3. 필요하면 **비밀번호 힌트 (선택)**를 작성합니다. 잠금 화면에서 힌트를 볼 수 있으므로 비밀번호 전체를 그대로 적지는 않습니다.
  4. 하단 저장을 누릅니다. 두 입력이 다르면 **비밀번호가 일치하지 않습니다.**라는 안내를 확인하고 다시 입력합니다.
  5. **비밀번호가 설정되었습니다.**라는 안내를 확인합니다. 스위치만 켜고 비밀번호를 저장하지 않은 상태와 구분합니다.
  6. 앱을 다시 실행했을 때 비밀번호를 입력하세요 화면에서 비밀번호를 입력하고 잠금 해제를 누릅니다. 필요하면 힌트 보기를 사용합니다.

비밀번호 변경과 해제

섹션 제목: “비밀번호 변경과 해제”
하려는 작업 필요한 확인 진행 방법
처음 설정 비밀번호 두 번 입력 하단 저장으로 적용합니다.
비밀번호 변경 현재 비밀번호 확인 확인 후 새 비밀번호를 두 번 입력하고 저장합니다.
보안설정 끄기 현재 비밀번호 확인 끄기 안내에 따라 비밀번호를 확인합니다.
잠금 화면 열기 등록한 비밀번호 입력 잠금 해제를 누릅니다.
입력 오류 해결 오타와 입력 언어 확인 비밀번호가 올바르지 않다는 안내 후 다시 입력합니다.

이미 비밀번호가 등록되어 있으면 바로 새 비밀번호 입력란이 나오지 않습니다. 현재 비밀번호 입력에서 확인을 마쳐야 변경할 수 있습니다. 보안설정을 끄는 경우에도 같은 확인이 필요합니다. 현재 비밀번호를 모르는 상태에서 문서의 임의 파일 삭제 절차를 따라 잠금을 해제하도록 안내하지 않습니다. 먼저 설정한 힌트와 입력 언어를 확인합니다.

잠금은 앱 화면에 접근하는 절차를 추가합니다. 탐색기나 Finder에서 열 수 있는 스크린샷, PDF, 콘텐츠 파일 자체를 비밀번호 파일로 바꾸지 않습니다. 여러 사람이 같은 OS 계정으로 파일에 접근할 수 있는 환경이면 그 권한도 별도로 관리해야 합니다. 앱 잠금만 켜서 모든 복사본까지 보호되었다고 판단하지 않습니다.

자동 업데이트 사용하기

섹션 제목: “자동 업데이트 사용하기”
  1. 설정 → 일반 → 자동 업데이트를 확인합니다. 기본으로 켜져 있으며 새 버전을 자동으로 내려받는 설정입니다.
  2. 새 버전 준비 완료 안내가 나오면 현재 편집과 녹음을 먼저 마칩니다. 동기화할 자료가 있으면 전송 상태도 확인합니다.
  3. 바로 적용하려면 지금 재시작을 누릅니다. 잠시 계속 작업하려면 나중에를 선택합니다.
  4. 앱을 다시 연 뒤 도움말 → Aurora Scrap 정보에서 적용된 버전을 확인합니다. macOS에서는 Aurora Scrap → Aurora Scrap 정보도 사용할 수 있습니다.

자동 업데이트를 끄면 새 버전이 있을 때 알림만 표시되고 자동으로 다운로드하지 않습니다. 새 버전이 있습니다 안내에서 자동 업데이트가 꺼져 있다는 설명을 확인할 수 있습니다. 자동으로 받으려면 설정에서 다시 켭니다. 업데이트 알림을 닫는 행동과 업데이트 파일의 다운로드 또는 설치가 완료되는 행동을 구분합니다.

트레이에서 수동 확인하기

섹션 제목: “트레이에서 수동 확인하기”

Windows에서는 작업 표시줄 알림 영역의 AURORA 아이콘을 확인합니다. 아이콘이 숨겨져 있으면 숨겨진 아이콘 목록을 엽니다. macOS에서는 화면 위 메뉴 막대의 아이콘을 확인합니다. 해당 아이콘의 메뉴에서 업데이트 확인을 선택합니다. 확인 중이거나 결과가 표시되는 동안 잠시 기다린 뒤 안내에 따릅니다.

트레이 메뉴 동작
Aurora Scrap 열기 메인 창을 다시 표시합니다.
새 웹스크랩 URL을 입력할 새 스크랩 화면을 엽니다.
새 콘텐츠 작성 콘텐츠 생성 흐름을 시작합니다.
새 사진첩 사진첩 생성 화면을 엽니다.
새 화면캡처 전체 화면, 창 선택, 자유 영역 중에서 선택합니다.
업데이트 확인 현재 시점에 새 버전을 확인합니다.
종료 트레이에 남은 앱까지 종료합니다.

창의 닫기 버튼을 누른 뒤에도 앱은 트레이에 남아 있을 수 있습니다. 브라우저 확장 연결을 계속 사용하려면 앱을 실행해 둡니다. 완전히 종료하려면 트레이의 종료를 사용합니다. 트레이 메뉴의 새 콘텐츠 작성과 파일 메뉴의 새 콘텐츠는 같은 종류의 자료를 만드는 진입점이며 표기가 조금 다릅니다.

자동 시작에 관하여

섹션 제목: “자동 시작에 관하여”

현재 설정 창에는 자동 시작을 켜는 조작 항목이 없습니다. 앱을 한 번 실행한 뒤 창을 닫아 트레이에 유지하는 동작과, 컴퓨터 로그인 때 앱이 자동으로 시작하는 동작은 다릅니다. PC를 재시작한 뒤 확장이 연결되지 않으면 먼저 AURORA가 실제로 실행되어 있는지 확인합니다. 설정에 없는 자동 실행 스위치를 찾을 필요는 없습니다.

화면 잠금의 범위

보안설정은 파일 암호화가 아닙니다. 로컬 저장 파일, 다른 PC의 복사본, 내보낸 파일을 자동으로 잠그지 않습니다. 각 PC의 앱 잠금 상태와 저장 폴더 접근 권한을 구분해서 확인합니다.

자주 묻는 질문

섹션 제목: “자주 묻는 질문”

비밀번호를 입력했는데 저장이 안 되면 무엇을 확인하나요?

섹션 제목: “비밀번호를 입력했는데 저장이 안 되면 무엇을 확인하나요?”

비밀번호와 재입력 값이 같은지 확인합니다. 기존 비밀번호를 바꾸는 상황이면 현재 비밀번호의 확인을 먼저 마칩니다. 하단 저장을 누른 뒤 설정 완료 안내까지 확인합니다.

나중에를 누르면 업데이트를 잃어버리나요?

섹션 제목: “나중에를 누르면 업데이트를 잃어버리나요?”

준비된 업데이트는 나중에 적용할 수 있습니다. 안내에는 다음 종료 때 설치된다는 설명이 표시됩니다. 작업을 마친 뒤 앱을 종료하고 다시 열어 버전을 확인합니다. 실제로 종료하지 않고 창만 숨긴 상태와 구분합니다.

트레이에 새 아이디어가 없는데 오류인가요?

섹션 제목: “트레이에 새 아이디어가 없는데 오류인가요?”

현재 트레이에는 새 웹스크랩, 새 콘텐츠 작성, 새 사진첩, 새 화면캡처가 있습니다. 아이디어는 메인 창의 새 아이디어나 파일 메뉴에서 만듭니다. 메뉴마다 제공하는 항목이 완전히 같은 것은 아닙니다.
