설정 항목 안내

설정에서는 앱 표시 방식, 목록을 읽는 방법, 스크랩의 미디어 처리, Google 계정과 라이선스를 관리합니다. 설정 창은 일반, 테마, 워크스페이스, 목록, 스크랩, 계정, 라이선스의 일곱 탭으로 구성됩니다. 같은 스크랩이라도 표시 방식과 저장 옵션의 역할은 다릅니다. 화면을 바꾸려는 것인지, 앞으로 가져올 자료의 처리 방식을 바꾸려는 것인지 먼저 구분하고 해당 탭을 엽니다.

설정 열고 확인하기

섹션 제목: “설정 열고 확인하기”
  1. 상단 설정 아이콘을 누릅니다. 키보드로는 Ctrl+, (macOS는 Cmd+,)를 사용합니다. 입력 중이면 입력란 바깥을 클릭한 뒤 실행합니다.
  2. 왼쪽 탭에서 바꾸려는 항목이 있는 구역을 선택합니다. macOS에서는 Aurora Scrap → 환경설정 메뉴로도 같은 창을 엽니다.
  3. 현재 선택과 설명 문구를 확인한 뒤 값을 바꿉니다. 테마, 언어, 목록 관련 옵션처럼 변경 즉시 저장되는 항목이 있습니다.
  4. 보안설정의 새 비밀번호는 두 입력을 일치시킨 뒤 하단 저장을 눌러 적용합니다. 비밀번호를 입력한 것만으로 잠금 설정이 완료되지는 않습니다.
  5. 창을 닫고 실제 목록이나 미리보기에서 결과를 확인합니다. 취소나 닫기를 누르면 이미 반영된 모든 설정이 되돌아간다고 생각하지 않습니다.

개인 저장 경로를 가린 현재 한국어 설정의 일반 탭입니다.

일반

섹션 제목: “일반”
항목 선택 또는 동작 사용 방법
저장 경로 워크스페이스 생성에 사용하는 전체 저장 루트 표시 읽기 전용입니다. 옆의 폴더 열기 버튼으로 위치를 확인합니다.
언어 한국어, English, 日本語, 中文 선택한 언어로 앱 문구를 바꿉니다.
링크 열기 기본 브라우저, Aurora 브라우저 원본 링크를 열 브라우저를 선택합니다.
새 콘텐츠·아이디어 간편 실행 켜기 또는 끄기 켜면 바로 생성하고, 끄면 입력 다이얼로그를 먼저 엽니다.
자동 업데이트 켜기 또는 끄기 끄면 새 버전을 알려 주지만 자동으로 내려받지 않습니다.
보안설정 비밀번호와 선택적 힌트 앱 실행 시 잠금 화면을 사용합니다.

저장 경로는 다른 폴더를 입력해 기존 자료를 옮기는 항목이 아닙니다. 처음 정한 저장 위치를 확인하는 표시입니다. 활성 워크스페이스의 실제 폴더는 워크스페이스 → 저장 폴더 열기로 확인합니다. 전체 저장 루트와 지금 선택한 워크스페이스 폴더를 혼동하지 않습니다.

언어는 앱을 다시 설치하지 않고 바꿀 수 있습니다. 번역된 메뉴의 위치는 동일하므로 다른 언어를 실수로 선택했으면 설정의 첫 번째 탭으로 돌아와 언어를 다시 선택합니다. 링크 열기는 웹페이지 원본을 확인할 때의 선택입니다. 이미 저장한 스크린샷 파일의 형식이나 목록의 분류를 바꾸지는 않습니다.

테마

섹션 제목: “테마”
항목 선택값 설명
테마 라이트, 다크, 시스템 밝은 화면, 어두운 화면 또는 OS 설정을 사용합니다.
다크 색상 계열 다크 블루, 그레이 다크 다크를 선택했을 때 색상 계열을 고릅니다.
카테고리 트리 스타일 모던, 클래식, 라인 카테고리 목록의 강조와 연결선 표시를 바꿉니다.

테마를 바꿔도 카테고리 구조와 자료는 그대로 있습니다. 트리 스타일은 표시 방식이며 카테고리를 새로 만드는 작업이 아닙니다. 시스템 테마를 사용하면 OS의 밝고 어두운 모드를 따릅니다. 특정 다크 색상을 직접 비교하려면 먼저 다크를 선택해 색상 계열 항목을 확인합니다.

워크스페이스와 목록

섹션 제목: “워크스페이스와 목록”
탭 항목 역할
워크스페이스 탭 위치 워크스페이스 탭을 상단 또는 하단에 놓습니다.
워크스페이스 탭에 스크랩 개수 표시 탭에서 항목 수를 함께 봅니다.
목록 목록 표시 방식 무한 스크롤 또는 페이지네이션을 선택합니다.
목록 페이지당 목록 수 한 번에 표시할 목록 수를 조절합니다.
목록 사진첩 목록 갯수 사진첩에서 한 번에 불러올 이미지 수를 정합니다.
목록 제목 풍선도움말 잘린 제목 위에 마우스를 올렸을 때 전체 제목을 봅니다.

무한 스크롤은 아래로 이동하면서 다음 항목을 이어 불러옵니다. 페이지네이션은 페이지 번호로 이동합니다. 사진첩 목록 수보다 많은 이미지도 삭제되거나 숨겨진 채 끝나는 것은 아닙니다. 사진첩에서 계속 스크롤하면 나머지를 불러옵니다. 카드와 리스트의 모양 전환은 목록 툴바나 보기 메뉴에서 따로 진행합니다.

스크랩

섹션 제목: “스크랩”
항목 선택 또는 동작 설명
동영상 자동 재생 켜기 또는 끄기 목록에서 영상을 선택했을 때 바로 재생할지 정합니다.
페이지 내 동영상/오디오 다운로드 켜기 또는 끄기 페이지에 포함된 미디어를 로컬 저장 대상으로 삼습니다.
최대 용량 100 MB, 500 MB, 1 GB, 2 GB, 무제한 페이지 내 미디어 다운로드의 최대 용량을 정합니다.
동영상 사이트 사이트 추가, 삭제 해당 주소를 영상 다운로드 방식으로 처리할지 정합니다.
기본 목록 복원 사이트 목록 초기화 동영상 사이트 목록을 기본 구성으로 되돌립니다.

동영상 사이트에 사이트 주소를 추가하면 해당 주소의 스크랩 처리 방식이 달라집니다. 추가한 사이트의 모든 영상이 내려받아지는 것을 보장하지는 않습니다. 로그인이 필요하거나 저장을 허용하지 않는 영상은 실패할 수 있습니다. 무제한은 이 미디어 옵션의 상한을 없애는 선택이며 요금제의 워크스페이스 용량 제한을 해제하지 않습니다.

현재 설정 창에는 기본 저장 포맷과 동시 스크랩 수를 바꾸는 별도 조작 항목이 없습니다. 새 웹스크랩의 PNG, JPG, PDF 선택은 스크랩 다이얼로그에서 확인합니다. 없는 설정을 찾기 위해 다른 탭을 반복해서 살펴볼 필요는 없습니다.

계정, 라이선스, 앱 정보

섹션 제목: “계정, 라이선스, 앱 정보”

계정에서는 Google 계정을 연결하거나 연결을 해제합니다. 연결된 이메일과 재인증 안내를 확인합니다. 동기화 적용 전에 남긴 로컬 자료는 같은 탭의 보관함에서 확인하고 내보낼 수 있습니다. 개발 설정이 없는 환경에서 표시되는 OAuth 클라이언트 ID는 개발자 구성을 위한 항목입니다. 일반 사용자가 Google 계정 비밀번호를 넣는 곳이 아닙니다.

라이선스에서는 현재 상태, 요금제별 한도, 등록된 키의 적용 버전과 발급 정보를 확인합니다. 라이선스 키 등록에 전체 키를 붙여 넣고 등록을 누릅니다. 앱 버전과 제품 정보는 도움말 → Aurora Scrap 정보에서 확인합니다. macOS에서는 앱 이름 메뉴에서도 정보 창을 열 수 있습니다.

표시 변경과 자료 변경

테마, 목록 표시 방식, 탭 위치는 자료의 저장 형식을 바꾸지 않습니다. 저장 위치를 확인하거나 파일 형식을 선택하는 작업은 해당 화면에서 별도로 진행합니다.

자주 묻는 질문

섹션 제목: “자주 묻는 질문”

설정에서 저장 경로를 왜 수정할 수 없나요?

섹션 제목: “설정에서 저장 경로를 왜 수정할 수 없나요?”

현재 화면은 실제 저장 루트를 읽기 전용으로 표시합니다. 폴더를 열어 위치를 확인하는 용도입니다. 표시된 글자를 고쳐 모든 워크스페이스를 이동하는 기능은 제공하지 않습니다.

자동 재생을 끄면 동영상도 저장되지 않나요?

섹션 제목: “자동 재생을 끄면 동영상도 저장되지 않나요?”

자동 재생과 다운로드는 별도 옵션입니다. 선택 즉시 소리가 나지 않게 하려면 동영상 자동 재생을 끕니다. 페이지 내 영상 저장 여부는 페이지 내 동영상/오디오 다운로드에서 조절합니다.

간편 실행을 켜면 카테고리가 필요 없나요?

섹션 제목: “간편 실행을 켜면 카테고리가 필요 없나요?”

간편 실행은 생성 전에 입력 창을 거칠지 정합니다. 자료를 정리할 카테고리 조건을 없애는 설정은 아닙니다. 생성 대상 카테고리를 먼저 선택하고 새 콘텐츠나 아이디어를 만듭니다.
