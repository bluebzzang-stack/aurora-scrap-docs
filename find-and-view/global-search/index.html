통합검색

통합검색은 이 앱에 등록된 여러 워크스페이스의 자료를 한 번에 찾습니다. 저장 위치나 카테고리를 기억하지 못할 때 사용합니다. 제목뿐 아니라 저장된 본문, 설명, 메모, 작성자, 사이트, URL을 검색하며 태그로 일치하는 자료도 찾습니다. 결과를 누르면 해당 자료가 보관된 워크스페이스와 카테고리로 이동합니다. 인터넷 전체를 검색하거나 원본 페이지를 새로 수집하는 기능은 아닙니다.

여러 워크스페이스에서 검색하기

섹션 제목: “여러 워크스페이스에서 검색하기”
  1. 앱 상단의 통합검색 버튼을 누릅니다. 현재 열어 둔 카테고리와 관계없이 통합검색 창을 엽니다. 좋아요 화면을 사용 중일 때도 필요한 자료를 검색할 수 있습니다.
  2. 모든 워크스페이스에서 검색… 입력란에 기억하는 단어를 적습니다. 제목의 일부, 메모의 표현, 작성자 이름, 사이트 이름처럼 자료를 구분할 수 있는 단서를 사용합니다.
  3. 검색 결과가 갱신될 때까지 잠시 기다립니다. 입력할 때마다 검색하므로 긴 문장을 한꺼번에 넣기보다 결과를 보면서 단어를 조정합니다.
  4. 워크스페이스 칩에서 원하는 공간을 선택합니다. 특정 칩을 선택하면 전체 검색 결과 중 해당 공간의 결과만 보여줍니다. 다른 칩으로 바꾸어 같은 검색어의 결과를 비교할 수 있습니다.
  5. 결과의 제목, 종류, 워크스페이스와 카테고리 정보를 확인합니다. 비슷한 제목이 여러 번 나와도 같은 보관 항목이라고 단정하지 않습니다.
  6. 원하는 결과를 누릅니다. 검색창이 닫히고 해당 워크스페이스로 전환한 뒤 카테고리와 항목이 선택됩니다. 자료를 옮기거나 복제하지 않고 원래 보관 위치를 엽니다.

일곱 기본 검색 필드

섹션 제목: “일곱 기본 검색 필드”
필드 검색하는 정보 검색 단서 예시
제목 항목에 저장된 제목입니다 기억하는 제목의 단어를 입력합니다
본문 추출하거나 작성하여 색인한 텍스트입니다 글 내용의 핵심 표현을 입력합니다
설명 원본이나 항목에 저장된 설명입니다 짧은 소개에 들어 있던 단어를 입력합니다
메모 사용자가 항목에 덧붙인 기록입니다 저장 이유나 후속 작업의 표현을 입력합니다
작성자 수집된 원본 작성자 정보입니다 글을 쓴 사람이나 조직의 이름을 입력합니다
사이트 수집된 사이트 이름입니다 게시된 서비스나 매체 이름을 입력합니다
URL 저장된 원본 주소입니다 주소의 도메인이나 구분되는 부분을 입력합니다

태그 이름도 별도로 검색하여 일치하는 항목을 결과에 포함합니다. 라벨 이름은 위 검색 필드에 해당하지 않습니다. 색상 라벨로 묶은 자료를 보고 싶으면 목록의 라벨로 필터를 사용합니다. 검색어를 넣는 것과 라벨을 선택하는 것은 서로 다른 검색 방법입니다.

필드에 실제 값이 있어야 그 정보로 찾을 수 있습니다. 작성자를 제공하지 않는 페이지에는 작성자 검색에 사용할 내용이 없을 수 있습니다. 본문이 없는 이미지 파일은 이미지 속 글자가 자동으로 모두 검색된다고 가정하지 않습니다. 필요한 글자는 텍스트 인식으로 복사하여 메모나 콘텐츠에 남길 수 있습니다.

아이디어와 작성한 콘텐츠 찾기

섹션 제목: “아이디어와 작성한 콘텐츠 찾기”

아이디어 보드의 텍스트와 표 셀, 페이지 이름은 검색에 활용됩니다. 여러 페이지로 된 보드에서도 표시되는 글자를 기준으로 찾습니다. 보드의 이미지 첨부 경로처럼 사용자가 읽을 내용이 아닌 정보는 검색 단서로 삼지 않습니다. 이미지 안의 글자는 보드의 텍스트 요소와 구분합니다.

기존 보드나 다른 워크스페이스의 자료는 파일과 검색 정보가 준비된 정도에 따라 결과가 달라질 수 있습니다. 다른 PC에서 만든 자료가 보이지 않으면 먼저 동기화 상태를 확인합니다. 로컬에 아직 없는 파일까지 새로 받아 전체 내용을 읽는 과정으로 통합검색을 이해하지 않습니다.

직접 작성한 콘텐츠도 저장된 본문을 기준으로 검색합니다. 긴 글을 자주 찾을 예정이라면 제목과 메모를 함께 정리합니다. 본문의 한 문장만 기억하기보다 문서 목적을 제목이나 태그에 남기면 다른 단서로도 접근할 수 있습니다. 검색 결과에서 열린 문서가 맞는지 실제 내용을 확인합니다.

검색 범위 조정하기

섹션 제목: “검색 범위 조정하기”

워크스페이스 칩은 결과를 공간별로 좁히는 버튼입니다. 칩의 결과 수는 해당 검색어에 일치한 항목 수이며 워크스페이스의 전체 스크랩 수가 아닙니다. 칩이 화면 폭보다 많으면 가로로 이동하여 다른 이름을 확인합니다. 특정 공간을 선택한 채 검색어를 바꿨다면 현재 칩도 함께 확인합니다.

검색어를 지우면 새 검색을 시작할 수 있습니다. 검색창을 닫았다가 다시 열면 초기 상태에서 입력합니다. 결과가 너무 많으면 자료를 구분할 수 있는 표현을 사용합니다. 검색 문법을 추측하여 특수 기호를 복잡하게 넣기보다 실제 제목이나 메모에 있는 단어를 우선 사용합니다.

검색은 저장된 자료를 기준으로 합니다

원본 페이지가 바뀌었다고 기존 스크랩의 검색 내용도 즉시 바뀌지는 않습니다. 현재 저장한 자료에 어떤 제목, 본문, 설명이 있는지 확인합니다. 최신 원문을 읽으려면 항목의 원본 URL을 엽니다.

자주 묻는 질문

섹션 제목: “자주 묻는 질문”

모든 워크스페이스란 Google Drive 전체인가요?

섹션 제목: “모든 워크스페이스란 Google Drive 전체인가요?”

아닙니다. 이 앱에 등록된 워크스페이스의 자료를 검색합니다. 원격에만 존재하고 이 PC에서 아직 가져오지 않은 워크스페이스를 Google Drive 전체 검색으로 대신 찾는 기능은 아닙니다. 먼저 해당 공간을 앱으로 가져옵니다.

휴지통에 있는 자료도 나오나요?

섹션 제목: “휴지통에 있는 자료도 나오나요?”

통합검색은 삭제되지 않은 항목을 대상으로 합니다. 삭제한 자료를 찾을 때는 해당 워크스페이스의 휴지통을 엽니다. 복원 후 일반 목록에서 내용을 확인하고 필요한 경우 다시 검색합니다.

본문 단어로 찾지 못하면 저장 실패인가요?

섹션 제목: “본문 단어로 찾지 못하면 저장 실패인가요?”

그렇다고 단정할 수 없습니다. 본문 추출이나 검색 정보 준비 상태가 영향을 줄 수 있습니다. 제목, URL, 메모로 찾아 실제 파일을 확인합니다. 동기화 중인 자료는 필요한 파일을 내려받은 뒤 다시 열어 확인합니다.
