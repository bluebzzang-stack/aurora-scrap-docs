이미지 글자 인식

이미지 글자 인식은 사진이나 캡처에 들어 있는 글자를 선택 가능한 텍스트로 변환하는 기능입니다. 앱에서는 텍스트 인식이라는 이름을 사용합니다. 현재 확인된 실행 위치는 콘텐츠 편집기에 삽입한 이미지의 도구입니다. 인식한 결과는 텍스트 복사로 가져와 메모나 문서에 붙여 넣을 수 있습니다. 이미지 안의 모든 문장이 항상 정확하게 변환되는 것은 아니므로 사용 전에 원본과 비교합니다.

이미지에서 글자 복사하기

섹션 제목: “이미지에서 글자 복사하기”
  1. 글자가 들어 있는 이미지 파일을 준비합니다. 스크린샷이나 사진처럼 글자 모양이 실제 이미지에 보여야 합니다. 흐리거나 잘린 부분은 인식 결과에도 영향을 줍니다.
  2. 새 콘텐츠를 만들거나 기존 콘텐츠를 엽니다. 자료를 보관할 워크스페이스와 카테고리를 확인합니다. 원본 이미지와 인식 결과를 같은 항목에서 비교할 수 있도록 배치하면 편리합니다.
  3. 이미지를 편집기에 드래그하거나 붙여 넣어 삽입합니다. 파일이 준비되고 이미지가 표시되는지 먼저 확인합니다. 다른 PC에서 만든 첨부는 내려받기가 끝나야 사용할 수 있습니다.
  4. 삽입한 이미지를 선택하여 이미지 도구를 표시합니다. 텍스트 인식을 누릅니다. 버튼이 인식 중… 상태일 때는 결과가 나올 때까지 기다립니다.
  5. 인식된 글자가 이미지 위에 표시되면 원본과 비교합니다. 제목, 숫자, 단위, 고유명사처럼 잘못 읽으면 의미가 바뀌는 부분을 먼저 확인합니다.
  6. 텍스트 복사를 누릅니다. 복사됨이 표시되면 콘텐츠 본문이나 메모에 붙여 넣습니다. 줄바꿈과 글자 오류를 다듬고 변경 내용을 저장합니다.

인터넷 연결과 운영체제 차이

섹션 제목: “인터넷 연결과 운영체제 차이”

Windows에서는 운영체제의 글자 인식 기능을 먼저 사용합니다. macOS에서는 Apple Vision을 먼저 사용합니다. 이런 운영체제 기능으로 처리할 수 있으면 이미지를 외부 인식 서버에 보내지 않고 로컬에서 처리합니다. 같은 이미지도 운영체제와 지원 언어에 따라 결과가 달라질 수 있습니다.

운영체제 기능을 사용할 수 없거나 결과를 얻지 못하면 공통 인식 엔진으로 다시 처리합니다. 이 엔진이 사용할 언어 자료를 처음 준비할 때 인터넷 연결이 필요할 수 있습니다. 따라서 첫 사용 전에 인터넷을 연결해 두면 필요한 자료를 준비할 수 있습니다. 매번 인터넷이 반드시 필요하다는 뜻은 아닙니다.

앱의 오류 문구에는 **텍스트 인식에 실패했습니다. 첫 사용 시 인터넷 연결이 필요합니다.**라고 표시될 수 있습니다. 이 문구만으로 모든 실패가 네트워크 문제라고 판단하지 않습니다. 이미지가 열리는지, 파일이 이 PC에 있는지, 글자가 충분히 선명한지 함께 확인합니다. 인식할 글자가 없는 이미지도 별도 안내가 나올 수 있습니다.

결과를 정리하여 활용하기

섹션 제목: “결과를 정리하여 활용하기”

인식 결과는 원본 이미지에 자동으로 정확한 문서 구조를 부여하는 기능이 아닙니다. 두 단으로 된 글, 표, 복잡한 배경에서는 읽는 순서나 줄바꿈이 원문과 다르게 나올 수 있습니다. 복사한 뒤 본문을 읽어 보며 문장 순서를 확인합니다. 표 안의 숫자는 행과 열이 맞는지도 확인합니다.

검색에 사용할 핵심 단어를 메모나 콘텐츠 본문에 남길 수 있습니다. 이미지 자체를 보관하는 것과 검색 가능한 글자를 저장하는 것은 별개의 작업입니다. 인식 버튼을 누른 사실만으로 모든 이미지의 글자가 영구 검색 색인에 자동 등록된다고 가정하지 않습니다. 활용할 결과를 실제 텍스트로 저장합니다.

원본을 지우기 전에 복사한 내용을 검토합니다. 특히 영문과 숫자가 섞인 코드, 날짜, 제품명, 주소는 비슷하게 보이는 글자가 바뀔 수 있습니다. 인식 결과를 그대로 다른 곳에 전달하기보다 원본과 대조한 문장을 사용합니다. 결과가 부정확하면 더 선명한 이미지로 다시 시도합니다.

인식이 잘되지 않을 때

섹션 제목: “인식이 잘되지 않을 때”
  1. 이미지가 정상으로 열리는지 확인합니다. 파일을 찾을 수 없다면 OCR보다 먼저 파일 내려받기나 첨부 문제를 해결합니다.
  2. 이미지의 글자가 충분히 큰지 확인합니다. 이미 작게 저장된 글자를 화면에서 확대하는 것만으로 원본 해상도가 높아지지는 않습니다.
  3. 불필요한 배경이 많거나 내용이 잘렸다면 글자를 온전히 포함한 캡처를 준비합니다. 내용을 지우거나 변형한 사본보다 읽을 수 있는 원본을 사용합니다.
  4. 첫 사용이거나 언어 자료가 준비되지 않은 환경이라면 인터넷을 연결하고 다시 실행합니다. 다른 이미지도 실패하는지 확인하면 파일 문제와 환경 문제를 구분하는 데 도움이 됩니다.

원본 이미지와 수정한 텍스트를 함께 둡니다

텍스트를 복사한 뒤에도 원본 이미지를 같은 콘텐츠에 남겨 두면 나중에 숫자와 표현을 다시 확인할 수 있습니다. 인식 결과를 수정했다면 원본과 구분되는 위치에 적습니다.

자주 묻는 질문

섹션 제목: “자주 묻는 질문”

사진첩에서 바로 인식 버튼을 찾을 수 없나요?

섹션 제목: “사진첩에서 바로 인식 버튼을 찾을 수 없나요?”

현재 확인된 텍스트 인식 도구는 콘텐츠에 삽입한 이미지에 있습니다. 사진첩의 이미지에서 사용할 때는 필요한 파일을 콘텐츠에 삽입하고 이미지 도구를 엽니다. 사진첩 전체를 자동 인식하는 기능으로 안내하지 않습니다.

macOS에서도 인터넷이 항상 필요한가요?

섹션 제목: “macOS에서도 인터넷이 항상 필요한가요?”

macOS에서는 Apple Vision을 먼저 사용하므로 항상 필요한 것은 아닙니다. 공통 인식 엔진으로 처리하면서 언어 자료를 처음 준비하는 경우에는 인터넷이 필요할 수 있습니다. 인식 실패 시 파일 상태도 함께 확인합니다.

복사한 텍스트가 자동으로 저장되나요?

섹션 제목: “복사한 텍스트가 자동으로 저장되나요?”

복사 동작은 클립보드에 텍스트를 넣습니다. 보관하려면 콘텐츠나 메모에 붙여 넣고 저장 상태를 확인합니다. 이후 다른 내용을 복사하면 클립보드가 바뀔 수 있으므로 필요한 결과는 바로 기록합니다.
