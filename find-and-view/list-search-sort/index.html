목록 검색과 정렬

목록 검색은 현재 워크스페이스의 자료를 찾는 기본 방법입니다. 카테고리와 라벨로 범위를 정한 뒤 검색어를 입력하고 자료 종류나 정렬을 바꿀 수 있습니다. 카드형 보기는 썸네일로 자료를 구분할 때 편리하며, 목록형 보기는 제목과 날짜를 비교할 때 사용합니다. 어떤 표시 방식을 선택해도 저장한 자료 자체는 바뀌지 않습니다.

현재 목록에서 찾기

섹션 제목: “현재 목록에서 찾기”
  1. 자료가 있는 워크스페이스를 선택합니다. 위치를 기억하면 카테고리를 열고, 같은 공간 전체를 확인하려면 전체 스크랩을 선택합니다.
  2. 목록의 검색 입력란을 누릅니다. Ctrl+F를 사용할 수도 있습니다. macOS에서는 Cmd+F를 사용합니다. 콘텐츠 편집 중에는 편집기의 찾기 기능과 구분하여 목록 검색창을 직접 확인합니다.
  3. 제목, URL, 메모처럼 기억하는 단어를 입력합니다. 입력란의 안내는 **제목, URL, 메모 검색…**입니다. 결과를 보면서 너무 긴 문장 대신 구분하기 쉬운 단어로 조정합니다.
  4. 자료 종류가 분명하면 타입 필터를 선택합니다. 예를 들어 사진첩을 찾을 때는 사진첩, 작성한 문서를 찾을 때는 콘텐츠로 범위를 줄입니다.
  5. 결과에서 항목을 선택하여 미리보기를 확인합니다. 같은 제목의 항목이 여러 개면 저장일이나 원본 URL을 비교합니다.
  6. 결과가 없으면 검색어와 라벨 및 타입 필터를 차례로 해제합니다. 다른 워크스페이스까지 찾아야 한다면 통합검색을 사용합니다.

자료 종류 필터

섹션 제목: “자료 종류 필터”
필터 확인할 자료 사용할 때 참고할 점
전체 현재 범위의 모든 종류입니다 검색어나 카테고리 조건은 별도로 적용됩니다
웹페이지 웹에서 저장한 페이지입니다 저장 형식은 항목별로 다를 수 있습니다
동영상 동영상으로 저장된 자료입니다 웹페이지에 영상이 보인다는 사실과 구분합니다
오디오 오디오로 저장된 자료입니다 MP3로 저장한 항목 등을 찾습니다
콘텐츠 직접 작성하거나 텍스트에서 만든 문서입니다 편집기에서 내용을 확인합니다
문서 문서 파일로 가져온 자료입니다 미리보기 가능 여부는 파일 형식에 따라 다릅니다
이미지 이미지 자료입니다 사진첩 내부의 개별 사진 목록과 구분합니다
사진첩 여러 이미지를 묶은 항목입니다 사진첩을 열면 내부 이미지가 표시됩니다
아이디어 아이디어 보드입니다 보드의 페이지와 요소를 열어 확인합니다

타입 필터는 저장된 자료의 종류를 기준으로 구분합니다. 제목에 특정 단어가 있다는 이유만으로 해당 종류가 되지는 않습니다. 예를 들어 제목에 사진첩이라는 단어가 들어 있어도 실제로 만든 항목이 콘텐츠라면 콘텐츠에서 찾습니다. 어떤 종류인지 모르면 먼저 전체에서 검색합니다.

정렬 기준 선택하기

섹션 제목: “정렬 기준 선택하기”
기준 의미 활용 방법
저장일 앱에 보관한 날짜입니다 최근 추가한 자료를 확인합니다
조회수 앱에서 자료를 열람한 횟수입니다 자주 보는 항목을 확인합니다
발행일 원본에서 수집한 발행 날짜입니다 원문이 발표된 시점을 비교합니다
제목 항목의 제목입니다 이름을 기준으로 자료를 찾습니다

정렬 기준과 방향 표시를 함께 확인합니다. 같은 기준을 사용해도 방향에 따라 오래된 자료나 최근 자료가 먼저 나올 수 있습니다. 발행일을 제공하지 않는 페이지에는 해당 정보가 없을 수 있습니다. 저장일과 발행일이 다르다고 해서 캡처 날짜가 잘못된 것은 아닙니다.

조회수는 항목 열람을 추적하기 위한 값입니다. 상세정보에서 조회 횟수와 최종 조회 정보를 확인할 수 있습니다. 이 숫자는 원본 사이트 방문자 수나 웹페이지의 인기도가 아닙니다. 자주 읽는 자료를 정리할 때 조회수로 비교하고, 바로 접근할 항목에는 좋아요를 붙일 수 있습니다.

카드와 목록 전환하기

섹션 제목: “카드와 목록 전환하기”

목록 위의 카드형 보기와 목록형 보기 버튼으로 표시 방식을 바꿉니다. 카드에서는 이미지나 페이지의 시각적 특징을 사용하여 자료를 찾습니다. 목록에서는 제목과 날짜를 연속해서 비교합니다. 제목이 길어 잘리면 설정 > 목록의 제목 풍선도움말 설정도 확인합니다.

표시 모드를 바꾼 다음에도 검색어와 선택한 분류를 확인합니다. 보기 전환은 전체 워크스페이스를 다시 검색하는 기능이 아닙니다. 기대한 자료가 없다면 현재 조건부터 살펴봅니다. 자료를 지우거나 다시 저장하기 전에 검색 범위를 확인하면 불필요한 중복 저장을 줄일 수 있습니다.

많은 항목 불러오기

섹션 제목: “많은 항목 불러오기”
  1. 설정 > 목록에서 목록 표시 방식을 확인합니다. 무한 스크롤은 아래로 내려가면 다음 항목을 이어서 불러옵니다.
  2. 페이지네이션은 페이지 번호로 이동하는 방식입니다. 목록 아래의 현재 페이지와 전체 페이지 정보를 보고 이동합니다.
  3. 페이지당 목록 수를 조정하여 한 번에 확인할 양을 정합니다. 이 값은 저장 가능한 스크랩 총수를 제한하는 설정이 아닙니다.
  4. 다중 선택 작업을 할 때는 불러온 범위와 선택 개수를 확인합니다. 화면 아래에 더 많은 결과가 남아 있을 수 있습니다.

검색이 안 될 때는 범위부터 확인합니다

현재 카테고리, 타입, 라벨, 검색어를 함께 확인합니다. 조건을 하나씩 풀면서 항목이 나타나는지 살펴본 뒤, 필요한 조건만 다시 적용합니다. 저장 위치를 모르면 통합검색으로 전환합니다.

자주 묻는 질문

섹션 제목: “자주 묻는 질문”

검색창에 본문 단어를 넣어도 되나요?

섹션 제목: “검색창에 본문 단어를 넣어도 되나요?”

저장된 본문 색인을 사용한 검색도 수행합니다. 다만 본문이 추출되지 않았거나 해당 파일을 아직 확인할 수 없는 자료는 본문 검색이 제한될 수 있습니다. 제목과 메모 같은 단서로 먼저 찾고, 다른 공간까지 찾을 때는 통합검색을 사용합니다.

검색 결과 총수와 현재 보이는 카드 수가 다른가요?

섹션 제목: “검색 결과 총수와 현재 보이는 카드 수가 다른가요?”

무한 스크롤이나 페이지네이션으로 일부 항목만 불러왔을 수 있습니다. 아래로 더 내려가거나 다음 페이지를 확인합니다. 총수와 현재 표시 범위 및 선택된 개수는 서로 다른 값입니다.

조회수를 기준으로 정렬하면 원본 사이트 인기순인가요?

섹션 제목: “조회수를 기준으로 정렬하면 원본 사이트 인기순인가요?”

아닙니다. 앱에서 열람한 기록을 기준으로 정렬합니다. 원본의 조회수나 검색 서비스 순위를 가져오는 기능은 아닙니다. 자신의 자료 이용 빈도를 확인하는 용도로 사용합니다.
