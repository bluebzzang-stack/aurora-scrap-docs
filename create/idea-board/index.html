아이디어 보드

아이디어 보드는 텍스트와 도형을 자유로운 위치에 배치하는 화이트보드입니다. 펜으로 그리거나 스티커 메모를 붙이고, 연결선으로 관계를 표현할 수 있습니다. 표와 이미지를 함께 놓고 여러 페이지로 나누어 정리할 수도 있습니다. 문단 순서대로 글을 작성하는 콘텐츠 에디터와 달리 위치와 연결 관계를 직접 구성하며, 변경 후 화면의 저장 상태를 확인합니다.

첫 보드 만들기

섹션 제목: “첫 보드 만들기”
  1. 자료를 보관할 워크스페이스와 카테고리를 선택합니다. 파일 메뉴나 빈 목록의 새 아이디어에서 시작합니다.
  2. 아이디어 만들기 화면이 나타나면 제목과 카테고리를 확인하고 생성을 누릅니다. 새 콘텐츠·아이디어 간편 실행을 켜 두었다면 바로 보드를 생성합니다.

화이트보드를 열기 전 아이디어의 기본 정보를 정하는 생성 화면입니다. 보드 도구와 마인드맵은 생성 후 화면에 나타납니다.

  1. 하단 도구에서 텍스트나 스티커 메모를 선택하고 보드에 놓습니다. 제목이나 생각을 짧게 입력합니다. 텍스트 입력 중에는 글자 입력과 도구 단축키가 구분됩니다.
  2. 도형을 선택하여 필요한 모양을 고릅니다. 보드에 놓은 뒤 크기와 위치를 조정합니다. 연결할 대상들이 구분되도록 간격을 둡니다.
  3. 연결선을 사용하여 두 요소를 연결합니다. 시작점과 끝점이 의도한 요소에 붙었는지 확인합니다.
  4. 저장됨 표시를 확인합니다. 전체 보기로 보드 전체를 살펴보고, 필요한 경우 페이지를 추가하여 내용을 나눕니다.

도구와 작성 방법

섹션 제목: “도구와 작성 방법”

기본 도구 모음은 다음 11개 도구를 제공합니다. 마인드맵은 텍스트 도구의 하위 모드이고, 이미지는 파일을 보드에 놓아 추가합니다. 따라서 마인드맵과 이미지 작업도 사용할 수 있지만 별도의 기본 도구 버튼 13개가 있는 구성은 아닙니다.

도구 키 용도
선택 V 요소를 선택하고 위치와 크기를 바꿉니다
이동 H 보드를 이동하여 다른 영역을 봅니다
펜 M 자유롭게 선을 그립니다
형광펜 I 강조할 부분을 그립니다
지우개 E 그린 내용을 정리할 때 사용합니다
스티커 메모 S 짧은 내용을 색상 메모로 배치합니다
도형 O 여러 종류의 도형을 만듭니다
연결선 C 요소 사이의 관계를 연결합니다
텍스트 T 일반 텍스트 또는 마인드맵을 만듭니다
표 Shift+T 셀에 내용을 입력하여 정리합니다
섹션 Shift+S 관련 요소를 구역으로 묶어 표시합니다

도형 목록에는 사각형, 둥근 사각형, 원, 마름모, 평행사변형, 삼각형, 육각형, 원통, 문서가 있습니다. 모양은 내용의 역할을 구분하는 데 사용합니다. 도형 안의 텍스트와 별도 텍스트 요소를 섞어 배치할 수 있습니다. 같은 역할에는 같은 모양을 사용하면 관계를 읽기 쉽습니다.

마인드맵 만들기

섹션 제목: “마인드맵 만들기”
  1. 텍스트 도구의 하위 선택에서 마인드맵을 고릅니다. 보드에 놓으면 중심 주제와 기본 가지를 작성할 수 있습니다.
  2. 질문 또는 주제를 자신의 중심 내용으로 바꾸고 기본 가지의 텍스트도 수정합니다. 보이는 예시 단어를 그대로 둘 필요는 없습니다.
  3. 가지를 선택하고 마인드맵에 자식 추가를 사용하면 하위 내용을 추가합니다. Ctrl+Enter를 사용할 수도 있습니다. macOS에서는 Cmd+Enter를 사용합니다.
  4. 같은 단계의 내용을 추가하려면 같은 레벨에 추가를 사용합니다. 선택한 마인드맵 노드에서는 Tab 또는 Enter로 같은 단계의 노드를 추가할 수 있습니다.
  5. 글자를 입력 중일 때와 노드를 선택한 상태를 구분합니다. 새로운 노드가 생긴 위치와 연결된 부모를 확인한 뒤 다음 내용을 입력합니다.

텍스트를 상자 안에 넣고 싶으면 선택 후 도형으로 바꾸기를 사용합니다. 모양을 바꾼 다음 연결 관계가 원하는 내용인지 확인합니다. 단순한 가지 목록에서 시작한 보드도 도형의 의미를 정하여 흐름이나 관계 설명으로 구성할 수 있습니다.

연결선, 핸들과 자석

섹션 제목: “연결선, 핸들과 자석”

연결선을 선택하면 끝점이나 경로를 조절하는 핸들이 표시됩니다. 핸들은 선의 위치를 바꾸는 작은 조절점입니다. 끝점을 다른 도형으로 옮기면 해당 대상에 다시 연결할 수 있습니다. 도형 가장자리의 붙는 위치를 확인한 뒤 마우스를 놓습니다.

도형의 측면 중간 가까이에 끝점을 가져가면 자석처럼 붙는 위치를 안내합니다. 바깥선 위의 다른 위치에도 연결점을 둘 수 있습니다. 단순히 화면상 선이 겹쳐 있는 것과 도형에 붙어 있는 연결은 다릅니다. 연결한 도형을 조금 움직여 선이 의도한 대상을 따라가는지 확인합니다.

경로는 직선, 꺾인 선, 구부러진 선, 곡선 중에서 선택합니다. 화살촉은 화살촉 없음, 시작 화살촉, 끝 화살촉, 양쪽 화살촉으로 정합니다. 화살촉 모양에는 삼각형, 선, 원, 사각형이 있습니다. 방향을 설명해야 하는 관계는 시작점과 끝점을 바르게 구분합니다.

연결선의 라벨에는 관계를 설명하는 짧은 글을 적을 수 있습니다. 점선이나 선 색, 선 굵기를 사용하여 구분할 수도 있습니다. 색상만으로 다른 의미를 전달하기보다 라벨을 함께 사용합니다. 선이 많아 복잡해지면 도형 위치를 조정하거나 페이지를 나눕니다.

표와 이미지

섹션 제목: “표와 이미지”

표를 놓고 셀에 글을 입력합니다. 행 추가, 열 추가로 크기를 늘리고, 선택한 행이나 열을 삭제할 수 있습니다. 행과 열의 조절 부분을 드래그하면 순서를 바꿉니다. 셀 범위를 선택하면 셀 병합과 셀 분할을 사용할 수 있습니다. 표 전체 선택과 셀 선택을 구분하여 작업합니다.

행이나 열을 삭제하기 전에는 해당 줄에 필요한 내용이 있는지 확인합니다. 셀 하나의 글을 수정하려는 경우에는 그 셀을 편집합니다. 표를 이동하려는 작업에서 실수로 행 순서가 바뀌지 않도록 선택 표시를 확인합니다. 비교할 항목의 수가 늘면 보드 전체 배치도 다시 정리합니다.

이미지 파일은 보드로 드래그하여 넣습니다. 배치한 뒤 크기와 위치를 조정하고 이미지 설명을 남길 수 있습니다. 지원되는 이미지 첨부에는 보드에 삽입 동작도 사용할 수 있습니다. 이미지 안의 글자와 보드의 텍스트 요소는 다르므로 검색할 핵심 설명은 별도의 텍스트로 적습니다.

속성 바와 임시 선택

섹션 제목: “속성 바와 임시 선택”

요소를 선택하면 그 종류에 맞는 속성 바가 나타납니다. 선 색, 선 굵기, 채우기 색, 글자 크기, 굵게, 정렬 등을 조절합니다. 지원되는 속성은 선택한 요소에 따라 달라집니다. 여러 속성을 바꾼 뒤 텍스트가 배경과 구분되는지 확인합니다.

복제는 비슷한 요소를 추가할 때 사용합니다. 맨 앞으로와 맨 뒤로는 겹친 요소의 표시 순서를 정합니다. 잠금을 사용하면 배치한 요소를 보호할 수 있고 다시 수정할 때는 잠금 해제를 사용합니다. 섹션은 섹션 색을 정하고 내용에 맞춰 크기 조절을 사용할 수 있습니다.

다른 도구를 사용하다가 잠깐 요소를 옮기려면 Ctrl을 누르는 동안 선택 도구로 전환합니다. macOS에서는 Cmd를 사용합니다. 키를 놓으면 원래 고른 도구로 돌아갑니다. 텍스트 입력 중에는 문자 편집을 우선하므로 먼저 입력을 마친 뒤 보드에서 조작합니다.

줌과 페이지 관리

섹션 제목: “줌과 페이지 관리”

확대, 축소, 100%로 맞추기로 배율을 조절합니다. Ctrl과 마우스 휠로 확대하거나 축소할 수도 있습니다. macOS에서는 Cmd와 마우스 휠을 사용합니다. 전체 구성을 확인하려면 전체 보기를 사용합니다. 배율이 작아져 요소가 안 보이면 삭제하기 전에 전체 보기를 확인합니다.

아래 페이지 탭에서 페이지 추가를 누르면 새 페이지를 만듭니다. 탭을 클릭하여 전환하고, 더블클릭하여 이름을 바꿉니다. 탭을 길게 누른 뒤 드래그하면 순서를 정리할 수 있습니다. 페이지를 삭제할 때는 해당 페이지 내용을 확인합니다. 서로 다른 주제는 페이지 이름으로 구분합니다.

읽기 실패 상태에서 빈 보드를 저장하지 않습니다

보드를 열지 못했습니다가 표시되면 원본을 보호하기 위해 편집과 저장을 막습니다. 앱을 다시 열어 보고 파일이나 동기화 상태를 확인합니다. 모두 지우기는 보드 내용을 지우는 작업이므로 문제 해결용으로 사용하지 않습니다.

자주 묻는 질문

섹션 제목: “자주 묻는 질문”

펜을 사용하다가 도형을 옮기려면 어떻게 하나요?

섹션 제목: “펜을 사용하다가 도형을 옮기려면 어떻게 하나요?”

선택을 누르거나 Ctrl을 누르는 동안 임시 선택을 사용합니다. macOS에서는 Cmd를 누릅니다. 이동을 마친 뒤 키를 놓으면 기존 도구로 돌아가므로 현재 선택된 도구 표시를 확인합니다.

연결선 끝이 도형에 붙었는지 어떻게 확인하나요?

섹션 제목: “연결선 끝이 도형에 붙었는지 어떻게 확인하나요?”

끝점을 놓을 때 대상 도형의 강조와 부착점 표시를 확인합니다. 연결한 뒤 도형을 조금 움직여 관계가 유지되는지 살펴봅니다. 의도한 대상을 따라가지 않으면 끝점 핸들로 다시 연결합니다.

아이디어 내용을 통합검색으로 찾을 수 있나요?

섹션 제목: “아이디어 내용을 통합검색으로 찾을 수 있나요?”

보드의 표시 텍스트와 표 셀, 페이지 이름을 검색에 사용합니다. 이미지 속 글자와 첨부 파일 경로가 같은 방식으로 검색되는 것은 아닙니다. 나중에 찾을 핵심 단어를 텍스트나 메모로 남깁니다.
