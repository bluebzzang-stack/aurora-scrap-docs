사진첩

사진첩은 여러 이미지 파일을 하나의 항목으로 보관하는 기능입니다. 파일을 개별 스크랩으로 늘어놓는 대신 같은 주제의 이미지를 묶어 볼 수 있습니다. 사진첩을 만든 뒤 파일이나 폴더를 추가하고, 썸네일 크기와 정렬을 조절합니다. 필요한 이미지는 크게 열어 보거나 다른 사진첩으로 옮기고, 한 개 또는 ZIP 파일로 내려받을 수 있습니다.

사진첩 만들고 이미지 추가하기

섹션 제목: “사진첩 만들고 이미지 추가하기”
  1. 새 사진첩을 선택합니다. 파일 메뉴나 빈 목록의 생성 버튼에서 시작할 수 있습니다. 보관할 워크스페이스를 먼저 선택합니다.
  2. 사진첩 만들기 화면에서 제목을 입력하고 카테고리를 선택합니다. 필요한 경우 **설명 (선택)**에 이미지 묶음의 목적을 적습니다.

사진을 추가하기 전 사진첩의 기본 정보를 정하는 생성 화면입니다. 이미지 그리드와 선택 작업 버튼은 생성 후 화면에 나타납니다.

  1. 생성을 누릅니다. 만든 사진첩을 열고 상단의 이미지 추가를 눌러 파일을 선택합니다. 파일 수가 많으면 추가 진행 상태를 확인합니다.
  2. 이미지가 모여 있는 폴더를 가져오려면 폴더 추가를 사용합니다. 사진첩 안으로 이미지 파일이나 폴더를 드래그해도 추가할 수 있습니다.
  3. 작업이 끝나면 이미지 개수와 썸네일을 확인합니다. 이미 있는 이미지나 지원하지 않는 형식을 제외했다는 안내가 나오면 추가한 전체 파일 수와 결과가 다른 이유를 확인합니다.
  4. 임의의 이미지 한 장을 열어 실제 내용을 확인합니다. PSD와 AI는 PNG 변환본으로 추가되므로 편집 가능한 원본도 보관해야 한다면 일반 파일 가져오기를 별도로 사용합니다.

형식과 표시 옵션

섹션 제목: “형식과 표시 옵션”
항목 지원 내용 사용할 때 참고할 점
일반 이미지 PNG, JPG, JPEG, GIF, WEBP, BMP, AVIF입니다 파일이 정상 표시되는지 확인합니다
SVG 벡터 이미지 파일을 추가합니다 앱은 벡터 편집 프로그램을 대신하지 않습니다
PSD 파일에 내장된 합성 이미지를 PNG로 변환하여 추가합니다 사진첩에 편집 가능한 PSD 원본을 함께 보관하지 않습니다
AI PDF 호환 파일의 첫 페이지를 PNG로 변환하여 추가합니다 사진첩에 편집 가능한 AI 원본을 함께 보관하지 않습니다
이미지 추가 선택한 이미지 파일을 넣습니다 여러 파일을 선택할 수 있습니다
폴더 추가 폴더 안의 이미지 자료를 추가합니다 이미지가 없으면 안내가 표시됩니다
썸네일 크기 그리드의 이미지 표시 크기를 조절합니다 원본 해상도는 바뀌지 않습니다
이름 파일 이름을 기준으로 정렬합니다 비슷한 파일을 연속해서 확인합니다
날짜 파일 수정일을 기준으로 정렬합니다 EXIF 촬영일과 파일 수정일을 혼동하지 않습니다
크기 파일 크기를 기준으로 정렬합니다 큰 파일을 확인할 때 사용합니다

정렬 기준을 선택할 때 방향도 함께 확인합니다. 이미지 이름이 비슷하면 크게 열어 내용을 비교합니다. 정렬은 그리드의 표시 순서를 정하며 다른 사진첩으로 옮기는 기능은 아닙니다. 자료를 나누려면 선택 이동을 사용합니다.

여러 이미지 선택하기

섹션 제목: “여러 이미지 선택하기”

썸네일의 선택 표시로 작업할 이미지를 고릅니다. 선택한 상태에서 상단에 표시되는 삭제, 이동, 다운로드의 개수를 확인합니다. 이미지를 크게 여는 클릭과 선택 표시를 바꾸는 클릭을 구분합니다. 많은 사진을 선택한 경우 작업 전에 처음과 마지막 대상을 다시 확인합니다.

이동을 누르면 워크스페이스 선택, 카테고리 선택, 사진첩 선택 순서로 목적지를 정합니다. 기존 사진첩을 고르거나 새 사진첩으로 이동을 사용할 수 있습니다. 같은 제목의 사진첩이 여러 공간에 있으면 워크스페이스와 카테고리를 함께 확인합니다. 이동 후 목적지 사진첩에서 결과를 확인합니다.

하나의 이미지를 내려받을 때는 다운로드를 사용합니다. 여러 이미지를 선택하면 ZIP 다운로드로 묶어 저장합니다. 저장 위치를 선택한 뒤 완료 안내를 확인합니다. ZIP은 선택한 이미지를 전달하거나 따로 보관할 때 사용하며, 사진첩 전체 설정을 다른 앱으로 옮기는 기능으로 이해하지 않습니다.

이미지 크게 보기와 정보 확인

섹션 제목: “이미지 크게 보기와 정보 확인”
  1. 이미지를 열어 큰 보기 화면을 표시합니다. 좌우 방향키로 이전 또는 다음 이미지를 확인합니다. Esc를 누르면 큰 보기를 닫습니다.
  2. Ctrl과 마우스 휠로 확대하거나 축소합니다. macOS에서는 Cmd와 마우스 휠을 사용합니다. Ctrl+더하기와 Ctrl+빼기 키도 사용할 수 있으며 macOS에서는 Cmd를 사용합니다.
  3. 배율 표시를 누르거나 Ctrl+0으로 화면에 맞춥니다. macOS에서는 Cmd+0을 사용합니다. 확대된 이미지는 Space를 누른 채 드래그하여 이동합니다.
  4. 이미지 정보를 눌러 파일명, 형식, 해상도, 용량, 수정일과 경로를 확인합니다. 원본의 크기와 앱에서 표시하는 크기를 구분합니다.
  5. EXIF 정보가 있는 사진은 카메라, 렌즈, 촬영 일시, 노출 등의 정보를 확인합니다. 위치 정보를 포함한 사진은 그 정보도 표시될 수 있습니다.

EXIF는 사진 파일에 들어 있는 촬영 정보입니다. 모든 이미지가 이 정보를 포함하지는 않습니다. **이 이미지에는 EXIF 정보가 없습니다.**라는 안내는 사진첩에 추가하지 못했다는 뜻이 아닙니다. 캡처 이미지나 편집하여 저장한 파일에는 촬영 정보가 없을 수 있습니다.

중복과 많은 이미지 처리

섹션 제목: “중복과 많은 이미지 처리”

같은 이름과 같은 파일 크기의 이미지가 있으면 중복으로 보고 제외합니다. 이미 있는 이미지 안내가 나오면 같은 자료를 다시 추가했는지 확인합니다. 이름이 같아도 크기가 다르면 다른 이름으로 보관합니다. 이미지 내용을 정밀 비교하는 기능은 아니므로 서로 다른 파일인데 이름과 크기가 같다면 추가 결과를 직접 확인합니다.

설정 > 목록 > 사진첩 목록 갯수는 한 번에 표시할 이미지 수를 정합니다. 그보다 많은 이미지는 스크롤하면 이어서 불러옵니다. 화면에 더 보기가 표시되면 남은 이미지를 추가로 확인할 수 있습니다. 처음 표시된 썸네일 개수가 사진첩 전체 이미지 개수와 같다고 판단하지 않습니다.

개별 이미지 삭제 전에 대상을 확인합니다

사진첩의 이미지 삭제와 사진첩 항목 자체를 휴지통으로 보내는 작업은 구분합니다. 필요한 원본은 내려받아 확인한 뒤 삭제합니다. 큰 보기에서 확인한 이미지와 체크박스로 선택한 이미지가 같은지 살펴봅니다.

자주 묻는 질문

섹션 제목: “자주 묻는 질문”

PSD와 AI도 수정할 수 있나요?

섹션 제목: “PSD와 AI도 수정할 수 있나요?”

사진첩에는 PSD의 합성 이미지와 AI의 첫 페이지를 PNG로 변환해 추가합니다. 편집 가능한 원본은 사진첩에 함께 복사하지 않습니다. 원본이 필요하면 일반 파일 가져오기를 사용하거나 별도로 보관합니다. 합성 이미지가 없는 PSD나 PDF 호환으로 저장하지 않은 AI는 추가되지 않을 수 있습니다.

폴더를 추가했는데 이미지 수가 적나요?

섹션 제목: “폴더를 추가했는데 이미지 수가 적나요?”

중복 이미지나 지원하지 않는 형식을 제외했을 수 있습니다. 추가 완료 안내를 확인합니다. 목록 표시 수 제한으로 일부만 보일 수도 있으므로 아래로 스크롤하거나 더 보기를 확인합니다.

이미지의 글자도 복사할 수 있나요?

섹션 제목: “이미지의 글자도 복사할 수 있나요?”

글자 인식은 콘텐츠에 삽입한 이미지 도구에서 사용할 수 있습니다. 필요한 이미지를 콘텐츠에 넣고 텍스트 인식을 실행합니다. 사진첩 전체를 자동으로 텍스트 변환하는 기능은 아닙니다.
