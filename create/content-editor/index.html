콘텐츠 에디터

콘텐츠 에디터는 직접 작성한 글과 이미지, 표, 영상, 첨부파일을 하나의 항목에 보관합니다. 회의록이나 자료 정리 문서를 만들고 여러 페이지로 나누어 편집할 수 있습니다. 입력 내용은 자동으로 저장하며 화면에서 저장됨 상태를 확인합니다. 웹페이지를 캡처하는 기능과 달리 자신이 작성하는 문서이므로 제목, 본문, 첨부를 필요에 맞게 수정합니다.

문서 만들기

섹션 제목: “문서 만들기”
  1. 대상 워크스페이스와 카테고리를 선택합니다. 파일 메뉴나 빈 목록에서 새 콘텐츠를 누릅니다. 상단의 콘텐츠 작성 진입점도 사용할 수 있습니다.
  2. 생성 화면이 나타나면 제목, **설명 (선택)**과 카테고리를 확인하고 생성을 누릅니다. 간편 실행이 켜져 있으면 생성 화면 대신 문서를 바로 만듭니다.

콘텐츠 편집기를 열기 전 새 문서의 기본 정보를 정하는 생성 화면입니다. 서식 도구와 본문은 생성 후 화면에 나타납니다.

  1. 본문을 클릭하고 내용을 입력합니다. 문서의 큰 구분은 제목 1, 하위 구분은 제목 2나 제목 3을 사용합니다. 글자 크기만 키우는 것과 제목 블록을 사용하는 것은 다릅니다.
  2. 필요한 표, 이미지와 첨부를 추가합니다. 문서가 길어지면 소제목이나 페이지를 나누어 정리합니다. 현재 편집 중인 페이지를 확인합니다.
  3. 저장됨 표시를 확인합니다. 저장 실패가 표시되면 성공한 것으로 가정하지 말고 저장 공간이나 동기화 상태를 확인합니다.
  4. 다른 항목을 열었다가 돌아와 제목과 본문이 유지되는지 확인합니다. 외부에 전달할 문서라면 마지막에 내보낸 파일도 열어 확인합니다.

서식과 블록

섹션 제목: “서식과 블록”
도구 기능 사용하는 방법
굵게, 기울임, 밑줄, 취소선 글자의 강조를 바꿉니다 적용할 글자를 선택하고 누릅니다
글꼴, 글자 크기 글자 모양과 크기를 고릅니다 제목 블록과 일반 글자를 구분합니다
글씨 색상, 하이라이트 글자와 강조 색을 정합니다 읽기 쉬운 대비를 확인합니다
아래 첨자, 위 첨자 작은 첨자를 넣습니다 수식 전체가 필요하면 수식 도구를 사용합니다
제목 1, 제목 2, 제목 3 문서의 구획을 만듭니다 목차에도 활용합니다
글머리 기호, 번호 목록 관련 내용을 목록으로 적습니다 순서가 필요하면 번호 목록을 사용합니다
체크리스트 완료 여부를 표시하는 항목입니다 체크박스와 본문을 함께 입력합니다
인용, 코드 블록 인용문이나 코드 내용을 구분합니다 일반 문단과 다른 블록으로 표시합니다
접기 블록 일부 내용을 접어 정리합니다 필요한 구간만 펼쳐 읽습니다
텍스트 정렬 왼쪽, 가운데, 오른쪽으로 맞춥니다 선택한 글이나 블록에 적용합니다
서식 지우기 적용된 서식을 정리합니다 내용 자체를 삭제하는 작업과 구분합니다
실행 취소, 다시 실행 최근 편집을 되돌리거나 다시 적용합니다 결과를 보며 한 단계씩 확인합니다

체크리스트는 할 일을 적고 완료 상태를 표시할 때 사용합니다. 항목의 들여쓰기를 바꾸면 하위 항목을 구성할 수 있습니다. 일반 글머리 목록과 체크리스트를 구분하여 선택합니다. 체크박스가 필요한 목록을 일반 문자 기호로 만드는 것보다 실제 체크리스트 도구를 사용하면 상태를 관리하기 쉽습니다.

슬래시 명령과 템플릿

섹션 제목: “슬래시 명령과 템플릿”

빈 문단에서 /를 입력하면 넣을 수 있는 블록 목록을 엽니다. 텍스트, 제목, 목록, 표, 접기 블록, 수식과 다이어그램 등을 선택할 수 있습니다. 입력한 조건과 일치하는 블록이 없으면 안내가 표시됩니다. 필요한 메뉴를 찾지 못하면 입력을 지우고 전체 목록을 다시 확인합니다.

정보 콜아웃, 경고 콜아웃, 팁 콜아웃은 문서의 안내를 별도 블록으로 표시합니다. 회의록 템플릿은 일시, 참석자, 안건, 결정 사항과 할 일을 정리할 때 사용합니다. 일지 템플릿은 오늘 한 일, 배운 점, 내일 할 일을 기록할 때 사용합니다. 템플릿을 삽입한 뒤 자신의 내용으로 채웁니다.

표, 수식과 다이어그램

섹션 제목: “표, 수식과 다이어그램”

테이블 삽입으로 표를 넣습니다. 표 안에서 오른쪽에 열 추가, 왼쪽에 열 추가, 아래에 행 추가, 위에 행 추가를 사용하여 크기를 늘립니다. 필요 없는 부분은 행 삭제나 열 삭제로 정리합니다. 셀을 묶으려면 셀 병합, 다시 나누려면 셀 분할을 사용합니다. 테이블 삭제는 표 전체를 대상으로 합니다.

수식은 인라인 수식과 수식 블록으로 넣습니다. 인라인 수식은 문장 사이에 표시하고 수식 블록은 독립된 구간에 표시합니다. 입력창에는 LaTeX 형식의 수식을 넣습니다. 복잡한 수식은 표시 결과를 확인하여 기호와 첨자 위치가 의도한 대로 나오는지 살펴봅니다.

다이어그램은 Mermaid 형식으로 작성한 내용을 그림으로 표시합니다. 표시된 다이어그램을 더블클릭하면 내용을 편집합니다. 사용할 문법을 입력한 뒤 실제 렌더링 결과와 연결 방향을 확인합니다. 복잡한 관계는 여러 도형을 한꺼번에 추가하기보다 일부를 먼저 표시하여 확인합니다.

이미지, 영상과 YouTube

섹션 제목: “이미지, 영상과 YouTube”

이미지는 파일을 드래그하거나 클립보드에서 붙여 넣어 삽입합니다. 삽입한 이미지를 선택하면 이미지 도구를 사용할 수 있습니다. 텍스트 인식으로 이미지 속 글자를 복사할 수도 있습니다. 문서 안에 놓은 이미지와 첨부 목록의 원본 파일을 구분하여 관리합니다.

영상과 오디오 파일을 삽입하면 본문에서 재생할 수 있습니다. 파일을 추가하는 동안 다른 페이지로 이동하기보다 삽입 결과를 먼저 확인합니다. 원격 주소를 사용하는 미디어는 네트워크 상태의 영향을 받을 수 있습니다. 오프라인에서 읽을 문서는 실제 파일이 저장되었는지 확인합니다.

YouTube 영상 삽입을 누르고 YouTube URL을 입력하면 문서에 영상을 넣을 수 있습니다. 이는 MP4 파일을 내려받아 보관하는 동작과 같지 않습니다. 외부 영상 재생에는 인터넷 연결이나 서비스 접근이 필요할 수 있습니다. 영상 파일 저장이 목적이면 동영상 다운로드 기능을 별도로 사용합니다.

화면 캡처와 손그림

섹션 제목: “화면 캡처와 손그림”
  1. 캡처를 넣을 본문 위치를 선택합니다. 화면 캡처 삽입을 눌러 필요한 화면을 캡처합니다. macOS에서는 화면 기록 권한이 필요할 수 있으므로 안내를 확인합니다.
  2. 캡처 결과가 본문에 들어오면 글자가 읽히는지 확인합니다. 다른 자료를 설명하는 캡처라면 바로 아래에 관련 설명을 적습니다.
  3. 손그림을 넣으려면 드로잉을 엽니다. 그리기 화면에서 필요한 표시를 작성하고 지우개나 모두 지우기로 수정합니다.
  4. 삽입을 눌러 결과를 문서에 넣습니다. 별도의 아이디어 보드처럼 여러 도형 관계를 계속 편집해야 하는 작업은 새 아이디어를 검토합니다.

회의 녹음과 첨부

섹션 제목: “회의 녹음과 첨부”

회의 녹음을 누르면 연결된 마이크를 사용하여 녹음을 시작합니다. 녹음이 끝나면 녹음 중지를 누릅니다. 녹음은 첨부파일로 저장되며 완료 안내를 확인할 수 있습니다. 마이크를 사용할 수 없다는 안내가 나오면 연결 상태와 운영체제 권한을 확인합니다.

녹음 중 다른 항목으로 이동하려 하면 녹음을 중지하고 지금까지 분량을 저장한다는 확인이 표시됩니다. 필요한 녹음이 끝났는지 판단한 뒤 이동합니다. 녹음 저장과 자동 음성 전사는 다른 기능입니다. 녹음했다고 회의 내용이 자동으로 문서에 받아쓰기되는 것으로 이해하지 않습니다.

첨부파일 목록에서는 파일을 열고 지원되는 항목을 본문에 삽입할 수 있습니다. 삭제할 때는 확인 문구를 읽습니다. 본문에 삽입된 첨부를 삭제하면 해당 본문 요소도 함께 지워질 수 있습니다. 개별 첨부파일 삭제는 휴지통을 거치지 않으므로 필요한 파일은 먼저 보관합니다.

찾기, 바꾸기와 목차

섹션 제목: “찾기, 바꾸기와 목차”

찾기를 열고 현재 편집하는 문서에서 단어를 찾습니다. 이전 찾기와 다음 찾기로 일치한 위치를 확인합니다. 수정이 필요하면 바꾸기를 사용하고, 같은 표현 전체를 수정할 때만 모두 바꾸기를 사용합니다. 다른 뜻으로 사용한 같은 단어까지 바뀌지 않는지 먼저 살펴봅니다.

목차는 제목 블록을 기준으로 긴 글을 이동할 때 사용합니다. 문서 제목을 단순히 굵은 글자로만 만들었다면 제목 블록 설정을 확인합니다. 전체 화면을 사용하면 편집에 더 넓은 영역을 사용할 수 있습니다. 돌아올 때는 전체 화면 닫기를 누릅니다.

여러 페이지와 텍스트 파일

섹션 제목: “여러 페이지와 텍스트 파일”

하단의 페이지 탭으로 편집할 페이지를 선택합니다. 페이지 추가로 새 페이지를 만들고 필요한 내용을 나눕니다. 페이지 이름과 순서를 정리하면 긴 자료에서 현재 위치를 구분하기 쉽습니다. 페이지 삭제는 해당 페이지 내용을 복구할 수 없다는 확인을 표시하므로 내용을 확인한 뒤 진행합니다.

텍스트 파일을 앱에 드롭하여 콘텐츠로 가져올 수 있습니다. .txt와 .md 파일은 글을 가져오는 데 사용합니다. 편집 화면에 놓을 때는 표시되는 가져오기 흐름과 삽입 위치를 확인합니다. 여러 페이지를 사용 중이면 파일을 놓기 전에 현재 선택된 페이지를 확인합니다.

설정 > 일반 > 새 콘텐츠·아이디어 간편 실행을 켜면 새 콘텐츠나 새 아이디어를 눌렀을 때 바로 생성합니다. 끄면 제목을 입력한 뒤 만듭니다. 빠르게 기록할 때와 제목을 먼저 정리할 때 중 자신의 작업 방식에 맞게 선택합니다. 카테고리가 준비되지 않았다면 먼저 저장할 위치를 선택합니다.

버전 히스토리와 내보내기

섹션 제목: “버전 히스토리와 내보내기”

버전 히스토리를 열면 현재 페이지의 저장된 버전 목록을 확인합니다. 목록의 버전을 누르면 그 내용으로 복원합니다. **저장된 버전이 없습니다.**가 표시되면 선택할 과거 버전이 없는 상태입니다. 다른 페이지의 내용을 복구하려면 먼저 해당 페이지를 선택합니다.

내보내기에서 Markdown (.md) 또는 **PDF (.pdf)**를 선택합니다. 내보내기는 현재 편집 페이지의 내용을 사용합니다. 여러 페이지를 모두 전달하려면 각 페이지를 확인하여 필요한 결과를 내보냅니다. Markdown은 웹 서식이나 첨부를 동일하게 재현하는 전체 보관 묶음이 아닙니다. 전달 전 파일을 열어 표, 이미지, 수식 등 필요한 내용을 확인합니다.

저장 실패와 파일 읽기 실패를 구분합니다

본문을 열지 못했습니다가 표시되면 원본 보호를 위해 편집이 막힐 수 있습니다. 빈 문서로 덮어쓰려고 하지 말고 파일이나 동기화 상태를 확인한 뒤 다시 시도합니다. 저장 실패가 표시된 내용도 성공한 것으로 가정하지 않습니다.
