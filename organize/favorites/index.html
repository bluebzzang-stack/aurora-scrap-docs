좋아요 모아보기

좋아요 화면은 여러 워크스페이스에서 하트 표시를 붙인 항목을 한곳에 보여줍니다. 자주 열 자료나 다시 살펴볼 자료를 표시해 두면 원래 카테고리를 기억하지 못해도 쉽게 접근할 수 있습니다. 좋아요를 붙여도 항목의 보관 위치는 바뀌지 않습니다. 모아보기에서 항목을 선택하면 해당 워크스페이스와 카테고리로 이동하여 내용을 확인합니다.

좋아요 표시하고 모아보기

섹션 제목: “좋아요 표시하고 모아보기”
  1. 일반 스크랩 목록에서 다시 볼 항목을 찾습니다. 제목이 같거나 비슷한 항목이 여러 개라면 저장일이나 원본 URL로 대상을 확인합니다.
  2. 목록 또는 상세 화면의 하트 아이콘을 누릅니다. 일반 목록에서는 즐겨찾기 또는 즐겨찾기 해제라는 도움말이 표시될 수 있습니다. 이 표시가 좋아요 모아보기에 사용하는 상태입니다.
  3. 앱 상단의 하트 버튼을 눌러 좋아요 화면을 엽니다. 현재 워크스페이스뿐 아니라 이 앱에 등록된 여러 워크스페이스의 좋아요 항목을 확인합니다.
  4. 왼쪽에서 전체를 선택하여 모아 둔 항목을 살펴봅니다. 특정 공간의 자료만 볼 때는 해당 워크스페이스 이름을 선택합니다.
  5. 제목과 썸네일을 보고 원하는 카드를 누릅니다. 앱이 그 항목이 있는 워크스페이스와 카테고리를 선택하고 일반 보기로 이동합니다.
  6. 항목을 선택하지 않고 돌아가려면 화면 오른쪽 위의 닫기 버튼을 누릅니다. 모아보기만 닫히며 표시한 좋아요는 유지됩니다.

좋아요 안에서 검색하기

섹션 제목: “좋아요 안에서 검색하기”

화면 위쪽의 **좋아요 항목에서 검색…**에 검색어를 입력합니다. 좋아요 검색은 현재 불러온 좋아요 항목의 제목, URL, 메모, 워크스페이스 이름, 카테고리 이름을 대상으로 합니다. 일반적인 본문 전체 검색이 필요하면 통합검색을 사용합니다. 좋아요 표시가 없는 항목은 이 화면에서 검색되지 않습니다.

검색어와 워크스페이스 선택은 함께 적용됩니다. 예를 들어 특정 워크스페이스를 선택한 상태에서 단어를 입력하면 그 공간의 좋아요 중 일치하는 항목만 남습니다. 원하는 결과가 없으면 먼저 전체로 바꾸고, 다음으로 검색어를 지워 봅니다. 이 순서로 확인하면 검색 조건 때문인지 좋아요 상태 때문인지 구분하기 쉽습니다.

워크스페이스 이름 옆의 개수는 현재 검색 조건에 맞는 좋아요 항목을 확인하는 데 사용합니다. 전체 자료 개수나 해당 공간의 용량을 뜻하지 않습니다. 표시되는 개수가 예상보다 작다면 일반 목록으로 돌아가 원하는 자료에 하트가 붙어 있는지 확인합니다. 항목이 휴지통에 있는 경우에는 일반 보관 상태도 함께 확인합니다.

좋아요 정리하기

섹션 제목: “좋아요 정리하기”

모아보기의 카드에 있는 하트 버튼을 누르면 좋아요 해제를 할 수 있습니다. 해제가 완료되면 해당 카드는 모아보기 목록에서 빠집니다. 자료 자체는 원래 워크스페이스와 카테고리에 남습니다. 다시 표시하려면 일반 목록에서 같은 항목을 찾아 하트를 누릅니다.

읽은 자료를 모아보기에서 빼고 싶을 때는 좋아요 해제를 사용합니다. 자료 파일도 더 이상 필요하지 않은 경우에만 일반 목록의 삭제를 검토합니다. 두 작업을 구분하면 다시 필요할 수 있는 자료를 실수로 휴지통에 보내지 않을 수 있습니다. 좋아요를 해제한 뒤 화면에서 사라졌다고 해서 파일이 지워진 것은 아닙니다.

모아보기는 여러 공간을 함께 보는 화면이므로 같은 제목의 카드가 나란히 나타날 수 있습니다. 이것만으로 중복 저장이라고 단정하지 않습니다. 각각의 워크스페이스와 카테고리를 확인한 다음 필요하면 원본 URL이나 저장일을 비교합니다. 남길 항목을 정한 후 하트 표시를 조정하면 됩니다.

빈 화면 확인 순서

섹션 제목: “빈 화면 확인 순서”
  1. 좋아요한 항목이 없습니다가 보이면 일반 목록에서 하트를 붙인 자료가 있는지 확인합니다. 처음 사용하는 경우에는 먼저 항목 하나를 표시하고 다시 엽니다.
  2. 특정 워크스페이스에 좋아요 항목이 없다는 안내가 나오면 전체를 선택합니다. 다른 공간에 표시한 항목이 있는지 확인합니다.
  3. **검색 결과가 없습니다.**가 나오면 검색어를 지웁니다. 검색 대상에 포함되지 않는 본문 단어를 입력한 경우에는 통합검색으로 옮겨 찾습니다.
  4. 최근 다른 PC에서 좋아요 상태를 바꾼 자료라면 동기화 상태를 확인합니다. 모아보기를 닫았다가 다시 열어 현재 저장 상태를 확인합니다.

다시 읽을 자료를 보관 위치와 함께 관리합니다

좋아요는 자주 접근할 대상을 표시하는 데 사용합니다. 자료의 주제 분류는 카테고리와 태그로 유지합니다. 좋아요를 해제한 뒤에도 원래 분류와 검색 단서가 남아 있으면 다시 찾기 쉽습니다.

자주 묻는 질문

섹션 제목: “자주 묻는 질문”

좋아요와 즐겨찾기는 다른 기능인가요?

섹션 제목: “좋아요와 즐겨찾기는 다른 기능인가요?”

현재 일반 목록의 하트 도움말에는 즐겨찾기라는 표현을 사용하고, 모아보기 화면에서는 좋아요라는 표현을 사용합니다. 같은 항목 표시를 가리킵니다. 일반 목록에서 하트를 켠 항목은 좋아요 화면에서 모아볼 수 있습니다.

좋아요 해제를 하면 저장 공간이 줄어드나요?

섹션 제목: “좋아요 해제를 하면 저장 공간이 줄어드나요?”

줄어들지 않습니다. 해제는 하트 표시만 바꾸며 파일은 그대로 남깁니다. 공간을 확보하려면 필요 없는 항목을 확인하고 삭제와 휴지통 정리를 별도로 진행합니다. 중요한 자료는 좋아요 상태와 관계없이 보존 여부를 판단합니다.

다른 워크스페이스의 카드를 누르면 어떻게 되나요?

섹션 제목: “다른 워크스페이스의 카드를 누르면 어떻게 되나요?”

해당 워크스페이스로 전환하고 자료가 들어 있는 카테고리와 항목을 선택합니다. 별도의 복사본을 만드는 동작은 아닙니다. 내용을 확인한 뒤 상단 하트 버튼으로 모아보기를 다시 열 수 있습니다.
