카테고리

카테고리는 현재 워크스페이스 안의 자료를 폴더 구조로 분류합니다. 상위 카테고리 아래에 하위 카테고리를 만들 수 있습니다. 자료를 저장할 때 선택하는 위치와 왼쪽 사이드바에서 목록을 여는 위치가 같은 카테고리입니다. 여러 워크스페이스를 사용하는 경우 먼저 대상 탭을 고른 다음 카테고리를 만듭니다. 주제별 분류와 색상 라벨을 함께 사용하면 같은 자료를 다시 찾기 쉽습니다.

카테고리 만들기

섹션 제목: “카테고리 만들기”
  1. 자료를 보관할 워크스페이스 탭을 선택합니다. 사이드바에 표시되는 카테고리 목록이 원하는 공간의 목록인지 확인합니다.
  2. 카테고리 추가 버튼을 누릅니다. 기존 항목 아래에 만들려면 해당 카테고리를 우클릭하고 하위 카테고리 추가를 선택합니다.
  3. 이름을 입력합니다. 개별 이름은 최대 20자입니다. 목록에서 구분할 수 있도록 주제나 작업 이름을 사용합니다. 이름만으로 설명이 부족한 내용은 각 스크랩의 메모에 적을 수 있습니다.
  4. 여러 카테고리를 한 번에 만들려면 이름을 쉼표로 나눕니다. 예를 들어 기획,디자인,개발을 입력하면 같은 부모 아래에 세 카테고리를 만듭니다. 쉼표는 하위 단계 구분 기호가 아닙니다.
  5. 상위 카테고리와 아이콘을 확인하고 추가를 완료합니다. 만들어진 항목을 사이드바에서 선택하여 해당 카테고리의 목록을 엽니다.
  6. 웹페이지나 콘텐츠를 만들 때 방금 만든 카테고리를 선택합니다. 목록이 비어 있으면 아직 그 위치에 저장한 항목이 없는지 확인합니다.

이름과 순서 바꾸기

섹션 제목: “이름과 순서 바꾸기”

카테고리를 우클릭하고 이름 변경을 선택하면 표시 이름을 수정합니다. 아이콘을 바꾸려면 아이콘 변경을 사용합니다. 이름과 아이콘은 카테고리를 구분하는 표시에 사용합니다. 항목을 다른 카테고리에 보내려는 경우에는 스크랩 목록의 카테고리 이동을 사용합니다.

같은 단계 안에서 순서만 바꾸려면 위로 이동 또는 아래로 이동을 선택합니다. 드래그로 옮길 수도 있습니다. 다른 카테고리 앞뒤에 놓으면 순서가 바뀌고, 안쪽 위치에 놓으면 해당 카테고리 아래로 이동합니다. 드래그하는 동안 표시되는 삽입 위치를 보고 마우스를 놓습니다.

부모 카테고리를 자신의 하위 카테고리 안으로 옮길 수는 없습니다. 이런 이동은 폴더 관계를 올바르게 구성할 수 없기 때문입니다. 잘못된 위치에 놓으려는 안내가 나오면 같은 단계의 앞뒤나 다른 부모 위치를 선택합니다. 여러 단계로 나눌 때는 상위 주제와 하위 주제가 목록에서 구분되는지 확인합니다.

항목과 표시 옵션

섹션 제목: “항목과 표시 옵션”
항목 기능 작업 기준
하위 카테고리 추가 선택한 카테고리 아래에 새 분류를 만듭니다 부모를 먼저 선택합니다
이름 변경 카테고리 이름을 수정합니다 기존 자료의 제목 수정과 구분합니다
아이콘 변경 카테고리에 표시할 아이콘을 고릅니다 이름과 함께 구분 표시에 사용합니다
위로 이동 같은 단계에서 앞쪽으로 옮깁니다 부모를 바꾸려면 드래그 위치를 확인합니다
아래로 이동 같은 단계에서 뒤쪽으로 옮깁니다 자주 쓰는 항목의 순서를 정리합니다
여기에 스크랩 추가 선택한 위치에서 스크랩을 시작합니다 저장 다이얼로그의 선택 위치를 확인합니다
여기에 콘텐츠 작성 선택한 위치에서 콘텐츠를 시작합니다 제목과 내용을 작성합니다
삭제 포함된 자료와 하위 카테고리를 휴지통으로 보냅니다 확인 화면의 대상 이름을 읽습니다

트리 스타일과 검색

섹션 제목: “트리 스타일과 검색”

설정 > 테마 > 카테고리 트리 스타일에서 모던, 클래식, 라인 중 하나를 고릅니다. 모던은 간결한 행과 선택 표시를 사용합니다. 클래식은 전통적인 연결선 구조를 표시합니다. 라인은 둥근 연결선과 강조 표시를 사용합니다. 세 방식 모두 같은 카테고리 자료를 표시하므로 디자인을 바꾸어도 분류 내용은 바뀌지 않습니다.

카테고리가 많으면 카테고리 검색… 입력란을 사용합니다. 이 검색은 트리에서 필요한 분류를 찾기 위한 검색입니다. 스크랩의 본문을 검색하려면 목록 검색이나 통합검색을 사용합니다. 카테고리 이름이 검색되지 않으면 먼저 현재 워크스페이스가 맞는지 확인하고 검색어를 짧게 바꾸어 확인합니다.

스크랩 생성 화면의 카테고리 선택에서도 계층 구조를 확인할 수 있습니다. 이름이 같은 카테고리가 다른 부모 아래에 있을 수 있습니다. 이때는 이름만 보지 말고 들여쓰기와 상위 경로를 함께 확인합니다. 자주 선택하는 위치는 생성 직전에 한 번 더 확인하면 잘못된 분류로 저장하는 일을 줄일 수 있습니다.

스크랩을 다른 카테고리로 옮기기

섹션 제목: “스크랩을 다른 카테고리로 옮기기”
  1. 이동할 항목이 들어 있는 카테고리를 엽니다. 여러 항목을 옮기려면 목록의 체크박스로 대상을 선택합니다.
  2. 항목의 우클릭 메뉴 또는 다중 선택 액션 바에서 카테고리 이동을 선택합니다. 카테고리 자체를 드래그하는 동작과 구분합니다.
  3. 목적지 카테고리를 선택합니다. 다른 워크스페이스로 보내려는 경우에는 워크스페이스 이동을 사용합니다.
  4. 이동을 마친 뒤 목적지 목록을 엽니다. 제목과 선택한 항목 수를 확인하여 필요한 자료가 모였는지 살펴봅니다.

이름과 구조를 함께 정리합니다

한 번에 많은 하위 단계를 만들기보다 실제 저장할 자료에 맞추어 분류를 추가합니다. 여러 주제에 걸친 자료는 한 카테고리에 보관하고 라벨이나 태그로 다른 주제를 표시할 수 있습니다.

자주 묻는 질문

섹션 제목: “자주 묻는 질문”

쉼표로 입력하면 여러 단계가 만들어지나요?

섹션 제목: “쉼표로 입력하면 여러 단계가 만들어지나요?”

아닙니다. 쉼표로 나눈 이름은 같은 부모를 공유하는 여러 카테고리를 만듭니다. 중첩 구조가 필요하면 먼저 부모 카테고리를 만든 뒤 하위 카테고리 추가로 다음 단계를 만듭니다. 추가 후 트리의 들여쓰기를 확인합니다.

카테고리를 삭제하면 자료도 사라지나요?

섹션 제목: “카테고리를 삭제하면 자료도 사라지나요?”

포함된 스크랩과 하위 카테고리가 휴지통으로 이동합니다. 삭제 확인 문구에서 대상 이름을 확인합니다. 필요한 항목만 옮기려던 경우에는 삭제를 취소하고 카테고리 이동을 사용합니다. 휴지통을 비우기 전에는 복원할 자료가 있는지 확인합니다.

트리 스타일을 바꾸면 폴더 구조도 바뀌나요?

섹션 제목: “트리 스타일을 바꾸면 폴더 구조도 바뀌나요?”

표시 방식만 바뀝니다. 같은 워크스페이스의 카테고리를 다른 모양으로 보여줍니다. 분류 구조를 바꾸려면 이름 변경, 순서 이동, 드래그 이동 중 필요한 작업을 직접 선택합니다.
