다중 선택과 휴지통

스크랩 목록에서는 체크박스로 여러 항목을 선택한 뒤 한 번에 이동하거나 라벨을 붙이거나 삭제할 수 있습니다. 선택된 항목 수는 화면 아래의 액션 바에서 확인합니다. 일반 삭제는 휴지통으로 보내는 동작이며, 휴지통 비우기는 저장된 항목을 영구적으로 제거하는 동작입니다. 작업 전에 선택 범위와 현재 워크스페이스를 확인하면 많은 자료를 정리할 때 실수를 줄일 수 있습니다.

여러 항목 선택하기

섹션 제목: “여러 항목 선택하기”
  1. 정리할 워크스페이스와 카테고리를 엽니다. 필요하면 검색어, 타입 필터, 라벨 필터를 사용하여 정리할 자료를 먼저 좁힙니다.
  2. 각 항목의 체크박스를 눌러 대상을 선택합니다. 항목을 클릭하여 미리보기를 여는 것과 체크박스로 여러 대상을 선택하는 것은 별도 동작입니다.
  3. 표시된 항목을 모두 선택하려면 목록의 전체 선택 체크박스를 사용합니다. 선택된 개수를 확인합니다. 아직 불러오지 않은 모든 페이지까지 선택되었다고 가정하지 않습니다.
  4. 연속된 체크박스를 빠르게 바꿀 때는 체크박스 영역을 누른 채 다른 체크박스 위로 드래그할 수 있습니다. 마우스를 놓은 뒤 원하는 항목만 선택되었는지 확인합니다.
  5. 아래 액션 바에 표시된 개수를 읽고 이동, 라벨, 삭제 중 필요한 작업을 선택합니다. 작업을 취소하려면 선택 해제를 누릅니다.

카테고리와 워크스페이스 이동

섹션 제목: “카테고리와 워크스페이스 이동”

같은 워크스페이스 안에서 분류를 바꾸려면 카테고리 이동을 사용합니다. 목적지 트리에서 카테고리를 선택합니다. 이름이 같은 카테고리가 여러 곳에 있으면 상위 경로를 확인합니다. 이동 후 목적지 목록에서 항목을 확인합니다.

다른 저장 공간으로 보낼 때는 워크스페이스 이동을 선택합니다. 먼저 대상 워크스페이스를 선택하고 필요한 카테고리를 선택합니다. 다른 워크스페이스가 없다는 안내가 나오면 이동할 공간을 먼저 준비합니다. 대상 공간의 용량 한도나 저장 위치도 미리 확인하면 이동 중 문제를 줄일 수 있습니다.

이동은 카테고리 이름을 바꾸는 동작과 다릅니다. 항목을 어느 분류에 둘 것인지 정하는 작업입니다. 목록의 선택 상태가 정리되거나 대상 공간으로 이동한 후에는 제목과 개수를 다시 확인합니다. 여러 번 연속 작업할 때는 이전 선택이 유지될 것이라고 가정하지 않습니다.

다중 선택 액션

섹션 제목: “다중 선택 액션”
액션 결과 실행 전에 확인할 내용
카테고리 이동 선택 항목을 같은 공간의 다른 분류로 옮깁니다 목적지 카테고리 이름과 부모 경로를 확인합니다
워크스페이스 이동 다른 워크스페이스로 항목을 보냅니다 대상 공간과 카테고리를 순서대로 고릅니다
라벨 설정 선택 항목에 라벨을 적용합니다 선택한 전체 항목에 붙일 라벨인지 확인합니다
삭제 선택 항목을 휴지통으로 보냅니다 확인창의 개수와 선택 범위를 읽습니다
선택 해제 여러 항목의 체크 상태를 지웁니다 저장된 자료는 변경하지 않습니다
복원 휴지통의 자료를 다시 사용하도록 복구합니다 복원할 항목의 제목과 삭제일을 확인합니다
휴지통 비우기 휴지통 항목을 영구 삭제합니다 필요한 복원을 먼저 마칩니다

삭제한 항목 복원하기

섹션 제목: “삭제한 항목 복원하기”
  1. 사이드바에서 휴지통을 선택합니다. 현재 워크스페이스의 휴지통을 보고 있는지 확인합니다. 다른 공간에서 삭제했다면 해당 탭으로 전환합니다.
  2. 제목과 삭제일을 확인하여 복원할 자료를 찾습니다. 비슷한 자료가 여러 개라면 이름만 보고 선택하지 않습니다.
  3. 해당 항목의 복원을 누릅니다. 복원 후 일반 목록이나 관련 카테고리로 돌아가 자료를 확인합니다.
  4. 카테고리를 삭제하여 하위 자료도 휴지통으로 이동한 경우에는 복원 결과의 분류 상태를 확인합니다. 필요한 정리는 복원된 자료를 확인한 뒤 진행합니다.

휴지통은 실수로 삭제한 항목을 확인하는 위치입니다. 오랫동안 모든 삭제 파일을 보관하는 별도의 백업으로 생각하지 않습니다. 워크스페이스 자체 삭제나 콘텐츠 첨부파일 삭제처럼 휴지통을 거치지 않는 작업도 있으므로 각 확인 문구를 읽습니다.

휴지통 비우기와 용량

섹션 제목: “휴지통 비우기와 용량”

휴지통에 남아 있는 파일은 저장 공간을 사용할 수 있습니다. 용량 안내에 휴지통 항목 수와 크기가 표시되면 복원할 자료가 있는지 먼저 살펴봅니다. 필요한 자료를 복원한 뒤 휴지통 비우기를 선택합니다. 확인창은 모든 항목이 영구적으로 삭제된다는 내용을 표시합니다.

동기화 워크스페이스에서는 휴지통을 비운 뒤에도 다른 기기에서 항목이 다시 나타나지 않도록 삭제 기록을 남깁니다. 이 기록은 사용자가 열어 보는 원본 파일을 계속 보관한다는 뜻이 아닙니다. 다른 PC에서 오래된 목록을 보고 있으면 동기화를 마친 뒤 상태를 확인합니다.

비우기 전에 복원을 마칩니다

휴지통 비우기는 되돌릴 수 없습니다. 용량을 확보할 때는 먼저 필요한 자료를 복원합니다. 체크박스 선택 범위와 관계없이 휴지통 비우기는 휴지통 전체를 대상으로 한다는 확인 문구를 읽고 진행합니다.

자주 묻는 질문

섹션 제목: “자주 묻는 질문”

전체 선택을 누르면 모든 페이지가 선택되나요?

섹션 제목: “전체 선택을 누르면 모든 페이지가 선택되나요?”

현재 목록에 불러온 항목을 기준으로 선택합니다. 무한 스크롤이나 페이지 전환을 사용하는 경우에는 액션 바의 선택 개수를 반드시 확인합니다. 화면에 표시된 검색 결과 총수와 선택된 항목 수가 같다고 가정하지 않습니다.

항목을 삭제했는데 용량이 그대로인가요?

섹션 제목: “항목을 삭제했는데 용량이 그대로인가요?”

휴지통에 파일이 남아 있으면 계속 용량을 사용할 수 있습니다. 휴지통을 확인하고 필요 없는 자료만 영구적으로 제거합니다. 단순히 목록에서 안 보이게 된 상태와 디스크에서 파일이 제거된 상태는 다릅니다.

첨부파일도 휴지통에서 복원할 수 있나요?

섹션 제목: “첨부파일도 휴지통에서 복원할 수 있나요?”

콘텐츠의 개별 첨부파일 삭제는 휴지통을 거치지 않는다는 확인 문구를 표시합니다. 일반 스크랩 삭제와 같지 않습니다. 어떤 삭제 화면을 사용했는지 확인하고, 되돌릴 수 없는 삭제를 진행하기 전에 필요한 파일을 보관합니다.
