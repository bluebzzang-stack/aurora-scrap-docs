워크스페이스

워크스페이스는 카테고리와 스크랩을 따로 보관하는 저장 공간입니다. 업무 자료와 개인 자료를 나누거나, 다른 저장 위치를 사용하는 자료를 구분할 때 만듭니다. 탭을 바꾸면 해당 워크스페이스의 카테고리와 목록이 표시됩니다. 새 워크스페이스를 만들 때 이름과 저장 위치를 먼저 확인합니다. 저장 경로는 생성한 뒤 편집 화면에서 바꿀 수 없습니다.

새 워크스페이스 만들기

섹션 제목: “새 워크스페이스 만들기”
  1. 워크스페이스 탭 옆의 추가 버튼을 누르고 새 워크스페이스를 선택합니다. 현재 사용 중인 워크스페이스와 별도로 자료를 보관할 공간을 만드는 단계입니다.
  2. 이름에 화면에서 알아보기 쉬운 이름을 입력합니다. 이름은 최대 20자입니다. 같은 업무 안에서 주제만 나누려면 새 워크스페이스 대신 카테고리를 만드는 방법도 있습니다.
  3. **ID (폴더명)**을 확인합니다. 영문 소문자, 숫자, 하이픈을 사용하며 최대 20자입니다. 이미 사용 중인 ID라는 안내가 나오면 다른 값을 입력합니다.
  4. 아이콘을 고릅니다. 이름과 아이콘은 여러 탭에서 원하는 저장 공간을 찾는 데 사용합니다. 동기화 종류나 저장 용량은 아이콘으로 결정하지 않습니다.
  5. 필요한 경우 저장 경로 직접 지정을 선택하고 폴더를 지정합니다. 생성 전에 최종 위치를 확인합니다. 이동식 디스크나 네트워크 위치라면 이후에도 접근할 수 있는 위치인지 확인합니다.
  6. 생성을 누릅니다. 생성된 탭을 열고 카테고리를 추가합니다. 새 자료를 저장하기 전에 선택된 탭과 카테고리 이름을 함께 확인합니다.

탭과 저장 공간 정리하기

섹션 제목: “탭과 저장 공간 정리하기”

탭을 누르면 작업할 워크스페이스가 바뀝니다. 진행 중인 스크랩이 있을 때 전환 안내가 표시되면 현재 작업을 확인하고 선택합니다. 같은 이름의 카테고리가 다른 워크스페이스에도 있을 수 있으므로 카테고리 이름만 보고 저장 대상을 판단하지 않습니다.

탭을 좌우로 드래그하면 순서를 바꿀 수 있습니다. 자주 사용하는 공간을 먼저 배치하면 목록을 오가는 횟수를 줄일 수 있습니다. 탭 순서 변경은 저장된 항목의 카테고리를 이동하는 작업과 다릅니다. 탭의 위치가 달라져도 각 항목은 원래 워크스페이스에 남습니다.

탭의 우클릭 메뉴에서 편집을 선택하면 이름과 아이콘을 관리할 수 있습니다. 저장 폴더 열기를 선택하면 실제 보관 위치를 확인할 수 있습니다. Windows에서는 탐색기로, macOS에서는 Finder로 해당 위치를 확인합니다. 폴더 안의 파일을 직접 옮기는 대신 앱의 항목 이동 기능을 사용합니다.

옵션과 한도

섹션 제목: “옵션과 한도”
항목 의미 사용할 때 확인할 점
이름 탭에 표시하는 이름입니다 최대 20자로 입력합니다
ID (폴더명) 저장 공간을 구분하는 폴더 이름입니다 중복된 ID는 사용할 수 없습니다
저장 경로 직접 지정 기본 위치와 다른 저장 위치를 고릅니다 생성 이후 경로 편집은 지원하지 않습니다
탭 위치 탭을 상단 또는 하단에 표시합니다 자료의 저장 위치는 바뀌지 않습니다
탭에 스크랩 개수 표시 탭에서 항목 수를 확인합니다 용량 사용량과 항목 수는 서로 다릅니다
무료 워크스페이스 2개, 각각 1GB입니다 각 공간의 사용량을 따로 확인합니다
Pro 워크스페이스 10개, 각각 10GB입니다 라이선스는 설정에서 등록합니다
Enterprise 워크스페이스 개수와 저장 용량 한도가 없습니다 실제 디스크의 남은 공간은 필요합니다

용량 안내 확인하기

섹션 제목: “용량 안내 확인하기”

용량 배너는 현재 워크스페이스가 사용하는 공간과 한도를 알려줍니다. 한도를 넘으면 새 저장이 제한됩니다. 개수가 적어도 고해상도 이미지나 동영상이 크면 한도에 빨리 도달할 수 있습니다. 반대로 작은 텍스트 항목이 많다고 해서 같은 정도의 용량을 사용하지는 않습니다.

용량이 부족하면 먼저 불필요한 항목을 확인합니다. 항목을 삭제하여 휴지통으로 옮겨도 파일이 남아 있으면 공간을 계속 사용합니다. 휴지통에 남은 항목과 크기가 안내되는 경우, 복원할 자료가 없는지 살핀 뒤 휴지통을 비웁니다. 계속 저장할 공간이 필요하면 라이선스 탭에서 현재 한도와 업그레이드 내용을 확인합니다.

워크스페이스 삭제하기

섹션 제목: “워크스페이스 삭제하기”
  1. 삭제할 탭의 우클릭 메뉴에서 삭제를 선택합니다. 같은 이름의 탭이 있다면 먼저 저장 폴더 열기로 대상 위치를 확인합니다.
  2. 확인 화면에 표시되는 스크랩 개수를 읽습니다. 현재 삭제 동작은 워크스페이스의 로컬 항목과 저장 파일을 함께 제거합니다. 필요한 자료는 삭제 전에 다른 워크스페이스로 이동합니다.
  3. 동기화 중인 공간에는 원격 데이터도 함께 삭제 옵션이 표시됩니다. 이를 선택하면 Google Drive 또는 동기화 폴더의 해당 워크스페이스 데이터도 제거합니다.
  4. 삭제 범위를 확인하고 진행합니다. 원격 데이터 삭제가 실패했다는 안내가 나오면 삭제가 중단된 상태를 확인하고 동기화 연결 문제를 먼저 해결합니다.

워크스페이스 삭제는 휴지통 이동과 다릅니다

워크스페이스 삭제는 되돌릴 수 없습니다. 항목 몇 개를 정리하려는 경우에는 목록의 삭제 기능을 사용합니다. 다른 PC에서도 계속 사용할 공간이라면 원격 데이터 삭제 옵션의 설명을 반드시 확인합니다.

자주 묻는 질문

섹션 제목: “자주 묻는 질문”

이름을 바꾸면 저장 경로도 바뀌나요?

섹션 제목: “이름을 바꾸면 저장 경로도 바뀌나요?”

이름 편집은 화면에 표시되는 이름을 관리하는 기능입니다. 저장 경로 변경과 같지 않습니다. 다른 위치가 필요하면 새 워크스페이스를 준비하고 앱에서 항목을 이동하는 방법을 검토합니다. 파일 탐색기에서 폴더 이름을 임의로 바꾸어 경로 변경을 대신하지 않습니다.

무료 용량은 전체 합계 1GB인가요?

섹션 제목: “무료 용량은 전체 합계 1GB인가요?”

무료 한도는 워크스페이스당 1GB입니다. 만들 수 있는 워크스페이스는 2개입니다. 한 공간이 가득 찼을 때 다른 공간의 빈 용량이 자동으로 합쳐지지는 않습니다. 저장하려는 공간의 배너를 기준으로 상태를 확인합니다.

원격 데이터를 남기면 이 PC의 파일도 남나요?

섹션 제목: “원격 데이터를 남기면 이 PC의 파일도 남나요?”

그렇지 않습니다. 원격 데이터 삭제 옵션은 동기화 위치에 있는 데이터의 처리 범위를 정합니다. 현재 워크스페이스 삭제는 이 PC의 로컬 파일을 함께 제거합니다. 로컬 파일을 보존하는 삭제 옵션으로 이해하지 않습니다.
