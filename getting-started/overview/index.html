화면 구성 안내

AURORA의 기본 화면은 자료를 저장할 공간을 고르고, 목록에서 항목을 선택한 뒤, 미리보기로 내용을 확인하는 순서로 사용합니다. 워크스페이스는 자료의 저장 공간을 구분합니다. 카테고리는 해당 공간 안에서 항목을 정리합니다. 목록에는 선택한 범위의 자료가 나타납니다. 미리보기는 목록에서 고른 항목의 파일과 정보를 보여 줍니다. 먼저 이 네 영역의 관계를 익히면 검색 결과에서 원래 자료로 돌아가기도 쉽습니다.

기본 화면 둘러보기

섹션 제목: “기본 화면 둘러보기”
  1. 워크스페이스 탭에서 사용할 공간을 선택합니다. 탭 위치는 설정에 따라 위쪽 또는 아래쪽에 나타납니다. 이름이 비슷한 공간이 여러 개라면 지금 선택한 탭을 먼저 확인합니다. 파일을 가져오거나 새 자료를 만들기 전에 이 선택을 확인하면 다른 공간에 저장하는 일을 줄일 수 있습니다.
  2. 왼쪽 사이드바에서 카테고리를 선택합니다. 하위 카테고리가 있는 항목은 펼쳐서 확인합니다. 목록의 자료 수나 내용이 예상과 다르면 다른 카테고리를 선택한 것은 아닌지 확인합니다. 새 자료를 저장할 카테고리가 없으면 먼저 카테고리를 만듭니다.
  3. 가운데 스크랩 목록에서 항목을 클릭합니다. 카드 형태에서는 썸네일을 중심으로 볼 수 있습니다. 리스트 형태에서는 여러 제목을 연속해서 확인하기 좋습니다. 보기 메뉴의 그리드 보기 또는 리스트 보기로 표시 방식을 바꿉니다. macOS에서는 네이티브 메뉴에 그리드/리스트 전환으로 나타납니다.
  4. 미리보기 패널에서 저장된 내용을 확인합니다. 이미지가 있는 자료는 스크린샷, 본문이 추출된 자료는 **본문(MD)**를 확인합니다. 영상이나 미디어가 있는 자료에는 해당 보기가 나타납니다. 모든 자료에 동일한 탭이나 파일이 생기는 것은 아닙니다.
  5. 상세정보에서 저장일, 원본 URL, 라벨, 태그, 메모를 살펴봅니다. 자료를 저장한 이유를 메모에 남기면 나중에 제목만 보고 기억하기 어려운 항목을 구분할 수 있습니다. 원본 페이지를 확인하려면 원본 URL을 사용합니다.
  6. 상단 도구에서 새 자료를 만들거나 좋아요 모아보기, 통합검색으로 이동합니다. 통합 화면에서는 다른 워크스페이스의 자료가 함께 보일 수 있습니다. 일반 목록으로 돌아온 뒤 새 자료를 만들 때에는 활성 워크스페이스와 카테고리를 다시 확인합니다.

워크스페이스와 카테고리를 선택하고, 가운데 목록의 항목을 오른쪽 미리보기에서 확인하는 기본 화면입니다.

자주 쓰는 화면 이동

섹션 제목: “자주 쓰는 화면 이동”

웹페이지 한 개를 저장할 때

섹션 제목: “웹페이지 한 개를 저장할 때”

먼저 워크스페이스와 카테고리를 선택합니다. 파일 > 새 웹스크랩을 열고 URL을 넣습니다. macOS의 파일 메뉴에서는 새 스크랩으로 표시됩니다. 저장을 시작하면 진행 항목이 목록에 나타납니다. 작업이 끝난 뒤 항목을 선택해 결과를 확인합니다. 처음 열었던 카테고리를 기억해 두면 작업 도중 다른 화면으로 이동해도 쉽게 돌아올 수 있습니다.

자료의 위치를 기억하지 못할 때

섹션 제목: “자료의 위치를 기억하지 못할 때”

현재 카테고리의 목록 검색부터 확인합니다. 다른 공간까지 찾아야 한다면 통합검색을 엽니다. 제목뿐 아니라 메모나 본문에서 기억나는 말을 사용할 수 있습니다. 검색 결과에서 자료를 찾은 뒤 해당 항목으로 이동합니다. 자료가 없어진 것처럼 보여도 현재 공간이나 필터가 달라서 목록에서 제외된 경우가 있으므로, 삭제 여부를 판단하기 전에 검색 범위를 확인합니다.

화면을 넓게 쓰고 싶을 때

섹션 제목: “화면을 넓게 쓰고 싶을 때”

보기 메뉴에서 사이드바 숨기기를 사용합니다. 필요할 때 사이드바 표시로 되돌립니다. 상단에는 툴바 접기와 툴바 펼치기가 있습니다. 도구를 접으면 사용할 버튼의 위치가 달라질 수 있으므로 새 기능을 익힐 때에는 펼친 상태로 확인합니다. 화면 배치는 설정에 따라 달라져도 워크스페이스, 카테고리, 목록, 선택 항목의 관계는 같습니다.

Windows와 macOS의 메뉴 위치

Windows에서는 앱 창 안의 메뉴바를 사용합니다. macOS에서는 화면 위쪽의 운영체제 메뉴바를 사용합니다. macOS에서 메뉴가 보이지 않으면 먼저 AURORA 창을 선택해 앱을 활성화합니다. 같은 작업이라도 일부 메뉴 이름은 두 운영체제에서 다르게 표시됩니다.

자주 묻는 질문

섹션 제목: “자주 묻는 질문”

목록에 아무것도 없으면 먼저 무엇을 확인하나요?

섹션 제목: “목록에 아무것도 없으면 먼저 무엇을 확인하나요?”

현재 워크스페이스와 카테고리를 확인합니다. 검색어와 타입 필터도 확인합니다. 원하는 자료가 다른 공간에 있을 수 있으므로 통합검색을 사용할 수 있습니다. 처음 만든 공간이라면 카테고리를 준비한 뒤 새 자료를 저장합니다. 빈 목록의 생성 버튼도 같은 작업을 시작하는 진입점입니다.

미리보기와 원본 URL은 어떻게 다른가요?

섹션 제목: “미리보기와 원본 URL은 어떻게 다른가요?”

미리보기는 저장된 자료를 확인하는 화면입니다. 원본 URL은 사이트의 현재 페이지로 이동합니다. 사이트 내용이 바뀌면 두 화면의 내용도 달라질 수 있습니다. 보존된 상태를 확인하려면 저장 파일을 먼저 열고, 최신 내용이 필요할 때 원본을 확인합니다.

좋아요 모아보기에 다른 공간의 자료가 보이는 이유는 무엇인가요?

섹션 제목: “좋아요 모아보기에 다른 공간의 자료가 보이는 이유는 무엇인가요?”

좋아요 모아보기는 여러 워크스페이스의 좋아요 항목을 함께 보여 주는 화면입니다. 현재 카테고리 목록과 표시 범위가 다릅니다. 공간별로 정리하려면 일반 화면으로 돌아와 해당 워크스페이스를 선택합니다. 좋아요 표시는 자료를 찾기 위한 분류 수단으로 활용합니다.
