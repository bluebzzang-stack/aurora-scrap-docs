설치

AURORA는 웹페이지와 파일을 워크스페이스에 저장하는 데스크톱 앱입니다. 설치한 뒤 저장 위치를 정하면 웹스크랩, 화면 캡처, 파일 가져오기를 시작할 수 있습니다. 브라우저 확장은 앱과 별도로 등록합니다. 먼저 앱 설치와 첫 실행을 마친 다음 확장을 연결합니다. 이 페이지에서는 설치 파일 선택부터 저장 위치 확인, 트레이 실행, 업데이트 확인까지 순서대로 진행합니다.

설치하고 처음 실행하기

섹션 제목: “설치하고 처음 실행하기”
  1. 사용 중인 운영체제와 컴퓨터 종류를 확인합니다. Windows에서는 x64용 설치 파일을 선택합니다. macOS에서는 Apple Silicon과 Intel을 구분합니다. Apple 메뉴의 컴퓨터 정보에서 칩 또는 프로세서 항목을 확인하면 파일을 고르는 데 도움이 됩니다.
  2. Windows에서는 AURORA-버전-x64.exe 형태의 설치 파일을 실행합니다. 설치 화면에서 안내하는 경로를 확인하고 설치를 진행합니다. 설치 프로그램이 끝나면 AURORA를 실행합니다. 앱을 저장할 위치와 스크랩 데이터를 저장할 위치는 서로 다릅니다. 설치 단계에서는 프로그램의 위치를 정합니다.
  3. macOS에서는 Apple Silicon용 AURORA-버전-arm64.dmg 또는 Intel용 AURORA-버전-x64.dmg 파일을 엽니다. AURORA를 Applications 폴더로 끌어 놓은 뒤 Applications에서 실행합니다. 확장 설치 안내도 설치된 앱을 기준으로 경로를 보여 주므로, 앱을 옮긴 다음 확장을 등록하는 순서가 편리합니다.
  4. 첫 실행의 스크랩을 어디에 저장할까요? 화면에서 현재 경로를 확인합니다. 표시된 위치를 사용하려면 그대로 둡니다. 다른 위치를 사용하려면 변경을 누른 뒤 폴더를 선택합니다. 자주 분리하는 외장 저장장치보다 작업 중 계속 사용할 수 있는 위치를 선택하면 저장 결과를 확인하기 쉽습니다.
  5. 시작하기를 누릅니다. 적용하는 중… 표시가 끝나고 메인 화면이 나타날 때까지 기다립니다. 이 단계는 첫 워크스페이스의 위치를 확정합니다. 이후 새 워크스페이스를 만들 때에는 각 워크스페이스에 다른 위치를 지정할 수 있습니다.
  6. 워크스페이스 탭과 왼쪽 카테고리 목록이 나타나는지 확인합니다. 저장할 카테고리를 준비한 뒤 첫 스크랩 가이드로 이동합니다. 처음에는 공개된 짧은 페이지로 저장과 미리보기 동작을 확인하는 것이 좋습니다.

트레이와 업데이트 확인하기

섹션 제목: “트레이와 업데이트 확인하기”
  1. 앱 창을 닫은 뒤 트레이에 AURORA 아이콘이 있는지 확인합니다. Windows에서는 숨겨진 아이콘 영역도 확인합니다. macOS에서는 화면 위 메뉴 막대에서 아이콘을 확인합니다. 창이 보이지 않아도 앱이 실행 중이면 브라우저 확장과 연결할 수 있습니다.
  2. 트레이 메뉴에서 앱을 다시 엽니다. 웹페이지를 자주 저장한다면 작업 중 앱을 실행 상태로 유지합니다. 트레이의 종료를 선택하면 백그라운드 실행도 끝납니다. 이 상태에서는 확장을 눌러도 앱에 저장 요청을 보낼 수 없습니다.
  3. 환경설정의 일반을 엽니다. 현재 앱에서 제공하는 실행과 업데이트 관련 항목을 확인합니다. 자동 실행 여부와 관계없이 확장을 사용할 때에는 트레이 아이콘과 연결 상태를 직접 확인합니다.
  4. 같은 화면의 자동 업데이트를 확인합니다. 이 옵션을 켜면 새 버전을 자동으로 내려받아 설치합니다. 끄면 새 버전 알림을 확인한 뒤 업데이트를 진행합니다. 수동 확인은 업데이트 확인 항목을 사용합니다. 업데이트 중에는 진행 안내를 읽고 필요한 재시작을 마칩니다.

처음에는 저장 위치를 확인합니다

설치가 끝난 뒤 첫 스크랩을 만든 다음 폴더 열기로 실제 저장 파일을 확인합니다. 앱이 설치된 폴더를 백업하는 것과 워크스페이스 데이터를 백업하는 것은 목적이 다릅니다. 자료를 보존하려면 워크스페이스의 저장 위치를 알아 두어야 합니다.

자주 묻는 질문

섹션 제목: “자주 묻는 질문”

앱 창을 닫으면 확장도 사용할 수 없나요?

섹션 제목: “앱 창을 닫으면 확장도 사용할 수 없나요?”

앱이 트레이에서 실행 중이면 사용할 수 있습니다. 트레이 아이콘을 확인한 뒤 확장 팝업의 연결됨 표시를 확인합니다. 앱을 완전히 종료했다면 먼저 AURORA를 실행합니다. 브라우저만 다시 시작하는 것으로 앱 실행을 대신할 수는 없습니다.

처음 고른 저장 위치를 모든 워크스페이스가 사용하나요?

섹션 제목: “처음 고른 저장 위치를 모든 워크스페이스가 사용하나요?”

워크스페이스를 추가할 때 위치를 개별 지정할 수 있습니다. 업무 자료와 개인 자료를 다른 위치에 보관하려면 워크스페이스를 나누어 구성합니다. 기존 자료가 들어 있는 폴더를 탐색기에서 임의로 이동하기보다 워크스페이스 관련 안내를 먼저 확인합니다.

앱 설치 후 바로 브라우저에서 저장할 수 있나요?

섹션 제목: “앱 설치 후 바로 브라우저에서 저장할 수 있나요?”

앱에서 URL을 입력하는 방식은 바로 시작할 수 있습니다. 브라우저에서 현재 열린 페이지를 저장하려면 확장 등록이 필요합니다. 로그인 후 보이는 페이지를 보존하려면 브라우저 확장을 설치하고 로그인된 탭에서 저장합니다.
