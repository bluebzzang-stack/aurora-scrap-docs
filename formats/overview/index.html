저장 형식 비교

웹페이지는 화면 이미지, 인쇄용 문서, HTML 아카이브처럼 서로 다른 형태로 보관할 수 있습니다. AURORA가 다루는 주요 형식은 PNG, JPG, PDF, MHTML, SingleFile HTML입니다. 같은 페이지라도 저장 형식에 따라 글자의 선택 가능 여부와 화면 배치, 오프라인 열람 결과가 달라집니다. 먼저 보관 목적을 정한 뒤 현재 저장 화면에서 필요한 옵션을 선택하고 결과 파일을 확인합니다.

목적에 맞게 형식 선택하기

섹션 제목: “목적에 맞게 형식 선택하기”
  1. 보관하려는 정보를 정합니다. 화면의 색상과 배치를 기록하려면 이미지를 선택합니다. 문서를 인쇄하거나 페이지 단위로 읽으려면 PDF를 검토합니다. 페이지 내용을 아카이브로 열어 보려면 HTML 아카이브를 확인합니다. 여러 목적이 있으면 파일을 함께 저장할 수 있습니다.
  2. 새 스크랩의 저장 포맷을 엽니다. 현재 앱의 선택 항목은 PNG, JPG, PDF, HTML 아카이브입니다. HTML 아카이브에는 항상 저장이 표시됩니다. 필요한 이미지와 PDF 조합을 고르고 캡처 범위도 함께 확인합니다.
  3. 작은 글자가 많거나 화면을 선명하게 남기려면 PNG를 선택합니다. 사진이나 긴 화면에서 용량을 줄이고 싶다면 JPG로 저장해 비교합니다. JPG는 압축 이미지이므로 작은 글자의 경계가 PNG와 다르게 보일 수 있습니다. 최종 용량은 실제 파일을 확인합니다.
  4. PDF가 필요하면 함께 선택합니다. PDF는 인쇄용 배치를 사용하므로 원본 화면과 줄바꿈이나 페이지 수가 다를 수 있습니다. 저장 후 표가 두 페이지로 나뉘지 않았는지, 그림이 잘리지 않았는지 확인합니다. 스크린샷과 동일한 모양이 필요하면 이미지 결과도 보관합니다.
  5. 아카이브가 만들어지면 앱의 HTML 보기에서 내용을 확인합니다. 단순히 파일 확장자가 있다는 이유로 오프라인 보존을 완료했다고 판단하지 않습니다. 중요한 글과 이미지가 열리는지 확인합니다. 영상과 외부 서비스 동작은 페이지 아카이브와 별도로 확인합니다.
  6. 자주 사용하는 조합으로 한 번 저장한 뒤 다음 대화상자를 열어 선택 상태를 확인합니다. 앱은 최근의 페이지 포맷 선택을 기억합니다. 다른 목적의 작업을 시작할 때에는 지난 선택이 그대로 남아 있는지 확인하고 조절합니다.

다섯 형식 비교

섹션 제목: “다섯 형식 비교”
형식 보관하는 내용 적합한 목적 알아둘 제한
PNG 무손실 화면 이미지 글자와 화면 모양의 선명한 기록 긴 페이지는 파일이 커질 수 있음
JPG 압축 화면 이미지 이미지 용량을 줄이는 보관 압축에 따라 글자 경계가 달라질 수 있음
PDF 인쇄용 페이지 문서 인쇄와 페이지 단위 열람 화면과 다른 줄바꿈이나 페이지 나눔 가능
MHTML 페이지와 리소스의 아카이브 HTML 페이지 보관 외부 서비스와 영상 재현은 별도 확인
SingleFile HTML 리소스를 포함하는 단일 HTML 동적으로 구성된 페이지의 보관 방식 현재 대화상자에 별도 선택 버튼 없음

MHTML과 SingleFile HTML은 둘 다 페이지를 보관하는 방법이지만 같은 파일 형식은 아닙니다. MHTML은 page.mhtml 같은 아카이브 파일을 사용합니다. SingleFile은 page.html 같은 HTML 파일을 사용합니다. 단일 HTML 파일이라고 해서 포함된 모든 외부 동작이 서버 없이 작동하는 것은 아닙니다.

사이트 유형별 확인 순서

섹션 제목: “사이트 유형별 확인 순서”

기사나 블로그 글

섹션 제목: “기사나 블로그 글”

먼저 PNG와 HTML 아카이브로 저장합니다. 글의 제목과 마지막 문단을 확인합니다. 메뉴와 사이드바가 많이 포함되면 콘텐츠 범위로 다시 비교합니다. 본문이 잘리는 경우에는 전체 페이지로 저장합니다. 인용할 문장을 다시 읽고 싶다면 본문 Markdown도 확인하되, 추출된 텍스트와 원본의 문맥을 대조합니다.

화면 구성이 복잡한 웹앱

섹션 제목: “화면 구성이 복잡한 웹앱”

버튼을 눌러 내용이 바뀌는 페이지나 데이터를 나중에 불러오는 페이지는 화면 상태가 중요합니다. 이런 페이지를 SPA라고 부르기도 합니다. 필요한 내용을 먼저 열고 브라우저 확장에서 캡처하면 현재 표시된 상태를 보관하는 데 도움이 됩니다. 아카이브와 이미지 결과를 함께 확인합니다. 저장 후에도 원래 서비스의 로그인이나 서버 기능을 사용할 수 있다고 가정하지 않습니다.

표와 인쇄용 자료

섹션 제목: “표와 인쇄용 자료”

PDF를 추가하고 페이지 구성을 확인합니다. 넓은 표는 PDF에서 나뉠 수 있으므로 이미지 결과와 비교합니다. 글자를 선택할 수 있는지는 실제 PDF를 열어 확인합니다. 이미지로만 된 문서의 글자는 별도 OCR이 필요할 수 있습니다. PDF 형식을 선택했다고 이미지 속 글자가 자동으로 텍스트가 되는 것은 아닙니다.

HTML 아카이브와 현재 선택 화면

현재 앱은 HTML 아카이브를 항상 포함하고 이미지와 PDF를 추가로 선택하는 흐름입니다. SingleFile이라는 별도 체크박스를 찾을 필요는 없습니다. 확장 팝업에서는 아카이브가 **MHTML (항상 포함)**으로 표시됩니다. 저장 결과가 부족하면 필요한 화면을 확장에서 다시 캡처해 확인합니다.

항상 저장과 기본 선택

섹션 제목: “항상 저장과 기본 선택”

HTML 아카이브는 페이지 캡처의 기본 보관 항목입니다. PNG를 해제해도 HTML 아카이브 선택은 유지됩니다. 따라서 이미지가 필요 없는 작업과 이미지가 필요한 작업을 구분해서 선택합니다. 이미지 미리보기를 꼭 사용하려면 PNG 또는 JPG를 선택했는지 확인합니다.

페이지 포맷과 영상 포맷은 구분해서 사용합니다. 동영상 다운로드 모드에서는 MP4 또는 MP3를 선택합니다. 영상 사이트를 페이지 캡처로 저장하는 작업과 영상 파일을 직접 받는 작업의 결과는 다릅니다. 이전에 MP3를 사용했다면 다음 영상 작업에서도 표시된 선택을 확인합니다. 자료의 목적이 바뀔 때 저장 옵션을 다시 읽는 습관이 중요합니다.

자주 묻는 질문

섹션 제목: “자주 묻는 질문”

모든 형식을 고르면 가장 안전한가요?

섹션 제목: “모든 형식을 고르면 가장 안전한가요?”

여러 결과를 비교할 수 있지만 파일 용량과 작업 시간이 늘어납니다. 필요한 보관 목적에 맞추어 선택합니다. 중요한 화면 기록은 이미지로, 인쇄 자료는 PDF로 확인하는 식으로 각 파일의 목적을 분명히 합니다. 여러 파일이 생겼어도 내용 확인은 필요합니다.

이미지에서 글자를 선택할 수 있나요?

섹션 제목: “이미지에서 글자를 선택할 수 있나요?”

PNG와 JPG는 화면 이미지입니다. 글자를 텍스트로 활용하려면 본문 Markdown이나 OCR 결과를 확인합니다. 본문이 추출되지 않은 이미지 자료는 OCR을 사용하고 결과를 원본과 대조합니다. 표나 작은 글자는 특히 확인이 필요합니다.

HTML 파일이 있으면 인터넷 없이 모두 볼 수 있나요?

섹션 제목: “HTML 파일이 있으면 인터넷 없이 모두 볼 수 있나요?”

저장된 본문과 리소스는 열람할 수 있지만 외부 영상이나 서버 기능까지 모두 재현되는 것은 아닙니다. 실제로 필요한 파일을 열어 확인합니다. 실제 미디어 재생 여부도 함께 확인하고, 중요 자료는 이미지 결과를 병행해 보관합니다.
