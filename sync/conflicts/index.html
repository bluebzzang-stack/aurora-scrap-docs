충돌 해결과 보관함

같은 워크스페이스를 두 PC에서 서로의 변경을 받기 전에 수정하면 다른 버전이 생깁니다. 앱은 이 상태에서 임의로 최신 시간을 정답으로 고르지 않습니다. 필요한 판단이 있으면 다른 기기에서 수정된 버전이 있습니다라는 안내를 표시합니다. 사용자는 두 버전을 비교한 뒤 항목을 합치거나 한 버전을 선택할 수 있습니다. 원격 자료를 적용하기 전에는 이 PC의 변경을 로컬 보관함에 보존합니다.

버전 차이 확인하기

섹션 제목: “버전 차이 확인하기”
  1. 동기화 상태 배너에서 버전 선택을 누릅니다. 비교할 워크스페이스가 활성 상태인지 먼저 확인합니다.
  2. 이 컴퓨터와 다른 기기의 항목 수와 마지막 수정 정보를 봅니다. 저장 시간이 늦다는 이유만으로 모든 내용이 더 필요한 버전이라고 판단하지 않습니다.
  3. 두 버전의 차이에서 다른 기기에만 있는 항목, 이 컴퓨터에만 있는 항목, 양쪽에서 수정된 항목을 확인합니다.
  4. 양쪽의 항목을 유지하려면 두 버전 합치기를 선택합니다. 충돌 항목이 있으면 남길 내용 선택 단계로 이동합니다.
  5. 각 항목에서 다른 기기의 내용 또는 이 컴퓨터의 내용을 고릅니다. 제목만 보지 말고 표시된 주소, 메모, 카테고리, 삭제 상태도 함께 확인합니다.
  6. 선택하지 않은 충돌 항목은 이 컴퓨터의 내용을 유지합니다. 필요한 선택을 마친 뒤 선택한 대로 합치기를 누릅니다.
  7. 완료 안내와 결과 목록을 확인합니다. 그다음 다른 PC에서도 최신 결과를 받아 같은 내용을 기준으로 작업합니다.

병합 규칙

섹션 제목: “병합 규칙”
비교 결과 처리 확인할 점
다른 기기에만 항목이 있음 가져올 수 있는 항목을 추가합니다. 파일을 찾을 수 없는 항목이 있는지 확인합니다.
이 컴퓨터에만 항목이 있음 이 컴퓨터의 항목을 유지합니다. 원격에 없다는 이유로 삭제하지 않습니다.
같은 항목을 다르게 수정함 남길 쪽을 사용자가 고릅니다. 선택하지 않으면 로컬 내용을 유지합니다.
라벨이나 태그 연결이 한쪽에 있음 연결을 함께 가져옵니다. 한쪽에서 해제한 연결이 다시 생길 수 있습니다.
스크린샷이나 HTML 본문 파일 파일 내용 자체를 합치지 않습니다. 목록 정보 선택과 파일 편집 병합을 구분합니다.
자료 보존에 실패함 적용을 중단합니다. 저장 공간과 폴더 권한을 확인합니다.

다른 기기의 새 항목을 추가하는 것만으로 해결되고 충돌이나 복원 불가 항목이 없으면 앱이 자동으로 합칠 수 있습니다. 이때 다른 기기의 새 항목을 가져왔다는 안내가 표시됩니다. 같은 항목을 두 기기에서 서로 다르게 수정한 경우에는 이 자동 처리 조건에 해당하지 않습니다. 자동으로 모든 파일 내용을 섞어 준다고 생각하지 않습니다.

한 버전을 기준으로 선택하기

섹션 제목: “한 버전을 기준으로 선택하기”

두 버전을 합칠 수 없거나 한쪽을 기준으로 계속 작업하려면 다른 기기의 최신 버전 사용 또는 이 컴퓨터의 버전 사용을 선택합니다. 다른 기기의 버전을 선택하면 이 PC의 현재 데이터가 선택한 버전으로 교체됩니다. 이 컴퓨터의 버전을 선택하면 로컬 내용을 클라우드의 최신 버전으로 올립니다. 적용 전 확인 문구를 읽고 선택 대상이 맞는지 확인합니다.

특정 항목의 어떤 내용이 필요한지 아직 판단하지 못했다면 바로 적용하지 않습니다. 비교 정보를 먼저 읽고, 필요할 때 미리보기로 버전 내용을 살펴봅니다. 본문 파일은 항목 병합에서 내용 단위로 합쳐지지 않으므로 두 PC에서 같은 콘텐츠를 길게 수정했다면 필요한 내용을 따로 보관한 뒤 판단하는 편이 좋습니다.

이전 저장 시점 확인하기

섹션 제목: “이전 저장 시점 확인하기”

모든 버전 보기를 열면 이전 저장 시점으로 되돌리기 목록을 확인할 수 있습니다. 이전 버전이 없으면 저장된 이전 버전이 없습니다가 표시됩니다. 목록에서 저장 시점을 선택하고 미리보기로 내용을 확인합니다. 되돌릴 버전이 확실하면 이 버전 사용을 누르고 현재 데이터 교체 안내를 확인합니다.

이전 저장 시점은 클라우드에 남아 있는 워크스페이스 버전입니다. 콘텐츠 에디터의 문서 버전 히스토리와 범위가 다릅니다. 워크스페이스 전체의 기준을 바꾸는 작업인지, 문서 하나의 편집 이력을 확인하는 작업인지 구분합니다. 버전을 적용하는 동안 워크스페이스를 바꾸면 해소 작업이 취소될 수 있으므로 대상 워크스페이스를 계속 열어 둡니다.

보관함 사용하기

섹션 제목: “보관함 사용하기”

보관함은 원격 적용 전에 이 PC의 변경을 남겨 두는 로컬 보존 공간입니다. 설정 → 계정의 보관함에서 항목과 파일 수, 크기를 확인하고 내보내기로 별도 위치에 저장할 수 있습니다. 보관함 자체는 다른 PC에 전달되지 않습니다. 다른 PC에서도 필요하면 먼저 내보낸 파일을 별도로 옮겨 보관합니다.

보관함을 저장하지 못했다는 메시지가 보이면 원격 적용이나 합치기를 반복하지 말고 이 PC의 디스크 공간과 보관 위치의 권한을 확인합니다. 기본 보관 위치를 사용할 수 없어 다른 위치에 보존한 경우에는 목록에 표시된 실제 경로를 확인합니다. 보관함에 항목이 있다는 사실만으로 새 PC에도 같은 항목이 있을 것이라고 판단하지 않습니다.

라벨과 태그 해제의 한계

항목 병합은 한쪽에 남은 라벨과 태그 연결을 합칩니다. 한 PC에서 연결을 해제해도 다른 PC에 남아 있으면 다시 연결될 수 있습니다. 앱의 해제 안내를 확인하고 두 PC의 상태를 함께 점검합니다.

자주 묻는 질문

섹션 제목: “자주 묻는 질문”

모두 다른 기기를 선택하면 파일 본문도 합쳐지나요?

섹션 제목: “모두 다른 기기를 선택하면 파일 본문도 합쳐지나요?”

파일 본문은 병합되지 않습니다. 이 선택은 비교 화면에 표시되는 목록 정보의 남길 쪽을 정합니다. 스크린샷 두 장이나 콘텐츠 본문 두 개를 자동으로 하나의 파일로 만드는 기능은 아닙니다.

합칠 수 없다는 안내가 나오면 어떻게 하나요?

섹션 제목: “합칠 수 없다는 안내가 나오면 어떻게 하나요?”

현재 버전 조합에서는 항목 단위 합치기를 사용할 수 없는 상태입니다. 미리보기와 버전 차이를 확인한 뒤 버전 선택으로 해결합니다. 파일을 찾을 수 없어 제외되는 항목이 표시되면 필요한 원본이 어느 PC에 있는지도 확인합니다.

보관함에서 내보내면 바로 복원되나요?

섹션 제목: “보관함에서 내보내면 바로 복원되나요?”

내보내기는 보관 자료를 별도 파일로 저장하는 동작입니다. 현재 워크스페이스를 자동 교체하는 버튼이 아닙니다. 이전 원격 상태를 적용하려면 저장 시점 목록의 이 버전 사용 절차와 구분해서 사용합니다.
