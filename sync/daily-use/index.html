매일 동기화하기

동기화를 사용하는 기본 흐름은 한 PC에서 작업을 마친 뒤 다른 PC에서 이어 쓰는 방식입니다. AURORA는 로컬에 먼저 저장하고 변경 내용을 동기화 대상으로 전달합니다. 다른 PC의 자료는 워크스페이스를 열거나 원격 변경을 확인할 때 반영합니다. 두 PC에서 같은 자료를 동시에 편집하는 실시간 공동 편집 도구로 사용하면 버전 선택이 필요할 수 있습니다.

다른 PC로 작업을 넘기기

섹션 제목: “다른 PC로 작업을 넘기기”
  1. 현재 작업 중인 콘텐츠나 아이디어에서 저장 실패 안내가 없는지 확인합니다. 편집기 저장과 원격 전송은 서로 다른 단계입니다.
  2. 사용한 워크스페이스를 연 상태에서 지금 동기화를 실행합니다. 다른 워크스페이스를 선택한 상태에서 누르면 원하는 자료의 상태를 확인하기 어렵습니다.
  3. 동기화 중… 표시가 사라지고 오류나 대기 안내가 없는지 확인합니다. 큰 영상과 사진첩은 작은 메모보다 전달하는 데 오래 걸립니다.
  4. 첫 PC에서 해당 자료의 편집을 마칩니다. 전송 중에 컴퓨터를 끄거나 네트워크 연결을 끊으면 다른 PC에 최신 변경이 아직 없을 수 있습니다.
  5. 두 번째 PC에서 같은 워크스페이스를 엽니다. **클라우드에서 내려받는 중…**이 보이면 목록이 나타날 때까지 기다립니다.
  6. 방금 변경한 항목의 제목과 본문을 확인합니다. 필요한 파일의 다운로드가 끝난 뒤 편집을 시작합니다.
  7. 두 번째 PC에서도 작업을 마칠 때 같은 순서로 동기화합니다. 첫 PC로 돌아갈 때는 다시 최신 상태를 받아 사용합니다.

상태 표시 읽기

섹션 제목: “상태 표시 읽기”
표시 의미 다음 행동
동기화 중… 로컬 변경을 전달하거나 동기화 작업을 처리합니다. 작업이 끝날 때까지 연결을 유지합니다.
클라우드에서 내려받는 중… 워크스페이스 자료를 받는 중입니다. 완료되면 목록이 자동으로 표시됩니다.
오프라인, 대기 중 N건 전송할 작업이 남아 있습니다. 인터넷 또는 동기화 폴더 연결을 복구합니다.
다른 기기에서 변경된 내용이 있습니다 원격에 이 PC가 받지 않은 내용이 있습니다. 현재 작업을 저장한 뒤 지금 동기화합니다.
다른 기기에서 수정된 버전이 있습니다 두 PC의 변경 중 선택이 필요합니다. 버전 선택에서 내용을 비교합니다.
Google 계정 재연결이 필요합니다 현재 계정으로 전송할 수 없습니다. 다시 연결을 누르고 로그인합니다.
동기화 중 문제가 발생했습니다 동기화 작업을 마치지 못했습니다. 오류 내용을 확인하고 다시 시도합니다.

상태 배너는 다음 행동이 필요한 상황을 알려 줍니다. 경고가 없다는 사실과 모든 첨부파일이 이 PC에 내려받아졌다는 사실은 같지 않습니다. 다른 PC에서 만든 파일은 열람 시점에 받는 경우가 있습니다. 오프라인 사용을 준비할 때는 필요한 항목을 하나씩 열어 확인합니다.

자동 확인과 지금 동기화

섹션 제목: “자동 확인과 지금 동기화”

활성 동기화 워크스페이스는 약 5분 간격으로 다른 기기의 원격 변경을 확인합니다. 이 주기는 다른 PC의 변경을 발견하기 위한 확인 간격입니다. 편집하는 글자가 5분마다 반드시 다른 PC에 똑같이 나타난다는 보장은 아닙니다. 네트워크 상태, 진행 중인 작업, 원격 버전 선택 여부에 따라 반영 시점이 달라집니다.

지금 반영해야 할 변경이 있으면 지금 동기화를 사용합니다. 회의가 끝나고 노트북으로 이동할 때처럼 작업 기기를 바꾸기 전 실행하면 상태를 확인하기 쉽습니다. 버튼을 반복해서 누르기보다 현재 진행 표시를 보고 완료를 기다립니다. 오류 표시가 있으면 동기화 명령을 되풀이하기 전에 안내된 원인을 확인합니다.

오프라인에서 작업할 때

섹션 제목: “오프라인에서 작업할 때”

이미 저장한 로컬 파일은 인터넷 없이 열람할 수 있습니다. 콘텐츠와 아이디어의 로컬 편집도 원격 응답을 기다리는 작업과 구분됩니다. 다만 새로운 웹페이지를 가져오거나 다른 PC의 파일을 처음 내려받는 일에는 해당 서비스 또는 동기화 대상과의 연결이 필요합니다. 오프라인이라는 이유만으로 웹의 새 자료까지 가져올 수 있는 것은 아닙니다.

인터넷이 끊어진 동안 변경한 항목은 다시 연결한 뒤 전송 상태를 확인합니다. 같은 시간에 다른 PC에서도 편집했다면 충돌 안내가 나올 수 있습니다. 어느 PC에서 어떤 변경을 했는지 기억해 두면 비교 화면에서 선택하기 쉽습니다. 중요한 편집을 한 직후에는 먼저 전송한 PC와 이어 받는 PC의 내용을 모두 확인합니다.

같은 파일을 확인하는 방법

섹션 제목: “같은 파일을 확인하는 방법”

목록에 새 제목이 보이는지 확인한 다음 미리보기에서 본문, 이미지, 첨부를 차례로 엽니다. 콘텐츠가 여러 페이지라면 실제로 수정한 페이지를 선택합니다. 아이디어도 수정한 페이지 탭에서 텍스트나 도형을 확인합니다. 단순히 항목 수가 같다는 이유만으로 변경이 모두 반영되었다고 판단하지 않습니다.

큰 파일 하나를 여는 동안에는 다운로드 진행을 기다립니다. 썸네일과 목록 정보가 먼저 표시되고 원본은 뒤에 준비될 수 있습니다. 파일을 열지 못했다는 안내가 남으면 계정과 네트워크 상태를 확인한 뒤 다시 시도를 사용합니다. 동일한 항목을 새로 만들거나 원본 폴더를 직접 정리하는 행동은 원인을 확인한 다음으로 미룹니다.

기기를 바꾸기 전 확인

현재 편집 저장, 지금 동기화, 다른 PC에서 최신 내용 확인의 세 단계를 순서대로 진행합니다. 이 순서를 지키면 두 PC가 서로 다른 내용을 기준으로 편집하는 상황을 줄일 수 있습니다.

실시간 공동 편집은 지원하지 않습니다

같은 계정과 워크스페이스를 열었어도 두 PC의 편집 화면이 실시간으로 연결되지는 않습니다. 한 번에 한 PC에서 편집하는 방식을 기준으로 사용합니다.

자주 묻는 질문

섹션 제목: “자주 묻는 질문”

앱 창을 닫으면 동기화도 종료되나요?

섹션 제목: “앱 창을 닫으면 동기화도 종료되나요?”

창을 닫아도 앱이 트레이에 남아 있을 수 있습니다. 종료 여부는 트레이 아이콘으로 확인합니다. 전송을 확실히 마쳐야 할 때는 창을 닫는 것에 의존하지 말고 먼저 지금 동기화와 상태 표시를 확인합니다.

5분을 기다렸는데도 최신 내용이 없으면 어떻게 하나요?

섹션 제목: “5분을 기다렸는데도 최신 내용이 없으면 어떻게 하나요?”

작업한 PC에서 실제 업로드가 끝났는지 확인합니다. 받는 PC의 계정과 선택한 워크스페이스도 확인합니다. 그다음 지금 동기화를 실행합니다. 원격 변경이나 버전 선택 안내가 있으면 해당 안내를 먼저 처리합니다.

같은 이름의 워크스페이스면 자동 연결되나요?

섹션 제목: “같은 이름의 워크스페이스면 자동 연결되나요?”

이름만 같다고 같은 동기화 대상이 되는 것은 아닙니다. 다른 PC에서는 기존 원격 워크스페이스를 가져오는 절차를 사용합니다. 각각 새 워크스페이스를 생성했다면 연결 상태를 별도로 확인합니다.
