확장으로 스크랩

확장으로 저장하면 현재 브라우저 탭에서 캡처한 결과를 AURORA가 보관합니다. 로그인 후 열린 화면을 저장하거나 페이지 요소를 직접 선택할 때 사용합니다. 먼저 브라우저에 확장을 등록하고 AURORA를 실행합니다. 팝업에서 저장할 워크스페이스와 카테고리를 고른 뒤 범위와 포맷을 확인합니다. 캡처가 끝나면 앱에서 실제 저장 결과를 확인합니다.

현재 페이지 저장하기

섹션 제목: “현재 페이지 저장하기”
  1. AURORA를 실행하고 트레이 아이콘을 확인합니다. 브라우저에서 저장할 페이지를 엽니다. 로그인이 필요한 경우에는 먼저 로그인하고 원하는 본문이 보이는 상태로 이동합니다. 접힌 설명이나 아직 불러오지 않은 이미지가 있으면 저장 전에 펼치고 기다립니다.
  2. 브라우저 도구 모음의 Aurora Scrap 아이콘을 누릅니다. 팝업 위쪽에 연결됨이 표시되는지 확인합니다. 미연결이면 앱을 실행한 뒤 팝업을 다시 엽니다. 페이지 우클릭 메뉴의 Aurora Scrap으로 스크랩으로도 옵션 화면을 열 수 있습니다.
  3. 현재 페이지 URL을 확인합니다. 팝업은 현재 탭을 대상으로 하므로 다른 탭을 보고 있다면 원하는 페이지로 이동한 뒤 다시 엽니다. 주소가 예상과 다르면 저장을 시작하지 말고 원본 탭부터 확인합니다.
  4. 워크스페이스와 카테고리를 선택합니다. 공간을 바꾸면 해당 공간의 카테고리를 확인합니다. 카테고리 없음이 표시되면 앱에서 카테고리를 만든 뒤 다시 시도합니다. 저장 위치가 준비되어 있어야 작업을 시작할 수 있습니다.
  5. 스크랩 영역에서 전체 또는 콘텐츠를 선택합니다. 전체는 페이지를 넓게 보관할 때 사용합니다. 콘텐츠는 글의 본문 영역을 중심으로 저장할 때 사용합니다. 원하는 요소를 직접 선택할 때에는 아래의 사용자지정 절차를 사용합니다.
  6. 저장 포맷에서 필요한 이미지나 PDF를 선택합니다. **MHTML (항상 포함)**은 페이지 아카이브입니다. 화면의 시각적 상태가 중요하면 PNG 또는 JPG를 함께 저장합니다. 문서로 읽거나 인쇄하려면 PDF 결과도 확인합니다.
  7. 스크랩하기를 누릅니다. 스크랩 중… 안내가 표시되는 동안 원본 탭을 닫지 않습니다. 페이지를 다른 주소로 바꾸거나 로그인 상태를 변경하는 작업도 캡처가 끝난 뒤에 진행합니다. 완료 안내 후 AURORA의 목록으로 이동합니다.
  8. 저장된 항목을 열어 위쪽과 아래쪽을 확인합니다. 로그인한 본문, 중요한 표, 마지막 문장이 들어 있는지 확인합니다. 아카이브와 스크린샷은 저장되는 범위나 열람 방식이 다를 수 있으므로 필요한 파일을 각각 점검합니다.

범위별 선택 기준

섹션 제목: “범위별 선택 기준”
선택 사용 목적 결과를 확인할 부분
전체 페이지 전체 모습 보관 머리글, 본문, 아래쪽 내용
콘텐츠 자동으로 찾은 본문 보관 제목과 본문의 시작 및 끝
사용자지정 클릭한 페이지 요소 보관 선택한 경계와 실제 저장 영역
PNG 선명한 이미지 보관 작은 글자와 그림의 세부 내용
JPG 압축 이미지 보관 글자 선명도와 파일 용량
PDF 문서 형태 보관 페이지 나눔과 표 잘림
MHTML 페이지 아카이브 보관 필요한 리소스가 함께 열리는지

사용자지정 영역 선택하기

섹션 제목: “사용자지정 영역 선택하기”
  1. 팝업에서 저장 위치와 포맷을 먼저 정합니다. 사용자지정을 선택해 영역 선택을 시작합니다. 안내에 따라 페이지 위에서 원하는 요소를 가리킵니다. 웹페이지의 글 블록이나 이미지처럼 요소 단위로 선택하는 방식입니다.
  2. 스크랩할 영역을 클릭하세요. ESC 키로 취소합니다. 안내를 확인합니다. 강조된 경계가 저장하려는 부분을 포함하는지 살펴봅니다. 너무 넓거나 좁은 영역을 고르지 않도록 제목과 마지막 문단을 함께 확인합니다.
  3. 원하는 영역을 클릭합니다. 선택한 영역의 저장이 시작되면 앱에서 결과를 확인합니다. 취소하려면 Esc를 누릅니다. 사각형을 자유롭게 그려 화면 일부를 저장하려면 앱의 새 화면캡처 > 자유 영역을 사용합니다.

범위에 따라 파일 내용이 다를 수 있습니다

콘텐츠나 사용자지정으로 화면 일부를 캡처해도 MHTML은 전체 페이지 아카이브로 보관될 수 있습니다. 선택 영역의 이미지와 HTML 보기만 보고 모든 저장 파일이 같은 범위라고 판단하지 않습니다. 외부에 전달할 파일은 실제로 열어서 내용을 확인합니다.

긴 페이지와 원본 배율

섹션 제목: “긴 페이지와 원본 배율”

긴 페이지는 원본 배율을 유지하며 여러 부분으로 나누어 캡처할 수 있습니다. 캡처 중에 페이지 높이에 맞추어 여러 이미지 조각을 처리하므로 짧은 페이지보다 시간이 걸릴 수 있습니다. 사용자에게 보이는 최종 결과는 앱에서 확인합니다. 긴 페이지를 무조건 한 화면 크기로 축소했다고 생각하거나, 항상 여러 독립 파일로 저장된다고 가정하지 않습니다.

저장 전에 페이지 내용을 끝까지 불러왔는지 확인합니다. 무한히 이어지는 목록은 사용자가 아직 열지 않은 내용까지 모두 저장하는 것으로 보장되지 않습니다. 필요한 부분이 나타나도록 먼저 탐색합니다. 저장 결과에서 반복되는 머리글, 빈 영역, 잘린 문장이 보이면 콘텐츠 범위나 사용자지정 영역으로 필요한 내용을 나누어 확인합니다.

자주 묻는 질문

섹션 제목: “자주 묻는 질문”

로그인 후 본문도 저장되나요?

섹션 제목: “로그인 후 본문도 저장되나요?”

현재 브라우저 탭에 표시된 화면을 캡처합니다. 로그인한 뒤 원하는 본문을 실제로 연 상태에서 시작합니다. 다만 화면에 보이는 모든 동작이나 서버 기능을 오프라인으로 재현하는 것은 아닙니다. 저장 후에는 필요한 본문과 이미지가 들어 있는지 확인합니다.

사용자지정이 자유 영역 화면 캡처와 같은가요?

섹션 제목: “사용자지정이 자유 영역 화면 캡처와 같은가요?”

사용자지정은 웹페이지 요소를 클릭해 선택합니다. 앱의 자유 영역은 화면에서 사각형을 직접 지정합니다. 글 블록을 보존하려면 확장의 사용자지정을 사용하고, 앱이나 브라우저 화면의 일부를 이미지로 남기려면 자유 영역을 사용합니다.

캡처 시간이 초과되면 어떻게 하나요?

섹션 제목: “캡처 시간이 초과되면 어떻게 하나요?”

원본 페이지를 다시 불러오고 필요한 내용이 표시될 때까지 기다립니다. 이후 한 번 더 시도합니다. 매우 긴 페이지라면 필요한 콘텐츠 영역을 선택합니다. 같은 오류가 반복되면 앱에서 이미 생성된 항목의 상태도 확인하고 캡처 문제 해결 문서를 참고합니다.
