동영상 다운로드

AURORA는 지원되는 사이트에서 영상을 MP4 또는 MP3로 저장할 수 있습니다. 웹페이지에 포함된 동영상과 오디오를 찾는 기능도 제공합니다. 영상 다운로드와 페이지 캡처는 서로 다른 결과를 만듭니다. 영상 자체가 필요하면 다운로드 모드를 사용하고, 제목이나 설명을 포함한 페이지 모습이 필요하면 페이지 캡처를 사용합니다. 모든 사이트나 모든 영상의 저장을 보장하지 않으므로 완료 후 실제 파일과 재생 상태를 확인합니다.

영상 주소로 다운로드하기

섹션 제목: “영상 주소로 다운로드하기”
  1. 지원되는 사이트에서 저장할 영상 페이지를 엽니다. 라이브 방송인지 일반 영상인지 확인합니다. 저장할 권한이 있는 자료인지 확인한 다음 주소를 복사합니다. 영상 재생에 필요한 접근 조건이 있다면 다운로드가 제한될 수 있습니다.
  2. AURORA에서 저장할 워크스페이스와 카테고리를 선택합니다. 파일 > 새 웹스크랩을 엽니다. macOS에서는 파일 > 새 스크랩을 사용합니다. URL에 영상 주소 전체를 붙여 넣습니다. 제목이 자동으로 감지되면 대상 영상이 맞는지 확인합니다.
  3. 해당 사이트가 동영상 사이트로 분류되면 동영상 다운로드와 페이지 캡처 선택을 확인합니다. 영상 파일을 저장할 때에는 동영상 다운로드를 사용합니다. 목록에 등록한 사이트라는 사실만으로 해당 사이트의 모든 영상이 내려받아지는 것은 아닙니다.
  4. MP4 영상 또는 MP3 오디오를 선택합니다. 화면과 소리가 모두 필요하면 MP4를 사용합니다. 소리만 필요한 자료는 MP3를 선택합니다. 선택을 바꾼 뒤 현재 표시된 형식을 확인하고 저장을 시작합니다.
  5. 다운로드 전에 원본 사이트의 이용 조건을 확인합니다. 개인 오프라인 보관에 필요한 자료를 대상으로 진행합니다. 다운로드한 파일의 재배포 가능 여부는 별도로 확인합니다. 보호된 콘텐츠나 라이브 방송은 일반 영상과 같은 방식으로 저장되지 않을 수 있습니다.
  6. 목록에서 다운로드 진행을 확인합니다. 영상 정보를 가져오는 단계와 실제 다운로드 단계는 다릅니다. 백분율이나 저장 중 안내가 보이면 작업이 끝날 때까지 기다립니다. 같은 주소를 연속으로 보내기 전에 기존 항목 상태를 확인합니다.
  7. 완료한 항목을 열어 영상 또는 오디오를 재생합니다. 제목만 저장된 것은 아닌지 확인합니다. 파일 크기와 목록의 영상 배지도 살펴봅니다. 다운로드 실패 뒤 일반 스크랩으로 전환되었다면 저장된 결과는 영상 파일과 다를 수 있습니다.

옵션과 결과 비교

섹션 제목: “옵션과 결과 비교”
항목 의미 확인할 점
동영상 다운로드 영상 또는 오디오 파일 저장 사이트 지원 여부와 실제 완료 상태
페이지 캡처 영상 페이지의 화면 저장 영상 자체의 오프라인 재생과 구분
MP4 영상 영상 파일 형식 영상과 소리가 필요한 경우
MP3 오디오 소리 파일 형식 화면이 필요 없는 경우
페이지 내 동영상/오디오 다운로드 페이지에서 미디어 탐지 발견된 미디어와 저장 결과
최대 용량 미디어 다운로드의 크기 제한 큰 파일 누락 여부와 남은 공간
동영상 사이트 영상 모드로 처리할 사이트 목록 목록 등록과 실제 지원은 별개
동영상 내려받기 클라우드의 기존 영상 받기 원본 사이트에서 새로 저장하는 작업과 구분

페이지에 포함된 미디어 저장

섹션 제목: “페이지에 포함된 미디어 저장”
  1. 환경설정을 열고 스크랩 탭으로 이동합니다. 페이지 내 동영상/오디오 다운로드를 확인합니다. 페이지의 미디어를 함께 보관하려면 켭니다. 설명에 있는 로컬 저장 목적을 확인하고 필요한 작업에 적용합니다.
  2. 최대 용량을 선택합니다. 현재 선택지는 100 MB, 500 MB, 1 GB, 2 GB, 무제한입니다. 이 값은 페이지 미디어 다운로드에 관한 선택입니다. 워크스페이스 요금제의 총용량 한도와 실제 디스크 공간을 없애는 설정은 아닙니다.
  3. 페이지를 저장한 뒤 진행 메시지에서 미디어 탐지와 다운로드 상태를 확인합니다. 목록에 영상 수 또는 크기 배지가 나타나면 해당 항목을 엽니다. 미디어에서 원하는 동영상과 오디오가 포함되어 있는지 확인합니다.
  4. 오프라인으로 사용하려면 실제 재생 상태도 확인합니다. HTML이나 MHTML이 저장되었다고 포함된 모든 영상까지 자동 보존되는 것은 아닙니다. 페이지 파일과 다운로드된 미디어 파일의 결과를 각각 확인합니다.

라이브 방송은 페이지로 전환될 수 있습니다

진행 중인 라이브 방송은 저장할 수 없습니다. 라이브로 감지되면 페이지 모드 또는 화면 스크랩으로 전환한다는 안내가 나타날 수 있습니다. 방송 종료 후 공개된 다시보기 영상이 제공되면 해당 주소로 다시 시도합니다.

다른 PC에서 영상 내려받기

섹션 제목: “다른 PC에서 영상 내려받기”

동기화된 목록에 영상 항목이 보여도 실제 영상 파일이 이 PC에 없을 수 있습니다. 미리보기에 동영상이 아직 이 PC에 없습니다가 표시되면 동영상 내려받기를 누릅니다. 이 버튼은 클라우드에 저장된 기존 파일을 받습니다. 사이트의 최신 영상을 다시 다운로드하는 기능과는 다릅니다.

파일을 내려받는 동안 인터넷 연결을 유지합니다. 원래 저장한 PC에서 업로드가 끝나지 않았다면 해당 PC의 앱 실행과 동기화 상태를 확인합니다. 내려받기가 끝난 뒤 재생해 원하는 파일이 맞는지 확인합니다. 큰 파일은 시간이 걸릴 수 있으므로 목록의 제목이 나타난 시점과 파일 준비가 끝난 시점을 구분합니다.

자주 묻는 질문

섹션 제목: “자주 묻는 질문”

동영상 사이트에 추가하면 모든 영상이 저장되나요?

섹션 제목: “동영상 사이트에 추가하면 모든 영상이 저장되나요?”

사이트 목록은 주소를 영상 다운로드 모드로 처리하는 기준입니다. 해당 사이트의 보호 방식, 로그인 조건, 영상 제공 방식에 따라 다운로드가 실패할 수 있습니다. 실패하면 안내를 확인하고 페이지 캡처로 보관 가능한 정보를 확인합니다.

최대 개수나 오디오 포함 설정은 어디에 있나요?

섹션 제목: “최대 개수나 오디오 포함 설정은 어디에 있나요?”

현재 설정 화면에서는 페이지 내 동영상과 오디오 다운로드 및 최대 용량을 조절합니다. 영상의 소리만 저장하려면 다운로드 모드에서 MP3 오디오를 사용합니다. 미디어의 종류와 개수는 저장 후 미디어 목록에서 확인합니다.

완료했는데 영상이 재생되지 않으면 어떻게 하나요?

섹션 제목: “완료했는데 영상이 재생되지 않으면 어떻게 하나요?”

다운로드가 완료된 파일인지, 일반 페이지 캡처로 전환된 결과인지 확인합니다. 다른 PC의 동기화 항목이라면 먼저 파일을 내려받습니다. 실제 재생 상태와 파일 존재 여부를 확인한 뒤 미디어 문제 해결 문서를 참고합니다.
