파일과 폴더 가져오기

PC에 있는 파일을 AURORA로 가져오면 웹스크랩과 같은 목록에서 정리할 수 있습니다. 이미지와 PDF는 파일을 보관하고, 텍스트는 편집 가능한 콘텐츠로 변환합니다. 이미지가 든 폴더를 끌어 놓으면 폴더 이름을 제목으로 하는 사진첩을 만들 수 있습니다. 가져오기 전에 저장할 워크스페이스와 카테고리를 선택합니다. 파일 종류에 따라 결과 형태가 달라지므로 처음에는 소수의 파일로 확인합니다.

파일 선택으로 가져오기

섹션 제목: “파일 선택으로 가져오기”
  1. 가져올 원본 파일을 준비합니다. 이미지는 PNG, JPG 등 지원 형식인지 확인합니다. PDF는 일반 뷰어에서 열리는지 확인합니다. PSD와 AI는 미리보기용 정보가 포함된 파일이어야 하므로 아래의 형식별 설명도 확인합니다.
  2. AURORA에서 워크스페이스와 카테고리를 선택합니다. 카테고리가 없다면 먼저 만듭니다. 파일 가져오기는 선택한 카테고리로 진행되므로 파일 선택 전에 저장 위치를 확인합니다. 다른 공간으로 이동한 직후라면 현재 탭 이름도 확인합니다.
  3. 파일 > 파일 가져오기를 선택합니다. macOS에서는 화면 위쪽 파일 메뉴를 사용합니다. 파일 선택 창에서 이미지 · PDF · 텍스트 필터에 표시되는 파일을 선택합니다. 여러 파일을 함께 선택할 수 있습니다. 파일을 골랐다면 선택을 확정합니다.
  4. 가져오기 진행이 끝날 때까지 기다립니다. PDF의 썸네일이나 디자인 파일의 미리보기를 만드는 동안 시간이 걸릴 수 있습니다. 파일을 선택한 직후 썸네일이 없다는 이유로 같은 파일을 다시 보내지 않습니다. 완료된 파일 수와 건너뛴 파일 안내를 확인합니다.
  5. 목록에서 가져온 항목을 선택합니다. 이미지와 PDF는 미리보기를 확인합니다. 텍스트 파일은 콘텐츠 편집 화면에서 변환 결과를 확인합니다. 제목과 메모를 정리하고 필요하면 라벨이나 태그를 추가합니다.
  6. 여러 파일 중 일부를 가져오지 못했다는 안내가 나오면 표시된 이름을 확인합니다. 성공한 파일도 목록에서 확인합니다. 실패한 파일만 원본의 형식과 상태를 점검한 뒤 다시 가져오면 중복 등록을 줄일 수 있습니다.

지원 형식과 결과

섹션 제목: “지원 형식과 결과”
분류 확장자 가져온 뒤 확인할 내용
일반 이미지 png, jpg, jpeg, gif, webp, bmp, avif 이미지와 썸네일
벡터 이미지 svg 미리보기의 표시 결과
PDF pdf 문서 내용과 미리보기
Photoshop 문서 psd 내장 합성 이미지로 만든 미리보기
Illustrator 문서 ai PDF 호환 정보로 만든 미리보기
일반 텍스트 txt, log 콘텐츠로 변환된 문단
Markdown md, markdown 콘텐츠로 변환된 본문
HTML html, htm 콘텐츠로 가져온 본문
표 데이터 csv, tsv 표로 변환된 행과 열
구조화된 텍스트 json, xml, yaml, yml 코드 블록으로 표시된 내용

텍스트 형식은 위 표의 열두 가지 확장자를 처리합니다. 다만 파일 선택 창에는 txt, md, markdown이 표시됩니다. 다른 텍스트 형식은 파일을 기본 화면에 직접 끌어 놓는 방법을 사용합니다. 가져온 본문은 원래 파일을 그대로 편집하는 방식과 다르므로, 글자와 표의 변환 결과를 확인한 뒤 작업합니다.

드래그앤드롭으로 가져오기

섹션 제목: “드래그앤드롭으로 가져오기”
  1. 탐색기 또는 Finder에서 가져올 파일을 선택합니다. AURORA의 기본 목록 화면으로 끌어 놓습니다. 본문 편집기 안에 놓는 동작은 해당 콘텐츠에 삽입하는 작업일 수 있으므로 독립 항목으로 등록할 때에는 기본 화면을 사용합니다.
  2. 여러 파일을 한 번에 넣었다면 완료 개수와 건너뛴 이름을 확인합니다. 지원하지 않는 파일은 등록되지 않을 수 있습니다. 목록에 보이는 마지막 항목만 확인하지 말고 필요한 파일이 모두 들어왔는지 제목을 비교합니다.
  3. 폴더를 가져오려면 이미지가 들어 있는 폴더 자체를 기본 화면에 끌어 놓습니다. 폴더 이름을 제목으로 사진첩이 만들어집니다. 모든 종류의 파일을 그대로 복제하는 폴더 백업 기능으로 생각하지 않습니다. 사진첩에 포함된 이미지 수와 내용을 확인합니다.
  4. 사진첩이 만들어졌다면 열어서 첫 이미지와 마지막 이미지를 확인합니다. 여러 사진을 따로 정리하려면 사진첩 안의 이동이나 삭제 기능을 사용합니다. 가져오기 이후의 정렬, ZIP 저장, 이미지 추가는 사진첩 문서에서 안내합니다.

PSD와 AI는 원본 저장 방식에 영향을 받습니다

PSD는 합성 미리보기 정보가 있어야 합니다. AI는 PDF 호환으로 저장된 파일이어야 합니다. 필요한 정보가 없으면 미리보기를 만들지 못하거나 가져오기를 건너뛸 수 있습니다. 원래 제작 프로그램에서 저장 옵션을 확인한 뒤 다시 가져옵니다.

가져온 자료 정리하기

섹션 제목: “가져온 자료 정리하기”

이미지나 PDF를 가져온 뒤에는 저장된 파일과 원본 파일을 구분합니다. AURORA 안에서 자료를 찾을 때에는 항목 제목과 카테고리를 사용합니다. 파일 이름에 날짜나 프로젝트 이름이 들어 있어도 목록 제목이 읽기 불편하다면 알아보기 쉽게 수정합니다. 원본을 확인해야 할 때에는 저장한 항목의 폴더를 열어 어떤 파일이 보관되었는지 살펴봅니다.

텍스트를 가져온 경우에는 내용이 콘텐츠로 변환됩니다. 문단, 표, 코드 블록의 구조를 읽어 보고 필요한 부분을 정리합니다. CSV나 TSV는 행과 열이 맞는지 확인합니다. JSON이나 YAML은 들여쓰기와 기호를 확인합니다. 텍스트 파일의 원본을 보존해야 한다면 원본도 별도로 관리하며, 변환된 본문만으로 원본 파일의 모든 특성이 유지된다고 판단하지 않습니다.

자주 묻는 질문

섹션 제목: “자주 묻는 질문”

파일 선택 창에서 CSV가 보이지 않습니다. 어떻게 하나요?

섹션 제목: “파일 선택 창에서 CSV가 보이지 않습니다. 어떻게 하나요?”

현재 파일 선택 필터는 일부 텍스트 확장자만 보여 줍니다. CSV 파일을 탐색기나 Finder에서 기본 화면으로 끌어 놓습니다. 가져오기가 끝나면 콘텐츠의 표에서 행과 열이 예상대로 나뉘었는지 확인합니다.

폴더를 가져오면 원래 하위 폴더 구조도 그대로 생기나요?

섹션 제목: “폴더를 가져오면 원래 하위 폴더 구조도 그대로 생기나요?”

폴더 가져오기는 이미지로 사진첩을 만드는 용도로 사용합니다. 원본 폴더 구조를 카테고리 트리로 그대로 복제하는 작업으로 보장하지 않습니다. 저장 위치는 미리 선택한 카테고리이며, 생성된 사진첩을 열어 포함된 이미지를 확인합니다.

일부 파일만 실패하면 전부 다시 가져와야 하나요?

섹션 제목: “일부 파일만 실패하면 전부 다시 가져와야 하나요?”

먼저 성공한 항목을 목록에서 확인합니다. 안내에 나온 실패 파일만 원본 상태와 지원 형식을 점검합니다. PSD와 AI라면 호환 미리보기 포함 여부도 확인합니다. 전체 묶음을 다시 넣기보다 실패한 파일을 구분해서 처리합니다.
