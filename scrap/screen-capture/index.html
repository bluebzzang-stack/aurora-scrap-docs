화면 캡처

화면 캡처는 모니터에 보이는 내용을 이미지로 저장합니다. 웹주소를 입력하지 않아도 앱 화면, 문서 일부, 작업 결과를 보관할 수 있습니다. AURORA는 전체 화면, 창 선택, 자유 영역의 세 가지 모드를 제공합니다. 캡처 결과는 선택한 카테고리에 이미지 항목으로 등록됩니다. 웹페이지의 HTML이나 본문 텍스트가 필요하다면 URL 스크랩 또는 브라우저 확장을 사용합니다.

캡처 시작하기

섹션 제목: “캡처 시작하기”
  1. AURORA에서 저장할 워크스페이스와 카테고리를 선택합니다. 카테고리가 없다면 먼저 만듭니다. 다른 프로그램을 캡처할 때에도 결과를 보관할 위치는 AURORA에서 정합니다. 저장 위치를 확인한 다음 캡처할 화면을 준비합니다.
  2. 캡처할 프로그램이나 문서를 엽니다. 필요한 내용이 실제로 화면에 보이도록 스크롤하고 창 크기를 조절합니다. 작은 글자가 중요하면 원래 프로그램에서 보기 배율을 조절합니다. 캡처 뒤에 이미지를 확대해도 원래 보이지 않던 내용이 새로 생기지는 않습니다.
  3. 파일 > 새 화면캡처를 엽니다. Windows에서는 앱 창 안의 메뉴를 사용합니다. macOS에서는 화면 위쪽의 네이티브 파일 메뉴를 사용합니다. 트레이 메뉴의 새 화면캡처에서도 같은 세 가지 모드에 접근할 수 있습니다.
  4. 화면 전체가 필요하면 전체 화면을 선택합니다. 특정 프로그램만 필요하면 창 선택을 고릅니다. 작은 부분만 잘라 저장하려면 자유 영역을 선택합니다. 캡처 목적에 맞추어 모드를 선택하면 나중에 불필요한 영역을 확인하는 시간을 줄일 수 있습니다.
  5. macOS에서 화면 기록 권한 안내가 나오면 시스템 설정 > 개인정보 보호 및 보안 > 화면 기록에서 Aurora Scrap을 허용합니다. 이후 앱을 다시 시작하고 캡처를 실행합니다. 권한을 허용하기 전에는 화면을 얻지 못할 수 있습니다.
  6. 캡처가 끝나면 AURORA 목록에서 새 이미지 항목을 확인합니다. 미리보기에서 내용이 맞는지 읽습니다. 필요하면 제목을 알아보기 쉽게 정리하고 메모를 남깁니다. 저장 파일을 직접 확인하려면 폴더 열기를 사용합니다.

상단의 새 화면캡처 메뉴에서 전체 화면, 창 선택, 자유 영역 중 하나를 선택합니다.

캡처 모드 비교

섹션 제목: “캡처 모드 비교”
모드 선택 방식 적합한 경우 확인할 부분
전체 화면 화면을 캡처 여러 창의 배치나 화면 상태 보관 불필요한 창이 함께 들어갔는지
창 선택 목록에서 창 클릭 특정 프로그램의 작업 화면 보관 같은 제목의 다른 창을 고르지 않았는지
자유 영역 화면 위에서 영역 지정 문서 일부나 작은 그림 보관 필요한 문장과 경계가 잘리지 않았는지
트레이 진입 트레이 메뉴에서 모드 선택 앱 창을 닫은 상태에서 캡처 앱이 실제 실행 중인지
파일 메뉴 진입 앱에서 모드 선택 카테고리를 확인한 뒤 캡처 저장 위치가 맞는지

창 선택으로 캡처하기

섹션 제목: “창 선택으로 캡처하기”
  1. 새 화면캡처 > 창 선택을 실행합니다. 캡처할 창을 선택하세요 화면에서 목록과 썸네일을 살펴봅니다. 비슷한 창이 여러 개라면 이름만 보고 고르지 말고 표시된 내용도 확인합니다.
  2. 저장할 창을 클릭합니다. 캡처가 끝난 뒤 AURORA에서 결과를 확인합니다. 예상과 다른 창이 저장되었으면 캡처할 프로그램을 명확히 표시한 뒤 다시 선택합니다. 창 목록에 없다면 그 프로그램이 실제로 열려 있는지 확인합니다.
  3. **캡처할 수 있는 창이 없습니다.**라는 안내가 나오면 창 준비 상태와 권한을 점검합니다. 원하는 창을 열고 다시 실행합니다. 캡처할 내용이 보이지만 창 목록에서 고르기 어렵다면 전체 화면 또는 자유 영역을 검토합니다.

자유 영역으로 캡처하기

섹션 제목: “자유 영역으로 캡처하기”
  1. 저장할 내용을 화면에 배치합니다. 새 화면캡처 > 자유 영역을 선택합니다. 영역 선택 화면이 나타나면 필요한 부분을 지정합니다. 문장 마지막이나 표의 바깥선까지 포함하는지 살펴봅니다.
  2. 잘못 선택했다면 Esc로 취소하고 다시 시작합니다. 취소는 저장 실패가 아니므로 결과 항목이 생기지 않을 수 있습니다. 필요한 범위를 다시 준비한 뒤 같은 메뉴에서 재실행합니다.
  3. 다른 프로그램이 전체 화면을 사용해 영역 선택을 열 수 없다는 안내가 나오면 해당 프로그램을 창 모드로 바꿉니다. 변경하기 어려우면 전체 화면 캡처를 사용합니다. 선택 화면이 열리지 않는데 같은 동작을 계속 반복하지 않습니다.

메뉴로 캡처를 시작합니다

이 안내의 캡처 진입점은 파일 메뉴와 트레이 메뉴입니다. 웹스크랩용 Ctrl+N (macOS는 Cmd+N)은 화면 캡처 명령이 아닙니다. 키보드 단축키가 필요한 작업은 단축키 문서에서 해당 명령을 확인하고, 캡처는 표시된 모드 메뉴를 사용합니다.

저장 결과 활용하기

섹션 제목: “저장 결과 활용하기”

캡처 이미지는 다른 스크랩 항목처럼 목록에서 열 수 있습니다. 제목과 메모를 정리하고 라벨이나 태그를 추가하면 나중에 목적별로 찾기 쉽습니다. 작업 화면을 여러 번 기록한다면 제목에 상황을 구분할 말을 넣습니다. 저장일만으로 구분하기 어려운 경우에는 메모에 확인하려던 문제나 작업 단계를 남깁니다.

이미지 속 글자를 편집 가능한 텍스트로 활용하고 싶다면 OCR을 사용합니다. 화면 캡처가 곧 본문 추출을 뜻하지는 않습니다. OCR 결과는 원본 이미지와 대조합니다. 작은 글자, 표, 특수문자는 정확하지 않을 수 있으므로 필요한 문장을 직접 확인한 뒤 사용합니다.

자주 묻는 질문

섹션 제목: “자주 묻는 질문”

화면 아래에 숨겨진 웹페이지도 함께 저장되나요?

섹션 제목: “화면 아래에 숨겨진 웹페이지도 함께 저장되나요?”

화면 캡처는 표시된 화면을 대상으로 합니다. 스크롤 아래의 긴 페이지를 보관하려면 브라우저 확장의 전체 또는 콘텐츠 캡처를 사용합니다. 목적에 따라 화면 캡처와 페이지 캡처를 구분하면 결과 누락을 줄일 수 있습니다.

캡처했는데 아무 항목도 생기지 않았습니다. 어떻게 하나요?

섹션 제목: “캡처했는데 아무 항목도 생기지 않았습니다. 어떻게 하나요?”

선택 과정에서 취소했는지 확인합니다. 권한이나 캡처 실패 안내도 확인합니다. 저장 대상으로 선택했던 카테고리를 열고 목록을 확인합니다. macOS에서 권한을 새로 허용했다면 앱을 다시 시작한 뒤 실행합니다.

이미지 대신 PDF나 HTML로 저장할 수 있나요?

섹션 제목: “이미지 대신 PDF나 HTML로 저장할 수 있나요?”

이 기능은 화면을 이미지로 보관하는 작업입니다. 웹페이지의 PDF나 HTML 아카이브가 필요하면 URL 스크랩에서 해당 포맷을 사용합니다. 화면의 시각적 기록과 페이지 문서 보관은 필요한 정보에 맞추어 선택합니다.
