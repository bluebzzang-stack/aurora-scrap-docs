릴리스 노트

AURORA의 주요 변경을 최신 버전부터 안내합니다. 각 항목은 사용자에게 보이는 기능과 오류 수정을 요약합니다. 현재 설치된 버전은 도움말 → Aurora Scrap 정보에서 확인합니다. 업데이트는 트레이의 업데이트 확인 또는 설정의 자동 업데이트를 사용합니다.

v1.1.3 · 2026년 9월 14일

섹션 제목: “v1.1.3 · 2026년 9월 14일”
  • 긴 웹페이지를 원본 픽셀 배율을 유지하는 분할 캡처 방식으로 저장합니다.
  • 큰 이미지 합성 중 과도한 메모리 사용으로 앱이 종료될 수 있던 문제를 수정했습니다.
  • 네이버 게시글의 내부 프레임 때문에 본문 아래쪽이 잘리던 문제를 개선했습니다.
  • 이미지, 폰트와 본문 로딩 대기를 보강해 웹 스크랩 결과의 누락을 줄였습니다.
  • URL을 바꾼 뒤 제목을 다시 자동으로 가져오도록 수정했습니다.
  • 로그인 후 페이지는 브라우저 확장으로 스크랩하도록 입력 화면에 안내합니다.
  • 확장 설치 안내에 OS별 실제 폴더 경로를 표시하고 macOS 폴더 이동 방법을 추가했습니다.
  • macOS 편집 전체 화면에서 제목과 편집 버튼의 위치 및 클릭 동작을 개선했습니다.

v1.1.2 · 2026년 9월 14일

섹션 제목: “v1.1.2 · 2026년 9월 14일”
  • 아이디어 보드의 텍스트 입력, 노드 생성과 통합검색 관련 동작을 개선했습니다.
  • 곡선 연결선의 화살촉이 선의 끝부분 방향에 맞게 보이도록 조정했습니다.
  • 중첩 체크리스트와 본문 이미지 툴바의 표시를 개선했습니다.
  • Google Drive 동기화의 오류 안내를 개선했습니다.
  • 스크랩에 사용할 브라우저를 찾지 못했을 때 원인을 이해할 수 있는 안내를 표시합니다.

v1.1.1 · 2026년 9월 11일

섹션 제목: “v1.1.1 · 2026년 9월 11일”
  • Windows와 macOS용 정식 설치 버전을 공개했습니다.
  • Windows 앱과 설치 파일에 BLUEB 게시자 서명을 적용한 배포본을 제공합니다.
  • macOS Intel과 Apple Silicon용 서명 및 공증된 배포본을 제공합니다.
  • macOS 다운로드에서 사용하는 CPU에 맞는 설치 파일을 선택할 수 있도록 안내를 개선했습니다.

v1.1.0 · 2026년 9월 11일

섹션 제목: “v1.1.0 · 2026년 9월 11일”
  • 도형, 텍스트, 연결선, 이미지와 마인드맵을 다루는 아이디어 보드를 추가했습니다.
  • 콘텐츠를 여러 페이지로 나누고 페이지별로 편집할 수 있습니다.
  • 아이디어와 콘텐츠의 자동 저장 실패를 표시하고 잘못 읽은 파일을 빈 자료로 덮어쓰지 않도록 보호합니다.
  • 워크스페이스를 바꾸기 전에 대기 중인 편집 저장을 처리하도록 개선했습니다.
  • 다른 PC에서 만든 아이디어와 콘텐츠를 처음 열 때 필요한 파일을 내려받도록 수정했습니다.
  • 본문과 아이디어에 넣은 이미지의 첨부 관리 및 재삽입을 개선했습니다.
  • 새 콘텐츠와 아이디어가 같은 간편 실행 설정을 따릅니다.
  • 라이선스와 워크스페이스 용량 안내를 보강했습니다.

v1.0.8 · 2026년 8월 31일

섹션 제목: “v1.0.8 · 2026년 8월 31일”
  • 라이선스 등록과 워크스페이스 개수 및 용량 한도 안내를 추가했습니다.
  • 첫 실행에서 앱 안에서 자료 저장 위치를 선택할 수 있습니다.
  • 설정의 저장 경로를 실제 위치를 보여 주는 읽기 전용 표시로 바꿨습니다.
  • 자동 업데이트를 끄고 새 버전 알림만 받는 옵션을 추가했습니다.
  • 새 워크스페이스와 저장 폴더 열기 등 메뉴 단축키를 복구했습니다.
  • 동기화 충돌을 항목별로 비교하고 남길 내용을 선택해 합칠 수 있습니다.
  • 웹 스크랩, 가져온 파일과 사진첩에도 첨부파일을 추가할 수 있습니다.
  • 넓은 창에서 영상 아래쪽이 잘리던 문제와 실제보다 작게 보이던 용량 표시를 수정했습니다.

v1.0.7 · 2026년 8월 26일

섹션 제목: “v1.0.7 · 2026년 8월 26일”
  • 사진첩을 만들고 이미지와 폴더를 모아 관리할 수 있습니다.
  • 사진첩의 이미지 정렬, 다중 선택, 다른 사진첩으로 이동과 확대 보기를 추가했습니다.
  • 콘텐츠 본문에 동영상을 넣고 이미지처럼 크기를 조절할 수 있습니다.
  • 본문에 넣은 이미지와 동영상을 하단 첨부 목록에서도 확인할 수 있습니다.
  • 카테고리 순서 변경과 카테고리 선택 안내를 개선했습니다.
  • macOS에서도 상단 툴바를 접거나 펼칠 수 있습니다.
  • 내용이 긴 동기화 버전 선택 창에서 정보가 팝업 밖으로 넘치던 문제를 수정했습니다.
  • Windows 설치본의 영상 처리 구성 요소 누락을 수정했습니다.

v1.0.6 · 2026년 8월 24일

섹션 제목: “v1.0.6 · 2026년 8월 24일”
  • 파일 메뉴에 새 화면캡처를 추가해 전체 화면, 창 선택과 자유 영역으로 진입할 수 있습니다.
  • 동기화 버전 선택에서 이전 버전 목록을 오른쪽 패널로 확인할 수 있습니다.
  • 버전 비교 중 로딩 상태와 선택 안내를 명확하게 표시합니다.
  • 워크스페이스의 Google Drive 동기화를 켤 때 다른 워크스페이스 자료가 섞일 수 있던 문제를 수정했습니다.
  • 통합검색에서 워크스페이스 필터를 선택할 수 있습니다.

v1.0.5 · 2026년 8월 23일

섹션 제목: “v1.0.5 · 2026년 8월 23일”
  • macOS에서 업데이트 재시작을 눌러도 앱이 백그라운드에 남던 문제를 수정했습니다.
  • 업데이트 적용을 위한 종료가 창 숨기기로 처리되지 않도록 개선했습니다.
  • 이전 배포본에서 이 버전으로 이동할 때는 한 번의 수동 재시작이 필요할 수 있습니다.

v1.0.4 · 2026년 8월 23일

섹션 제목: “v1.0.4 · 2026년 8월 23일”
  • 전체 화면, 창 선택, 자유 영역의 화면 캡처를 추가했습니다.
  • 이미지, PDF와 텍스트 파일을 앱으로 가져올 수 있습니다.
  • 원격 버전을 적용하기 전에 로컬 변경을 보관함에 남기는 동기화 보호를 추가했습니다.
  • macOS에서 AURORA 실행 중 사용자의 Chrome이 활성화되지 않던 문제를 수정했습니다.
  • 앱 첫 실행과 자유 영역 캡처의 응답을 개선했습니다.

v1.0.2 · 2026년 8월 20일

섹션 제목: “v1.0.2 · 2026년 8월 20일”
  • 콘텐츠의 회의 녹음과 첨부 오디오 재생 기능을 추가했습니다.
  • 녹음 데이터를 진행 중에도 파일에 기록해 예기치 않은 종료에 대비하도록 개선했습니다.
  • 유튜브 영상이 낮은 화질로만 저장되던 문제를 개선했습니다.
  • 앱 실행 시 비밀번호를 요구하는 보안설정을 추가했습니다.
  • 새 콘텐츠를 바로 만들지, 입력 화면을 먼저 열지 정하는 간편 실행 옵션을 제공합니다.
  • 미리보기의 이미지, HTML과 PDF 로딩 상태를 표시합니다.
  • 동영상 썸네일과 미디어 목록의 표시 문제를 수정했습니다.
  • 다크 테마 색상 계열과 시스템 테마 동작을 개선했습니다.

v1.0.1 · 2026년 8월 18일

섹션 제목: “v1.0.1 · 2026년 8월 18일”
  • macOS용 첫 서명 릴리스를 공개했습니다.
  • Intel과 Apple Silicon 환경에 맞는 macOS 설치 파일을 제공합니다.
  • 새 버전을 확인하고 내려받는 자동 업데이트 기능을 추가했습니다.

v1.0.0 · 2026년 8월 13일

섹션 제목: “v1.0.0 · 2026년 8월 13일”

  • 콘텐츠 이미지의 글자 인식을 지원하며 Windows와 macOS의 기본 인식 기능을 사용합니다.
