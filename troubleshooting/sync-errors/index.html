동기화 오류 해결

동기화 오류가 보이면 배너의 문구에 따라 조치합니다. 네트워크 끊김, Google 계정 재연결, Drive 공간 부족, 두 기기의 버전 충돌은 서로 다른 문제입니다. 로컬에 저장한 자료와 아직 내려받지 않은 원격 파일도 구분합니다. 오류를 해결하기 위해 워크스페이스를 먼저 삭제하거나 Drive 폴더를 직접 바꾸기보다 현재 상태를 확인합니다.

오류를 확인하는 순서

섹션 제목: “오류를 확인하는 순서”
  1. 오류가 표시되는 워크스페이스를 선택합니다. 이름과 저장 위치를 확인해 Google Drive인지 로컬·네트워크 폴더인지 구분합니다.
  2. 상태 배너의 전체 문구를 읽습니다. 다시 시도, 다시 연결, 버전 선택 중 어떤 버튼이 표시되는지 확인합니다.
  3. 현재 편집을 저장합니다. 편집기의 저장 실패와 동기화 배너 오류는 별도이므로 두 상태를 함께 확인합니다.
  4. 네트워크 오류이면 인터넷이나 동기화 폴더 접근을 복구합니다. 계정 오류이면 같은 Google 계정으로 다시 연결합니다.
  5. 원인을 처리한 뒤 다시 시도 또는 지금 동기화를 누릅니다. 진행 중에는 버튼을 반복해서 누르지 않습니다.
  6. 동기화 뒤 문제가 있던 파일을 다시 엽니다. 새로 만든 항목의 제목뿐 아니라 실제 본문과 첨부가 준비되었는지도 확인합니다.

오류 유형별 조치

섹션 제목: “오류 유형별 조치”
안내 확인할 원인 조치
네트워크 문제로 동기화하지 못했습니다 인터넷 연결 또는 통신 실패 연결을 확인한 뒤 다시 시도합니다.
Google 계정 재연결이 필요합니다 현재 인증 정보로 접근할 수 없음 다시 연결을 눌러 로그인합니다.
Google Drive 접근 권한이 없습니다 로그인 때 Drive 권한 미허용 계정을 다시 연결하고 해당 권한을 허용합니다.
Google Drive 저장 공간이 가득 찼습니다 Google 계정의 공간 부족 Drive 공간을 확보한 뒤 동기화를 확인합니다.
다른 기기에서 변경된 내용이 있습니다 아직 받지 않은 원격 변경 현재 저장을 마친 뒤 지금 동기화합니다.
다른 기기에서 수정된 버전이 있습니다 두 PC에서 변경한 내용이 갈라짐 버전 선택에서 차이를 확인합니다.
보관함에 저장하지 못해 가져오기 중단 로컬 공간 또는 폴더 권한 문제 보존 공간과 권한을 확인합니다.
동기화 중 문제가 발생했습니다 구체적 분류가 없는 작업 실패 다시 시도하고 계속되면 오류 문구를 기록합니다.

Google 계정 다시 연결하기

섹션 제목: “Google 계정 다시 연결하기”

다시 연결을 누르면 시스템 브라우저에서 로그인합니다. 브라우저에서 로그인을 완료하세요. 안내가 나오는 동안 브라우저로 이동합니다. 다른 PC에서 사용하는 계정과 같은 이메일을 선택합니다. 계정이 여러 개이면 기본으로 선택된 계정이 맞는지 다시 확인합니다.

Drive 권한을 허용하라는 동의 화면이 표시되면 해당 항목을 선택합니다. 로그인 자체가 성공했어도 Drive 권한을 주지 않으면 동기화할 수 없습니다. 권한을 허용하지 않았다는 오류가 나오면 다시 로그인하면서 권한을 선택합니다. 앱으로 돌아와 연결된 계정과 재연결 완료 안내를 확인합니다.

로그인을 취소했다면 연결이 완료되지 않은 상태입니다. 다시 연결 버튼을 여러 번 누르기보다 진행 중인 브라우저 창의 상태를 먼저 봅니다. 다른 계정으로 연결했는데 워크스페이스가 안 보이면 새 워크스페이스를 만들기 전에 원래 계정으로 돌아가 가져오기 목록을 확인합니다.

용량 오류 구분하기

섹션 제목: “용량 오류 구분하기”

Google Drive 공간 부족과 AURORA의 워크스페이스 용량 한도는 다릅니다. Drive 배너가 공간 부족을 표시하면 Google 계정 저장 공간을 확인합니다. 무료 1GB 또는 Pro 10GB 안내가 나온다면 AURORA의 해당 워크스페이스 용량을 확인합니다. PC 디스크가 가득 차면 로컬 저장이나 보관함 보존도 실패할 수 있습니다.

어느 공간이 부족한지 확인하지 않고 아무 파일이나 지우지 않습니다. 특히 Drive의 AuroraScrap 내부 파일이나 로컬 보관함을 임의로 정리하면 이후 확인할 자료가 줄어들 수 있습니다. 필요한 자료는 먼저 내보내고, 앱에서 지원하는 항목 정리 절차를 사용합니다. 정리 후에는 실제 용량 표시와 동기화 상태를 다시 확인합니다.

원격 앞섬과 버전 충돌

섹션 제목: “원격 앞섬과 버전 충돌”

다른 기기에서 변경된 내용이 있습니다는 다른 PC의 변경을 받을 필요가 있다는 알림입니다. 항상 충돌을 뜻하지는 않습니다. 현재 작업을 저장한 뒤 지금 동기화합니다. 로컬에서 수정한 내용이 없으면 원격 자료를 받아 정상적으로 이어 사용할 수 있습니다.

반면 다른 기기에서 수정된 버전이 있습니다와 버전 선택이 보이면 두 버전을 비교해야 합니다. 다른 기기의 새 항목만 가져오면 되는 경우는 자동으로 합칠 수 있지만, 같은 항목의 내용이 다르면 사용자가 선택합니다. 대화상자에서 내용 차이를 읽고 항목 병합 또는 한쪽 버전을 선택합니다. 시간만 보고 무조건 마지막 버전을 고르지는 않습니다.

보관함과 파일 다운로드 문제

섹션 제목: “보관함과 파일 다운로드 문제”

원격 버전을 가져오기 전에 로컬 변경을 보관함에 남기는 단계가 있습니다. 이 PC의 변경을 보관함에 저장하지 못해 가져오기를 중단했습니다가 보이면 앱이 보존 없이 교체를 진행하지 않은 상태입니다. 저장 공간과 폴더 권한을 확인한 뒤 다시 진행합니다. 보관함은 로컬에만 있으므로 다른 PC에서 같은 보관함을 찾을 수 없습니다.

목록이 표시되어도 첨부가 처음 열리지 않을 수 있습니다. 지연 다운로드가 끝날 때까지 기다리고 다시 시도를 누릅니다. 해당 파일을 만들었던 PC에서 업로드가 끝났는지도 확인합니다. 파일이 없는 문제를 계정 재설치나 워크스페이스 삭제로 먼저 해결하려 하지 않습니다. 원본 파일의 위치와 동기화 상태를 확인하는 것이 우선입니다.

로컬·네트워크 폴더를 사용하는 경우에는 Google 계정 재연결 대신 동기화 폴더가 열리는지 확인합니다. NAS나 공유 폴더가 연결되어 있는지, 현재 OS 계정이 해당 폴더에 쓸 수 있는지 확인합니다. 이름이 비슷한 다른 폴더로 바꿔 연결하면 원래 자료를 찾지 못할 수 있으므로 기존 대상 경로를 먼저 확인합니다.

문제를 설명할 때

워크스페이스 이름, 저장 위치 종류, 마지막으로 편집한 PC, 배너 문구, 마지막 정상 동기화 시점을 함께 기록합니다. Google 비밀번호나 라이선스 키를 오류 설명에 포함할 필요는 없습니다.

자주 묻는 질문

섹션 제목: “자주 묻는 질문”

다시 연결해도 브라우저에 오류가 보이면 어떻게 하나요?

섹션 제목: “다시 연결해도 브라우저에 오류가 보이면 어떻게 하나요?”

앱의 계정 연결 오류와 브라우저에 표시된 권한 안내를 확인합니다. Drive 권한을 선택했는지, 올바른 계정인지, 로그인을 끝까지 진행했는지 확인합니다. 같은 메시지가 반복되면 문구를 기록해 문의합니다.

오프라인 중 대기 항목은 없어지나요?

섹션 제목: “오프라인 중 대기 항목은 없어지나요?”

대기는 원격으로 전달할 작업이 남아 있다는 의미입니다. 연결이 복구된 뒤 상태를 확인합니다. 로컬에 저장한 자료는 먼저 보존하고, 다른 PC에서 동시에 수정하지 않은 상태로 동기화를 마치는 것이 좋습니다.

로그아웃하면 문제도 초기화되나요?

섹션 제목: “로그아웃하면 문제도 초기화되나요?”

연결 해제는 Google Drive 동기화를 중지합니다. 공간 부족이나 두 버전의 내용 차이를 해결하지는 않습니다. 인증 문제일 때 재연결하고, 다른 오류는 해당 원인에 맞는 절차를 사용합니다.
