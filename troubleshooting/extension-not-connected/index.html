확장 연결 문제

브라우저 확장 팝업에 미연결이 표시되면 먼저 AURORA 앱이 실행 중인지 확인합니다. 확장은 같은 컴퓨터에서 실행되는 앱과 연결해 워크스페이스와 카테고리를 불러옵니다. 브라우저에 확장을 설치한 것만으로 앱이 실행되는 것은 아닙니다. 앱 창이 보이지 않아도 트레이에 남아 있을 수 있으므로 창과 실행 상태를 구분해서 확인합니다.

연결을 다시 확인하는 순서

섹션 제목: “연결을 다시 확인하는 순서”
  1. AURORA 앱을 실행합니다. Windows에서는 시작 메뉴나 설치한 바로가기에서 엽니다. macOS에서는 응용 프로그램에 설치한 앱을 엽니다.
  2. 처음 실행한 상태이면 저장 위치 선택을 마칩니다. 잠금 화면이 있으면 비밀번호를 입력해 앱 화면을 엽니다.
  3. 사용할 워크스페이스와 카테고리가 있는지 확인합니다. 카테고리가 없다는 안내는 앱 연결 오류와 다르므로 먼저 카테고리를 만듭니다.
  4. 브라우저에서 확장 팝업을 닫았다가 다시 엽니다. 확인 중… 다음에 연결됨이 나타나는지 확인합니다.
  5. 연결되면 워크스페이스와 카테고리 목록이 표시되는지 확인합니다. 필요한 워크스페이스를 고르고 스크랩할 페이지로 돌아갑니다.
  6. 여전히 미연결이면 트레이에서 앱 실행 상태를 확인합니다. 앱을 완전히 종료한 뒤 다시 실행하고 확장 팝업을 다시 엽니다.
  7. 같은 문제가 계속되면 아래의 확장 설치 상태와 포트 충돌 항목을 확인합니다. 앱을 여러 번 실행하는 행동만 반복하지 않습니다.

문구별로 구분하기

섹션 제목: “문구별로 구분하기”
문구 또는 상태 의미 먼저 할 일
확인 중… 앱의 연결 상태를 확인합니다. 잠시 기다립니다.
미연결 현재 앱과 연결하지 못했습니다. 앱 실행과 트레이를 확인합니다.
Aurora Scrap 앱을 실행해주세요 앱 연결이 필요한 동작입니다. 데스크톱 앱을 먼저 실행합니다.
카테고리 없음 저장할 카테고리가 없습니다. 앱에서 카테고리를 만듭니다.
워크스페이스 로드 실패 연결 후 목록을 받지 못했습니다. 앱의 워크스페이스 상태를 확인하고 팝업을 다시 엽니다.
현재 탭 정보를 가져올 수 없습니다. 탭 정보를 읽지 못했습니다. 실제 웹페이지 탭에서 다시 시도합니다.
요청 시간이 초과되었습니다. 요청 응답을 정해진 시간에 받지 못했습니다. 앱의 진행 상태부터 확인합니다.

요청 시간이 초과되었다고 해서 반드시 저장 결과가 없는 것은 아닙니다. 앱 목록에 같은 제목의 항목이 생성되었는지 확인합니다. 처리 중인 요청이 남아 있으면 먼저 결과를 기다립니다. 연결 실패와 캡처 실패가 함께 보일 때는 연결부터 복구한 뒤 페이지 캡처를 확인합니다.

확장이 목록에 없는 경우

섹션 제목: “확장이 목록에 없는 경우”

앱의 도움말 → 크롬 익스텐션 설치가이드를 엽니다. 안내에 표시되는 실제 확장 폴더 경로를 사용합니다. Chrome에서는 주소 표시줄에 chrome://extensions를 입력하고 개발자 모드를 켠 뒤 압축해제한 확장을 로드하는 버튼을 선택합니다. manifest.json이 들어 있는 앱의 chrome-extension 폴더를 선택합니다.

macOS에서 폴더 선택 창으로 앱 내부 경로에 이동하기 어려우면 Cmd+Shift+G를 눌러 설치 안내의 실제 경로를 붙여 넣습니다. Windows 경로를 macOS에 그대로 입력하지 않습니다. 폴더 이름이 비슷해도 manifest.json이 없는 상위 폴더를 고르면 정상 설치되지 않습니다. 앱의 크롬 익스텐션 폴더 메뉴로 위치를 확인할 수 있습니다.

확장 목록에서 AURORA가 꺼져 있으면 사용 설정을 켭니다. 설치된 브라우저 프로필과 현재 사용하는 프로필이 같은지도 확인합니다. 다른 프로필에만 설치했다면 현재 창에는 확장이 표시되지 않을 수 있습니다. 확장 메뉴에서 고정하면 도구 모음에서 팝업을 다시 열기 쉽습니다. 설치된 것과 도구 모음에 고정된 것은 별도 상태입니다.

앱이 트레이에 보이지 않는 경우

섹션 제목: “앱이 트레이에 보이지 않는 경우”

Windows의 알림 영역에서 숨겨진 아이콘을 확인합니다. macOS에서는 위쪽 메뉴 막대의 아이콘을 확인합니다. 아이콘이 있으면 Aurora Scrap 열기로 메인 창을 다시 표시합니다. 종료를 선택했다면 앱은 실행 중이 아니므로 다시 실행해야 합니다.

PC를 재시작한 뒤에는 앱이 실제로 실행되어 있는지 다시 확인합니다. 현재 앱 설정에는 자동 시작을 켜는 조작 항목이 없습니다. 이전에 창을 닫아 트레이에 남겨 둔 상태가 컴퓨터 재시작 뒤에도 그대로 유지되는 것은 아닙니다. 확장을 사용하기 전에 앱을 실행하는 순서를 지킵니다.

로컬 포트 충돌 확인

섹션 제목: “로컬 포트 충돌 확인”

확장은 같은 PC의 127.0.0.1:17395에 있는 앱 서버와 통신합니다. Windows와 macOS에서 같은 포트를 사용합니다. 다른 프로그램이나 남아 있는 실행이 이 포트를 이미 사용하면 앱이 연결 서버를 열지 못할 수 있습니다. 이 경우 앱을 다시 실행해도 미연결이 계속될 수 있습니다.

먼저 AURORA를 트레이의 종료로 끝낸 뒤 한 번만 다시 실행합니다. 개발용 실행과 설치된 앱을 함께 사용하고 있었다면 필요한 실행 하나만 남깁니다. 어떤 프로그램이 포트를 사용하는지 모르는 상태에서 임의 프로세스를 종료하거나 방화벽 전체를 끄지 않습니다. 관리 담당자에게 포트 번호와 실행 상황을 알려 충돌 여부를 확인합니다. 공유기의 외부 포트 개방은 이 로컬 연결의 설치 절차가 아닙니다.

연결이 복구되면 작은 공개 웹페이지 한 건으로 저장을 확인합니다. 동일한 브라우저에서 연결됨을 확인하고, 카테고리를 선택한 뒤 스크랩하기를 누릅니다. 앱 목록에 새 항목이 나타나면 열어 결과를 봅니다. 이 확인을 마친 뒤 로그인 페이지나 긴 페이지를 다시 시도하면 연결 문제와 페이지 문제를 나누어 판단할 수 있습니다.

통신 방식

현재 확장은 같은 컴퓨터의 로컬 HTTP 서버를 사용합니다. 별도의 네이티브 메시징 호스트 등록이나 레지스트리 수정을 일반 사용자 연결 절차로 진행하지 않습니다.

자주 묻는 질문

섹션 제목: “자주 묻는 질문”

앱 창을 항상 화면에 띄워야 하나요?

섹션 제목: “앱 창을 항상 화면에 띄워야 하나요?”

창은 닫아도 앱이 트레이에서 실행 중이면 연결할 수 있습니다. 종료로 앱을 끝낸 상태에서는 연결되지 않습니다. 팝업의 연결 상태와 트레이를 함께 확인합니다.

연결됨인데 스크랩이 안 되면 어떻게 하나요?

섹션 제목: “연결됨인데 스크랩이 안 되면 어떻게 하나요?”

카테고리 선택, 현재 탭, 저장 포맷, 용량 안내를 확인합니다. 연결 성공은 앱에 도달했다는 뜻이며 모든 웹페이지의 캡처 성공을 보장하지 않습니다. 앱에 표시된 진행 상태와 오류도 확인합니다.

브라우저를 바꾼 뒤 확장이 사라졌어요.

섹션 제목: “브라우저를 바꾼 뒤 확장이 사라졌어요.”

확장은 사용하는 브라우저와 프로필에 설치해야 합니다. 다른 브라우저에 설치한 상태가 자동으로 복사되는 것으로 가정하지 않습니다. 앱의 설치 안내에서 현재 브라우저에 맞는 절차를 다시 확인합니다.
