동영상, 글자 인식과 녹음 문제

동영상 다운로드, 이미지의 글자 인식, 회의 녹음은 사용하는 입력과 실패 원인이 다릅니다. 영상은 원본 서비스와 다운로드 조건을, 글자 인식은 이미지 상태와 인식 엔진을, 녹음은 마이크 연결과 OS 권한을 확인합니다. 먼저 어느 단계에서 실패했는지 구분하고 해당 오류 문구에 맞춰 조치합니다. 모든 실패를 인터넷 연결 하나로 설명하지 않습니다.

문제를 구분하는 순서

섹션 제목: “문제를 구분하는 순서”
  1. 화면에 표시된 문구를 그대로 확인합니다. 다운로드 실패, 텍스트 인식에 실패했습니다, 녹음 저장에 실패했습니다는 다른 단계의 오류입니다.
  2. 원본이 준비되어 있는지 확인합니다. 영상은 브라우저에서 재생되는지, 이미지는 로컬에서 열리는지, 마이크는 연결되어 있는지 확인합니다.
  3. 다른 PC에서 받은 파일이면 동기화 다운로드부터 끝냅니다. 목록에 항목이 있어도 영상이나 이미지 원본이 아직 로컬에 없을 수 있습니다.
  4. 아래 표에서 현재 오류와 맞는 항목을 찾습니다. 원인을 처리한 뒤 같은 기능을 한 번 다시 실행합니다.
  5. 성공한 뒤 실제 결과를 확인합니다. 영상은 재생, OCR은 글자 대조, 녹음은 첨부 오디오 재생으로 확인합니다.

오류별 첫 조치

섹션 제목: “오류별 첫 조치”
표시 주로 확인할 것 다음 행동
다운로드 실패 사이트 지원과 영상 접근 상태 원본 재생 여부와 다운로드 선택을 확인합니다.
라이브 방송 감지 방송이 현재 진행 중인지 페이지 모드로 전환된 결과를 확인합니다.
인식된 텍스트가 없습니다 이미지의 글자 크기와 선명도 글자가 보이는 원본 이미지로 다시 확인합니다.
텍스트 인식에 실패했습니다 이미지와 인식 자료 준비 상태 첫 사용이면 인터넷 연결도 확인합니다.
연결된 마이크가 없습니다 입력 장치 연결 사용할 마이크를 연결한 뒤 시도합니다.
마이크 권한이 거부되어 있습니다 OS의 앱 마이크 권한 해당 권한을 허용합니다.
마이크를 시작할 수 없습니다 다른 앱 사용 또는 OS 차단 다른 녹음 앱과 시스템 권한을 확인합니다.
녹음 저장에 실패했습니다 저장 폴더와 디스크 공간 저장 위치를 확인하고 결과 파일을 점검합니다.

동영상 다운로드가 실패할 때

섹션 제목: “동영상 다운로드가 실패할 때”

브라우저에서 원본 영상이 재생되는지 먼저 확인합니다. 삭제되었거나 로그인이 필요한 영상은 다운로드 경로에서도 접근하지 못할 수 있습니다. AURORA는 지원되는 사이트에서 다운로드를 시도하며 모든 사이트의 모든 영상을 보장하지 않습니다. 브라우저에서 재생되는 것과 앱에서 파일로 내려받을 수 있는 것은 다른 조건입니다.

스크랩 다이얼로그에서 MP4 또는 MP3 중 무엇을 선택했는지 확인합니다. MP3를 선택했다면 영상 파일이 없는 것이 정상일 수 있습니다. 페이지 내 미디어를 받으려면 페이지 내 동영상/오디오 다운로드 선택도 확인합니다. 설정한 최대 용량보다 큰 파일이면 받지 못할 수 있습니다. 최대 용량을 바꾸기 전에 로컬과 워크스페이스의 남은 공간을 확인합니다.

라이브 방송이 감지되면 화면 스크랩으로 전환될 수 있습니다. 이 결과는 방송 전체를 녹화한 파일과 다릅니다. 동영상 다운로드 실패, 일반 스크랩으로 전환… 안내가 나오면 저장된 페이지와 이미지부터 확인합니다. 미디어 목록에 표시된 원본 주소를 열어 접근 상태를 확인합니다. 다운로드 조건을 바꿨다면 페이지를 새로 스크랩하고 결과를 비교합니다. 실패 항목만 확인하려다 정상 저장된 전체 스크랩을 삭제하지 않습니다.

OCR에 인터넷이 필요하다는 안내가 나올 때

섹션 제목: “OCR에 인터넷이 필요하다는 안내가 나올 때”

OCR은 이미지에서 글자를 읽어 텍스트로 바꾸는 기능입니다. 현재는 콘텐츠 에디터에 이미지를 삽입하고 선택한 뒤 텍스트 인식을 실행합니다. 사진첩이나 스크린샷 미리보기에서 직접 같은 버튼을 찾는 절차는 아닙니다. 필요한 이미지를 콘텐츠에 넣은 뒤 인식 결과를 확인합니다.

Windows에서는 운영체제의 글자 인식 기능을 먼저 사용하고, macOS에서는 Apple Vision을 먼저 사용합니다. 이 경로는 이미지를 외부 인식 서버에 보내는 방식이 아닙니다. 기본 인식이 불가능하거나 결과가 없을 때는 보조 인식 엔진을 사용할 수 있습니다. 보조 엔진이 처음 필요한 경우 언어 자료를 내려받기 위해 인터넷 연결이 필요할 수 있습니다.

그래서 오류 문구에 첫 사용 시 연결이 필요하다고 표시됩니다. 모든 OCR 실행에 항상 인터넷이 필수라는 뜻은 아닙니다. 처음 실패했을 때는 연결을 확인한 뒤 다시 시도하고, 이미지 파일이 실제로 열리는지도 함께 확인합니다. 글자가 아주 작거나 흐린 이미지에서는 결과가 비어 있거나 오인식할 수 있습니다.

원본에서 더 선명한 이미지가 있으면 그 파일로 확인합니다. 텍스트 복사로 가져온 글자는 숫자, 날짜, 이름을 원본과 대조합니다. 인식 성공은 내용의 정확성까지 보장하는 의미가 아닙니다. 검색이나 문서에 붙이기 전에 필요한 부분을 수정합니다.

마이크 권한 확인하기

섹션 제목: “마이크 권한 확인하기”

Windows에서는 시스템 설정의 마이크 개인정보 권한과 데스크톱 앱의 접근 허용 상태를 확인합니다. 연결된 입력 장치가 사용할 마이크인지도 확인합니다. macOS에서는 시스템 설정의 개인정보 보호 및 보안에서 마이크 권한을 확인하고 Aurora Scrap을 허용합니다. 권한 변경 뒤 앱을 다시 시작해야 하는 안내가 나오면 그 순서를 따릅니다.

권한이 허용되어 있어도 마이크가 분리되어 있으면 녹음을 시작할 수 없습니다. 다른 회의나 녹음 프로그램이 장치를 사용하고 있으면 그 프로그램의 사용 상태를 확인합니다. 앱의 회의 녹음을 짧게 실행한 뒤 녹음 중지를 눌러 실제 소리가 들어오는지 시험합니다. 중요한 녹음을 시작하기 전에 짧은 결과 파일을 재생하면 입력 장치 문제를 미리 확인할 수 있습니다.

녹음 중 화면 이동과 저장

섹션 제목: “녹음 중 화면 이동과 저장”

회의 녹음 중에는 목록에 REC 표시가 나타납니다. 다른 항목이나 워크스페이스로 이동하려 하면 녹음을 중지하고 지금까지의 분량을 저장한다는 확인이 나올 수 있습니다. 계속 녹음하려면 이동을 취소합니다. 이동할 계획이면 먼저 녹음 중지를 누르고 녹음이 첨부파일로 저장되었습니다. 안내를 확인합니다.

녹음 데이터는 진행 중에도 파일로 기록하지만, 정상 종료와 저장 완료 확인을 생략해도 된다는 의미는 아닙니다. **녹음 저장에 실패했습니다.**가 나오면 디스크 공간과 자료 저장 위치를 확인합니다. 녹음 시작 실패와 파일 저장 실패는 구분해서 설명합니다. 첨부 목록에서 실제 녹음 파일을 열고 필요한 분량이 재생되는지 확인합니다.

짧은 결과로 먼저 확인

영상은 재생 시작 부분과 끝부분을, OCR은 몇 줄의 글자를, 녹음은 짧은 시험 파일을 확인합니다. 버튼 클릭 성공보다 결과 파일의 내용을 확인하는 것이 정확합니다.

자주 묻는 질문

섹션 제목: “자주 묻는 질문”

무료라서 영상이나 OCR이 실패하나요?

섹션 제목: “무료라서 영상이나 OCR이 실패하나요?”

두 기능은 무료에서도 사용할 수 있습니다. 사이트 지원, 인식 자료, 권한, 워크스페이스 용량 등 실제 오류 조건을 확인합니다. 모든 실패를 유료 등록으로 해결할 수 있는 것은 아닙니다.

회의 녹음이 회의 내용을 글자로 바꾸나요?

섹션 제목: “회의 녹음이 회의 내용을 글자로 바꾸나요?”

여기서 안내하는 회의 녹음은 마이크 오디오를 첨부파일로 저장하는 기능입니다. 녹음 결과가 자동으로 회의록이나 받아쓰기 텍스트가 되는 기능으로 설명하지 않습니다.

OCR 결과가 비어 있어도 원본은 남나요?

섹션 제목: “OCR 결과가 비어 있어도 원본은 남나요?”

글자 인식 결과가 비어 있다는 안내와 이미지 파일 삭제는 별개입니다. 원본 이미지를 확인하고 다른 선명한 이미지로 다시 시도합니다. 결과 창을 닫기 전에 필요한 텍스트를 복사합니다.
